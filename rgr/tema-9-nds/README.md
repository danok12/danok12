Вариант: задача 1 — строка 14 (σx, σy, τxy) и строка 11 (σz, τyz, τzx);
задача 2 — σx по строке 29, σy по строке 8, τxy по строке 25.

В этой папке — **продолжение** расчёта: задача 1, пп. 7–8 (удельная потенциальная
энергия и проверка прочности по IV теории) и задача 2, пп. 1–3 (тензор, главные
напряжения через кубическое уравнение, углы наклона главных площадок).

Порядок решения и обозначения повторяют разбор на практическом занятии
(тетрадь): U₀ = U₀^об + U₀^ф через главные напряжения, σ_экв^IV по модели

с I₃н = 0, углы — по формуле tg αi = τyx/(σy − σi) при оси y, направленной вниз.
