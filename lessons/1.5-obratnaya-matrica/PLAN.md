# Урок 1.5. Обратная матрица — полный план на 60 минут

**Тема:** обратная матрица: определение, критерий существования, два способа вычисления, свойства, применение.
**Уровень:** первое знакомство с темой (§1.5), от нуля.
**Что ученик должен уметь к концу урока:**

1. объяснить, что такое обратная матрица, и проверить, обратна ли данная матрица другой;
2. мгновенно определять по определителю, существует ли обратная матрица;
3. находить `A⁻¹` для 2×2 «в одну строчку»;
4. находить `A⁻¹` для 3×3 методом алгебраических дополнений;
5. находить `A⁻¹` методом Гаусса–Жордана;
6. решать матричное уравнение `AX = B` и систему через `A⁻¹`;
7. знать свойства `(AB)⁻¹ = B⁻¹A⁻¹`, `det A⁻¹ = 1/det A` и типовые ловушки.

**Нужно на уроке:** доска/лист А4 в клетку, карандаш, ластик. Калькулятор **не нужен** — все примеры подобраны с целыми числами.

## Блок 0 (0–3 мин). Вход

**Говорим ученику (дословно можно так):**

> Сегодня мы научимся «делить на матрицу». Делить матрицы напрямую нельзя — такой операции не существует. Но у чисел деление `b / a` — это на самом деле умножение на `1/a = a⁻¹`. Значит, чтобы «поделить», достаточно найти для матрицы `A` такую матрицу, которая играет роль `1/A`. Она называется **обратной** и обозначается `A⁻¹`. Весь урок — про то, когда она есть и как её найти.

Записываем на доске цель: **найти `A⁻¹`** и **решить `AX = B`**.

## Блок 1 (3–10 мин). Разминка: три вещи, без которых дальше нельзя

### 1.1. Умножение матриц — «строка на столбец»

Элемент результата в строке `i` и столбце `j` = скалярное произведение `i`-й строки первой матрицы на `j`-й столбец второй.

**Задание ученику (1 мин, устно/на листке):** перемножить

```
A = | 2  5 |      B = |  3  -5 |
    | 1  3 |          | -1   2 |
```

Считаем вместе:

```
(A·B)₁₁ = 2·3 + 5·(-1) = 6 - 5 = 1
(A·B)₁₂ = 2·(-5) + 5·2 = -10 + 10 = 0
(A·B)₂₁ = 1·3 + 3·(-1) = 3 - 3 = 0
(A·B)₂₂ = 1·(-5) + 3·2 = -5 + 6 = 1

A·B = | 1  0 |
      | 0  1 |
```

**Ключевой вопрос:** что получилось? — Единичная матрица. Оставляем это на доске, через 10 минут окажется, что мы уже нашли обратную матрицу.

### 1.2. Единичная матрица `E`

```
E = | 1  0  0 |
    | 0  1  0 |
    | 0  0  1 |
```

Единицы по главной диагонали, остальное — нули. Главное свойство: `A·E = E·A = A` для любой `A` подходящего размера. **`E` в мире матриц — это то же, что число 1 в мире чисел.**

### 1.3. Определитель

2×2:
```
| a  b |
| c  d |   →   det = ad - bc
```

3×3 — разложение по первой строке:
```
| a₁₁ a₁₂ a₁₃ |
| a₂₁ a₂₂ a₂₃ |  = a₁₁·| a₂₂ a₂₃ | - a₁₂·| a₂₁ a₂₃ | + a₁₃·| a₂₁ a₂₂ |
| a₃₁ a₃₂ a₃₃ |        | a₃₂ a₃₃ |        | a₃₁ a₃₃ |        | a₃₁ a₃₂ |
```
Обратите внимание на знаки `+ − +` — они не случайны, к ним вернёмся в блоке 5.

**Разминочный счёт (1 мин):** `det | 2 5 ; 1 3 | = 2·3 - 5·1 = 1`.

**Терминология, сразу на доску:**
- `det A ≠ 0` → матрица **невырожденная** (неособенная);
- `det A = 0` → матрица **вырожденная** (особенная).

## Блок 2 (10–14 мин). Мотивация: почему нужна именно обратная матрица

Пишем на доске обычное школьное уравнение и рядом матричное:

```
числа:     3x = 12        →  x = 12/3 = (1/3)·12 = 3
матрицы:   A·X = B        →  X = ?
```

Деления матриц **нет**. Но если найдётся матрица `A⁻¹` со свойством `A⁻¹·A = E`, то умножим уравнение слева на неё:

```
A·X = B
A⁻¹·(A·X) = A⁻¹·B
(A⁻¹·A)·X = A⁻¹·B      (ассоциативность)
E·X = A⁻¹·B
X = A⁻¹·B
```

Уравнение решено. **Вот и вся мотивация:** `A⁻¹` — это инструмент, которым «переносят матрицу через знак равенства».

**Сразу важное предупреждение (подчеркнуть двумя чертами):** умножать надо **с одной и той же стороны** в обеих частях, потому что `A·B ≠ B·A`. Поэтому:
- из `A·X = B` следует `X = A⁻¹·B` (умножали **слева**);
- из `X·A = B` следует `X = B·A⁻¹` (умножали **справа**).

Это ошибка №1 всех контрольных. Спросить ученика: «а если `A·X·C = B`?» — ответ: `X = A⁻¹·B·C⁻¹`.

## Блок 3 (14–21 мин). Определение и когда обратная существует

### 3.1. Определение

> **Определение.** Пусть `A` — **квадратная** матрица порядка `n`. Матрица `A⁻¹` того же порядка называется **обратной** к `A`, если
>
> ```
> A·A⁻¹ = A⁻¹·A = E
> ```

Три замечания, которые обязательно проговорить:

1. **Только квадратные матрицы** могут иметь обратную: иначе `A·A⁻¹` и `A⁻¹·A` — разных размеров и не могут обе равняться `E`.
2. Требуются **оба** равенства. (Полезный факт: для квадратных матриц достаточно проверить одно — из `A·B = E` автоматически следует `B·A = E`. Поэтому на практике проверяют одно произведение.)
3. `A⁻¹` — это **обозначение целиком**, а не «`A` в степени минус один» поэлементно. `A⁻¹` **не** получается заменой каждого элемента на `1/aᵢⱼ`. Это ошибка №2. Проверить на `A = |2 5; 1 3|`: поэлементно было бы `|0.5 0.2; 1 0.333|`, а правильный ответ — `|3 -5; -1 2|` (мы его уже получили в разминке!).

**Возврат к разминке:** мы в блоке 1.1 перемножили `|2 5; 1 3|` и `|3 -5; -1 2|` и получили `E`. Значит

```
| 2  5 |⁻¹ = |  3  -5 |
| 1  3 |     | -1   2 |
```

Первая обратная матрица найдена — до всякой теории. Вопрос ученику: **а как её было найти, если бы не подсказали?** Этим и займёмся.

### 3.2. Единственность

> **Теорема.** Если обратная матрица существует, то она единственна.

**Доказательство (написать, оно в три строки):** пусть `B` и `C` — обе обратные к `A`. Тогда
```
B = B·E = B·(A·C) = (B·A)·C = E·C = C.
```
Значит `B = C`. ∎

Отсюда законно говорить «**та** обратная матрица» и писать `A⁻¹`.

### 3.3. Критерий существования — главная теорема урока

> **Теорема (критерий обратимости).** Квадратная матрица `A` имеет обратную **тогда и только тогда, когда** `det A ≠ 0`, то есть когда она невырожденная.

**Почему «только тогда» (необходимость) — доказываем, это 2 строки и запоминается навсегда.**
Используем свойство определителя произведения: `det(A·B) = det A · det B`. Пусть `A⁻¹` существует. Тогда

```
A·A⁻¹ = E   ⟹   det A · det A⁻¹ = det E = 1
```

Произведение двух чисел равно 1 ⟹ ни один множитель не равен нулю ⟹ `det A ≠ 0`. Попутно бесплатно получили важную формулу:

```
det A⁻¹ = 1 / det A
```

Достаточность («если `det A ≠ 0`, то `A⁻¹` есть») докажем конструктивно в блоке 5 — просто предъявим формулу.

**Практический вывод, который ученик должен усвоить как рефлекс:**

> **Шаг 0 любой задачи на обратную матрицу — посчитать `det A`.**
> `det A = 0` → ответ «обратной не существует», работа закончена.
> `det A ≠ 0` → считаем дальше, и этот же `det A` понадобится в формуле.

**Мини-проверка (2 мин, ученик считает сам):** у каких матриц есть обратная?

```
P = | 3  1 |     Q = | 2  -1 |     R = | 1  2  3 |
    | 6  2 |         | 4  -1 |         | 0  0  0 |
                                       | 7  8  9 |
```

Ответы: `det P = 6 - 6 = 0` → нет. `det Q = -2 + 4 = 2 ≠ 0` → есть. `det R = 0` (нулевая строка) → нет.
Полезное наблюдение для `R`: если есть нулевая строка/столбец или две пропорциональные строки — определитель нулевой, обратной нет, считать ничего не надо.

## Блок 4 (21–27 мин). Случай 2×2: формула, которую надо знать наизусть

Для
```
A = | a  b |        det A = ad - bc ≠ 0
    | c  d |
```
обратная равна
```
A⁻¹ = ───1───  ·  |  d  -b |
      ad - bc     | -c   a |
```

**Мнемоника (проговорить и показать пальцем на доске):**
1. элементы **главной** диагонали `a` и `d` — **поменять местами**;
2. элементы **побочной** диагонали `b` и `c` — **сменить знак**;
3. всё **разделить на определитель**.

**Проверим формулу честно** (это и есть доказательство для 2×2):
```
| a  b | · |  d  -b |  =  | ad - bc    -ab + ab |  =  | ad-bc     0   |  = (ad-bc)·E
| c  d |   | -c   a |     | cd - dc    -cb + ad |     |   0    ad-bc  |
```
Поделив на `ad - bc`, получаем ровно `E`. ∎

### Пример 1 (разбираем вместе)

```
A = | 4  3 |
    | 3  2 |
```
1. `det A = 4·2 - 3·3 = 8 - 9 = -1 ≠ 0` → обратная есть.
2. Меняем диагональ, меняем знаки:
```
|  2  -3 |
| -3   4 |
```
3. Делим на `-1`:
```
A⁻¹ = | -2   3 |
      |  3  -4 |
```
4. **Проверка (никогда не пропускать!):**
```
| 4  3 | · | -2   3 | = | -8+9   12-12 | = | 1  0 |   ✓
| 3  2 |   |  3  -4 |   | -6+6    9-8  |   | 0  1 |
```

### Пример 2 (ученик делает сам, 2 мин)

```
B = | 7  4 |
    | 5  3 |
```
Ответ: `det B = 21 - 20 = 1`, `B⁻¹ = | 3 -4 ; -5 7 |`.
Проверка: `7·3 + 4·(-5) = 21 - 20 = 1` ✓, `7·(-4) + 4·7 = -28 + 28 = 0` ✓.

**Вопрос на понимание:** почему в примерах так часто получаются целые числа? — Потому что `det = ±1`. Если `det A = 5`, в ответе будут дроби со знаменателем 5, и это нормально: **дроби в `A⁻¹` — не признак ошибки.** Лучше оставлять множитель перед матрицей: `A⁻¹ = (1/5)·| ... |` — так меньше арифметических ошибок.

## Блок 5 (27–38 мин). Метод алгебраических дополнений (присоединённая матрица)

Это общий метод для любого порядка. Нужны два новых понятия.

### 5.1. Минор и алгебраическое дополнение

> **Минор** `Mᵢⱼ` элемента `aᵢⱼ` — определитель, который остаётся, если **вычеркнуть** `i`-ю строку и `j`-й столбец.
>
> **Алгебраическое дополнение** `Aᵢⱼ = (-1)^(i+j) · Mᵢⱼ` — тот же минор со знаком «шахматной доски».

Знаки удобно держать в голове картинкой:
```
| +  -  + |
| -  +  - |
| +  -  + |
```
Левый верхний угол всегда `+`, дальше знаки чередуются. (Это те же знаки, что в разложении определителя из блока 1.3 — теперь понятно, откуда они.)

### 5.2. Формула

> **Теорема.** Если `det A ≠ 0`, то
> ```
>            1
> A⁻¹ = ───────── · Ã ,     где Ã = (Aᵢⱼ)ᵗ
>          det A
> ```
> `Ã` — **присоединённая** (союзная) матрица: матрица из алгебраических дополнений, **транспонированная**.

**Почему это работает** (объяснить идею, не обязательно расписывать полностью): при умножении `A · Ã` на диагонали стоят суммы `aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + aᵢ₃Aᵢ₃` — это в точности разложение определителя по `i`-й строке, то есть `det A`. А вне диагонали стоят «разложения по чужой строке», и такие суммы всегда равны нулю (это равносильно определителю матрицы с двумя одинаковыми строками). Итого `A·Ã = det A · E`, откуда и получается формула. ∎ Заодно это и есть доказательство достаточности из блока 3.3.

### 5.3. Алгоритм (записать в тетрадь как памятку)

```
Шаг 1. Посчитать det A.  Если 0 — ответ «обратной нет», стоп.
Шаг 2. Посчитать все 9 алгебраических дополнений Aᵢⱼ (для 3×3).
Шаг 3. Записать их в матрицу на свои места (i, j).
Шаг 4. ТРАНСПОНИРОВАТЬ её → получили Ã.
Шаг 5. Разделить каждый элемент на det A.
Шаг 6. Проверить: A·A⁻¹ = E.
```

**Шаг 4 забывают чаще всего.** Это ошибка №3. Подчеркнуть.

### 5.4. Разбор примера 3×3 полностью

```
A = | 1  2  3 |
    | 0  1  4 |
    | 5  6  0 |
```

**Шаг 1. Определитель** (по первой строке):
```
det A = 1·| 1 4 | - 2·| 0 4 | + 3·| 0 1 |
          | 6 0 |     | 5 0 |     | 5 6 |

      = 1·(1·0 - 4·6) - 2·(0·0 - 4·5) + 3·(0·6 - 1·5)
      = 1·(-24) - 2·(-20) + 3·(-5)
      = -24 + 40 - 15 = 1 ≠ 0      → обратная существует
```

**Шаг 2. Девять алгебраических дополнений.** Каждый раз вычёркиваем строку и столбец и не забываем знак:

```
A₁₁ = + | 1 4 | = 1·0 - 4·6 = -24        (вычеркнули 1-ю строку, 1-й столбец)
        | 6 0 |

A₁₂ = - | 0 4 | = -(0·0 - 4·5) = +20
        | 5 0 |

A₁₃ = + | 0 1 | = 0·6 - 1·5 = -5
        | 5 6 |

A₂₁ = - | 2 3 | = -(2·0 - 3·6) = +18
        | 6 0 |

A₂₂ = + | 1 3 | = 1·0 - 3·5 = -15
        | 5 0 |

A₂₃ = - | 1 2 | = -(1·6 - 2·5) = +4
        | 5 6 |

A₃₁ = + | 2 3 | = 2·4 - 3·1 = 5
        | 1 4 |

A₃₂ = - | 1 3 | = -(1·4 - 3·0) = -4
        | 0 4 |

A₃₃ = + | 1 2 | = 1·1 - 2·0 = 1
        | 0 1 |
```

**Шаг 3. Матрица алгебраических дополнений:**
```
| -24   20   -5 |
|  18  -15    4 |
|   5   -4    1 |
```

**Шаг 4. Транспонируем** (строки ↔ столбцы) — получаем присоединённую `Ã`:
```
Ã = | -24   18    5 |
    |  20  -15   -4 |
    |  -5    4    1 |
```

**Шаг 5. Делим на `det A = 1`:**
```
A⁻¹ = | -24   18    5 |
      |  20  -15   -4 |
      |  -5    4    1 |
```

**Шаг 6. Проверка** (достаточно посчитать все элементы одной строки и по одному из остальных, но здесь покажем полностью первую строку):
```
(A·A⁻¹)₁₁ = 1·(-24) + 2·20 + 3·(-5) = -24 + 40 - 15 = 1   ✓
(A·A⁻¹)₁₂ = 1·18 + 2·(-15) + 3·4   = 18 - 30 + 12 = 0     ✓
(A·A⁻¹)₁₃ = 1·5 + 2·(-4) + 3·1     = 5 - 8 + 3 = 0        ✓
(A·A⁻¹)₂₂ = 0·18 + 1·(-15) + 4·4   = -15 + 16 = 1         ✓
(A·A⁻¹)₃₃ = 5·5 + 6·(-4) + 0·1     = 25 - 24 = 1          ✓
```
Всё сходится.

**Оценка трудозатрат (сказать вслух):** для 3×3 это 1 определитель 3-го порядка + 9 определителей 2-го порядка = 10 счётных операций. Для 4×4 было бы 1 + 16 определителей 3-го порядка — уже очень долго. Поэтому существует второй метод.

## Блок 6 (38–46 мин). Метод Гаусса–Жордана (элементарных преобразований)

### 6.1. Идея

Приписываем справа к `A` единичную матрицу и получаем «широкую» таблицу `(A | E)`. Затем **элементарными преобразованиями строк** превращаем левую половину в `E`. Правая половина сама превратится в `A⁻¹`:

```
( A | E )  →  ...  →  ( E | A⁻¹ )
```

**Разрешённые преобразования строк (только строк, не столбцов!):**
1. умножить строку на число ≠ 0;
2. прибавить к строке другую строку, умноженную на число;
3. поменять две строки местами.

**Почему работает:** каждое преобразование строк — это умножение слева на некоторую матрицу. Если цепочка преобразований превратила `A` в `E`, то она равносильна умножению на `A⁻¹`; но та же цепочка применяется и к правой половине, поэтому из `E` она делает `A⁻¹·E = A⁻¹`. Если левую половину привести к `E` **не удаётся** (появилась нулевая строка) — значит `det A = 0` и обратной нет. Метод сам сообщает об этом.

### 6.2. Порядок действий

Сначала «вниз» — обнуляем всё **под** диагональю (прямой ход), потом «вверх» — обнуляем всё **над** диагональю (обратный ход), по пути делая диагональ единичной.

### 6.3. Разбор примера полностью

```
A = | 1  1  1 |
    | 0  1  2 |
    | 1  2  4 |
```

Записываем `(A | E)`:
```
| 1  1  1 |  1  0  0 |
| 0  1  2 |  0  1  0 |
| 1  2  4 |  0  0  1 |
```

**(1) Обнуляем первый столбец под единицей:** `R₃ := R₃ - R₁`
```
| 1  1  1 |  1  0  0 |
| 0  1  2 |  0  1  0 |
| 0  1  3 | -1  0  1 |
```

**(2) Обнуляем второй столбец под диагональю:** `R₃ := R₃ - R₂`
```
| 1  1  1 |  1  0  0 |
| 0  1  2 |  0  1  0 |
| 0  0  1 | -1 -1  1 |
```
Прямой ход закончен: слева «ступеньки», на диагонали единицы, нулевой строки не появилось → `det A ≠ 0`, обратная существует.

**(3) Обратный ход. Обнуляем третий столбец над диагональю:** `R₂ := R₂ - 2R₃`
```
| 1  1  1 |  1  0  0 |
| 0  1  0 |  2  3 -2 |
| 0  0  1 | -1 -1  1 |
```
и `R₁ := R₁ - R₃`
```
| 1  1  0 |  2  1 -1 |
| 0  1  0 |  2  3 -2 |
| 0  0  1 | -1 -1  1 |
```

**(4) Обнуляем второй столбец над диагональю:** `R₁ := R₁ - R₂`
```
| 1  0  0 |  0 -2  1 |
| 0  1  0 |  2  3 -2 |
| 0  0  1 | -1 -1  1 |
```

Слева `E` → справа ответ:
```
A⁻¹ = |  0  -2   1 |
      |  2   3  -2 |
      | -1  -1   1 |
```

**Проверка:**
```
(A·A⁻¹)₁₁ = 1·0 + 1·2 + 1·(-1) = 1      ✓
(A·A⁻¹)₁₂ = 1·(-2) + 1·3 + 1·(-1) = 0   ✓
(A·A⁻¹)₂₂ = 0·(-2) + 1·3 + 2·(-1) = 1   ✓
(A·A⁻¹)₃₃ = 1·1 + 2·(-2) + 4·1 = 1      ✓
```

### 6.4. Какой метод выбирать

| | Алгебраические дополнения | Гаусс–Жордан |
|---|---|---|
| 2×2 | лучший (формула в одну строку) | избыточно |
| 3×3 | удобно, если много нулей | удобно, если в первом столбце есть 1 |
| 4×4 и больше | практически неподъёмно | единственный разумный способ |
| Дроби | появляются один раз в конце | могут появиться в середине и тянуться |
| Бонус | попутно получаем `det A` | сам сообщает, что `det A = 0` |

## Блок 7 (46–50 мин). Свойства и применение

### 7.1. Свойства (записать в тетрадь, все нужны на контрольной)

Пусть `A`, `B` — невырожденные матрицы одного порядка, `λ ≠ 0` — число.

```
1)  (A⁻¹)⁻¹ = A                     обратная к обратной — исходная
2)  (A·B)⁻¹ = B⁻¹·A⁻¹               ПОРЯДОК МЕНЯЕТСЯ!
3)  (Aᵗ)⁻¹ = (A⁻¹)ᵗ                 транспонирование и обращение перестановочны
4)  (λA)⁻¹ = (1/λ)·A⁻¹
5)  det A⁻¹ = 1 / det A
6)  E⁻¹ = E
```

**Свойство 2 — проверить вместе, оно самое важное:**
```
(A·B)·(B⁻¹·A⁻¹) = A·(B·B⁻¹)·A⁻¹ = A·E·A⁻¹ = A·A⁻¹ = E   ✓
```
«Снимаем» матрицы, как обувь и куртку: надевали куртку последней — снимаем первой.

**Чего НЕ существует (проговорить явно):** `(A + B)⁻¹ ≠ A⁻¹ + B⁻¹`. Контрпример: `A = B = E`, тогда слева `(2E)⁻¹ = 0.5E`, справа `2E`.

### 7.2. Применение: система линейных уравнений

Систему
```
 x +  y +  z =  6
      y + 2z =  8
 x + 2y + 4z = 17
```
записываем в матричном виде `A·X = B`, где `A` — та самая матрица из блока 6:
```
A = | 1  1  1 |     X = | x |     B = |  6 |
    | 0  1  2 |         | y |         |  8 |
    | 1  2  4 |         | z |         | 17 |
```
Так как `A⁻¹` уже найдена, `X = A⁻¹·B`:
```
x =  0·6 + (-2)·8 +  1·17 = -16 + 17 = 1
y =  2·6 +   3·8  + (-2)·17 = 12 + 24 - 34 = 2
z = -1·6 + (-1)·8 +  1·17 = -14 + 17 = 3
```
Ответ: `x = 1, y = 2, z = 3`. **Проверка подстановкой:** `1+2+3 = 6` ✓, `2 + 6 = 8` ✓, `1 + 4 + 12 = 17` ✓.

Этот способ называется **матричным методом** решения системы; он работает, когда число уравнений равно числу неизвестных и `det A ≠ 0`.

### 7.3. Три типовые ошибки — повторить списком

1. **Сторона умножения:** `AX = B ⟹ X = A⁻¹B`, но `XA = B ⟹ X = BA⁻¹`.
2. **`A⁻¹` не считается поэлементно** как `1/aᵢⱼ`.
3. **Забыли транспонировать** матрицу алгебраических дополнений.

Плюс: не забыть шаг 0 (`det A`) и не забыть проверку `A·A⁻¹ = E`.

### Задача 2. Матрица 3×3 методом алгебраических дополнений

```

    | 0  1  1 |
    | 1  1  2 |
```

**Решение.**
`det C = 1·(1·2 - 1·1) - 0·(0·2 - 1·1) + 2·(0·1 - 1·1) = 1 - 0 - 2 = -1 ≠ 0`.

Алгебраические дополнения:
```
C₁₁ = +(1·2 - 1·1) =  1      C₁₂ = -(0·2 - 1·1) =  1      C₁₃ = +(0·1 - 1·1) = -1
C₂₁ = -(0·2 - 2·1) =  2      C₂₂ = +(1·2 - 2·1) =  0      C₂₃ = -(1·1 - 0·1) = -1
C₃₁ = +(0·1 - 2·1) = -2      C₃₂ = -(1·1 - 2·0) = -1      C₃₃ = +(1·1 - 0·0) =  1
```
Матрица дополнений и её транспонирование:
```
|  1   1  -1 |              |  1   2  -2 |
|  2   0  -1 |     →   C̃ =  |  1   0  -1 |
| -2  -1   1 |              | -1  -1   1 |
```
Делим на `det C = -1`:
```
C⁻¹ = | -1  -2   2 |
      | -1   0   1 |
      |  1   1  -1 |
```
Проверка: `(C·C⁻¹)₁₁ = 1·(-1) + 0·(-1) + 2·1 = 1` ✓; `(C·C⁻¹)₁₂ = 1·(-2) + 0·0 + 2·1 = 0` ✓; `(C·C⁻¹)₃₃ = 1·2 + 1·1 + 2·(-1) = 1` ✓.

### Задача 4. Матричное уравнение
