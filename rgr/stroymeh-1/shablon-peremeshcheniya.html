ЧАСТЬ 2. ПЕРЕМЕЩЕНИЯ ТОЧЕК K

Общий приём — метод Мора (как на паре)

Единичное состояние. Берём ту же систему, но без заданной нагрузки, и в точке K прикладываем единичное воздействие по направлению искомого перемещения: силу P = 1 — для линейного перемещения, момент M = 1 — для угла поворота. От него находим реакции и строим единичные эпюры M₁ (и N₁, когда они нужны).

Почему так можно. Это принцип возможных перемещений. Единичная сила вместе со своими реакциями и внутренними усилиями — уравновешенная система. Дадим ей «возможные» перемещения, равные действительным перемещениям конструкции от заданного воздействия. Тогда работа внешних сил единичного состояния равна работе его внутренних усилий на действительных деформациях. Работа единичной силы — 1·Δ, отсюда и Δ.

От нагрузки действительные деформации — изгиб стержней, кривизна MP/EJ. Влиянием N и Q в рамах пренебрегаем:

ΔKP = Σ ∫ MP·M₁ / EJ · dx

Интеграл берём перемножением эпюр. По Верещагину — площадь одной эпюры на ординату другой (прямолинейной) под центром тяжести этой площади: Ω·yc. По Симпсону — там, где эпюра MP — парабола от q: l/6·(a·c + 4·m·n + b·d), где a, b и c, d — ординаты эпюр по концам, m, n — посередине. Ординату параболы посередине находим как середину хорды плюс-минус ql²/8. Произведение берётся со знаком «+», если ординаты по одну сторону от оси стержня, и со знаком «−», если по разные.

От температуры стержень удлиняется на α·tср·dx и изгибается: грани удлиняются по-разному, взаимный поворот торцов — α·t′/h·dx. Работа единичных N₁ и M₁ на этих деформациях даёт:

ΔKt = Σ α·tср·ΩN1 + Σ α·t′/h·ΩM1, tср = (t₁ + t₂)/2, t′ = |t₁ − t₂|

Здесь ΩN1, ΩM1 — площади единичных эпюр N₁ и M₁ на стержне, h — высота сечения, α — коэффициент линейного расширения. Знак первого слагаемого «+», если N₁ — растяжение (при нагреве). Знак второго «+», если эпюра M₁ лежит со стороны более тёплого волокна, и «−», если со стороны более холодного.

От осадки опор стержни не деформируются, конструкция смещается как набор жёстких дисков. Внутренние усилия единичного состояния работы не совершают, а реакции совершают работу на смещениях опор: 1·ΔKc + Σ Ri1·ci = 0, откуда

ΔKc = −Σ Ri1·ci

Ri1 — реакции единичного состояния в тех связях, которые сместились. Произведение Ri1·ci положительно, если смещение опоры совпадает по направлению с реакцией.

Знак ответа. Если Δ получилось «+», точка K смещается по направлению единичного воздействия, если «−» — в обратную сторону.

Схема 1 — перемещение точки K от нагрузки, ΔKP

Направление в задании не указано (ΔKP — ?), поэтому находим обе составляющие — вертикальную и горизонтальную — и полное перемещение.

1. Грузовая эпюра MP — эпюра M из части 1:

A–B: 242 у A → 122 у B, растянуто нижнее волокно (нагрузки на участке нет — прямая) B–C: 122 у B → 130 у C, растянуто левое; под q — парабола, посередине: хорда (122 + 130)/2 = 126, плюс qh²/8 = 1·4²/8 = 2 → 128 C–K: 10 по всей длине (момент m на конце), растянуто левое C–D: 120 у C → 0 у D, растянуто нижнее

2. Единичное состояние «вертикаль»: P = 1 вниз в точке K. Реакции в заделке: RAy = 1 (вверх), MA = 1·6 = 6. Сила P = 1 направлена вдоль оси стойки K–C–B, поэтому изгибает только ригель A–B:

A–B: M₁ = 6 у A → 0 у B, растянуто верхнее волокно; на B–C, C–K, C–D M₁ = 0

3. Перемножение. Ненулевое произведение — только на A–B. Берём площадь треугольника M₁ и ординату трапеции MP под его центром тяжести (на 1/3 длины от A, то есть в 2 м от A):

Ω(M₁) = ½·6·6 = 18; yc(MP) = 242 − (242 − 122)·2/6 = 242 − 40 = 202 ординаты по разные стороны (M₁ сверху, MP снизу) — знак «−» ΔKверт = (1/EJ)·[−18·202] = −3636/EJ

Минус — точка K смещается против единичной силы, то есть вверх на 3636/EJ.

2′. Единичное состояние «горизонталь»: P = 1 вправо в точке K. Реакции: RAx = 1 (влево), MA = 1·8 = 8 (по часовой). Момент в сечении — 1, умноженное на расстояние по вертикали до K:

C–K: 0 у K → 4 у C, растянуто левое B–C: 4 у C → 8 у B, растянуто левое, посередине 6 A–B: 8 по всей длине, растянуто нижнее; C–D: M₁ = 0

3′. Перемножение — на всех трёх участках ординаты по одну сторону, знак «+»:

A–B (M₁ — прямоугольник, берём площадь трапеции MP): Ω(MP) = (242 + 122)/2·6 = 1092; yc(M₁) = 8 → 1092·8 = 8736 B–C (MP — парабола, по Симпсону): 4/6·(122·8 + 4·128·6 + 130·4) = 4/6·(976 + 3072 + 520) = 4/6·4568 → 3045,33 C–K (M₁ — треугольник, MP постоянна): Ω(M₁) = ½·4·4 = 8; yc(MP) = 10 → 8·10 = 80 C–D: M₁ = 0 → 0 ΔKгор = (1/EJ)·[8736 + 3045,33 + 80] = 11 861,33/EJ

Плюс — точка K смещается вправо на 11 861,33/EJ. Полное линейное перемещение:

ΔKP = √(3636² + 11 861,33²)/EJ = 12 406,12/EJ

Схема 3 — угол поворота сечения K от температуры, φKt

1. Единичное состояние: момент M = 1 в точке K (по часовой стрелке). Рама трёхшарнирная: шарниры в опорах 1 и 2 и шарнир J, которым ригель примыкает к левой стойке. Реакции — в том же порядке, что на паре:

ΣM₁ = 0 (вся рама, относительно опоры 1; горизонтальные реакции на одном уровне — плечо 0): −M + R2v·l = 0 → R2v = 1/6 (вверх) ΣY = 0: R1v + R2v = 0 → R1v = −1/6, то есть 1/6 вниз ΣMJправ = 0 (ригель с правой стойкой): R2v·l + R2h·h = 0 → R2h = −(1/6)·6/4 = −1/4, то есть 1/4 влево ΣX = 0: R1h + R2h = 0 → R1h = 1/4 (вправо) проверка ΣMJлев (левая стойка): −M + R1h·h = −1 + 1/4·4 = 0 ✓

2. Единичные эпюры M₁ и N₁:

M₁: K–J (консоль над ригелем): 1 по всей длине J–1 (левая стойка ниже J): 1 у J → 0 у опоры (R1h·4 = 1), наружная сторона J–R (ригель): 0 у J (шарнир) → 1 у R (R2h·4 = 1), наружная (верхняя) R–2 (правая стойка): 1 у R → 0 у опоры, наружная N₁: J–1: +1/6 (растяжение); J–R: −1/4 (сжатие); R–2: −1/6 (сжатие); K–J: 0

3. Площади единичных эпюр:

ΩN1: J–1: +1/6·4 = +2/3; J–R: −1/4·6 = −3/2; R–2: −1/6·4 = −2/3 Σ ΩN1 = 2/3 − 3/2 − 2/3 = −3/2 ΩM1: J–1: ½·4·1 = 2; J–R: ½·6·1 = 3; R–2: ½·4·1 = 2 — все с наружной стороны Σ ΩM1 = 2 + 3 + 2 = 7

4. Температура. Снаружи рамы t₁, внутри контура t₂ (как на паре: t₁ = −8°, t₂ = +20°). Внутри теплее, значит у всех стержней контура эпюра M₁ лежит со стороны более холодного волокна — второе слагаемое берётся со знаком «−». У консоли K–J обе грани снаружи: t′ = 0, а N₁ = 0. Поэтому, хотя M₁ = 1 на ней есть, вклада она не даёт.

φKt = α·tср·ΣΩN1 − α·(t′/h)·ΣΩM1 = α·tср·(−3/2) − α·(t′/h)·7 φKt = −α·(1,5·tср + 7·t′/h)

Подстановка с данными, как на паре (t₁ = −8°, t₂ = +20°, h = 0,5 м; свои t₁, t₂, h — из таблицы варианта):

tср = (−8 + 20)/2 = 6°, t′ = |20 − (−8)| = 28° φKt = α·6·(−3/2) − α·(28/0,5)·7 = −9α − 392α = −401·α рад

Минус — сечение K поворачивается против единичного момента, то есть против часовой стрелки. Например, для стали α = 1,2·10⁻⁵ 1/°C: φKt = −0,0048 рад.

Схема 4 — вертикальное перемещение точки K от осадки опор, ΔKc

1. Единичное состояние: P = 1 вниз в точке K — по направлению искомого вертикального перемещения. Реакции находим по поэтажной схеме, как в основном решении:

Этаж 2 — диск I (S–K–C–H): ΣMH = 0: −RS·6 + 1·3 = 0 → RS = 1/2 (вверх) ΣY = 0: RS + YH − 1 = 0 → YH = 1/2 (вверх); ΣX = 0: XH = 0 Этаж 1 — диск II (H–R–B), давление 1/2 вниз в H: ΣY = 0: RBy = 1/2 (вверх); ΣX = 0: RBx = 0 ΣMB = 0: 1/2·6 + MB = 0 → MB = −3, то есть 3 по часовой стрелке

2. Перемещение. Эпюры здесь не нужны — нужны только реакции в тех опорах, которые сместились:

ΔKc = −(RS·cS + RBx·cBx + RBy·cBy + MB·φB) = −(½·cS + 0·cBx + ½·cBy + 3·φB)

Смещения берутся со знаком «+», если они совпадают с направлением единичной реакции: cS и cBy — вверх, φB — по часовой стрелке. Что даёт каждое смещение:

смещение опорыреакция единичного состояниявклад в ΔKc (вниз)
опора S опустилась на cRS = 1/2 ↑ — навстречу+c/2
заделка B опустилась на cRBy = 1/2 ↑ — навстречу+c/2
заделка B сдвинулась по горизонтали на cRBx = 00
заделка B повернулась на φ по часовойMB = 3 ↻ — в ту же сторону−3φ (точка K поднимается)
заделка B повернулась на φ против часовойMB = 3 ↻ — навстречу+3φ

Подстановка с данными, как на паре (заделка опустилась на c₁ = 0,01 м, сдвинулась на c₂ = 0,02 м и повернулась на φ = 0,05 рад; свои смещения и направления — из задания):

ΔKc = −(½·(−0,01) + 0·0,02 + 3·0,05) = −(−0,005 + 0,15) = −0,145 м (при повороте по часовой) ΔKc = −(½·(−0,01) + 0·0,02 − 3·0,05) = −(−0,005 − 0,15) = +0,155 м (при повороте против часовой)

При повороте по часовой стрелке точка K поднимается на 14,5 см, при повороте против часовой — опускается на 15,5 см.

Проверка кинематикой. Каждое смещение опоры проверено отдельно, без формулы Мора. Диски перемещали как жёсткие тела: заделка B задаёт движение диска II, шарнир H и стержень S — движение диска I. Перемещение K совпало с −ΣR·c во всех четырёх случаях.

Все числа посчитаны программой (peremeshcheniya.py) в точной арифметике. Каждое перемножение эпюр проверено прямым численным интегрированием. Схема 3 проверена кинематически — сборкой температурных удлинений и искривлений стержней от опор с условием совпадения перемещений в шарнире J. Схема 4 — жёсткими перемещениями дисков.
