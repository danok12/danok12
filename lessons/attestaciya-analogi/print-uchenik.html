Аттестация: аналоги задач 1–11

Линейная алгебра · по образцу «Примерных задач на экзамен», задачи 1–11

К каждой задаче экзамена — два варианта того же типа (к задаче 3 — три). Решай в тетради с полной записью, как на экзамене.

Курсивом под заголовком — напоминание, как решать, а не ответ. Сначала попробуй без него.

Каждый ответ, где это возможно, проверь сам: подставь найденный вектор в систему, умножь матрицу на вектор, убедись, что |cosφ| ≤ 1.

1. Угол между функциями в C[0;1]

Как решать. (f,g) = ∫10f(x)·g(x)dx,   ‖f‖ = √(f,f),   cosφ = (f,g)‖f‖·‖g‖.
А)
Найдите косинус угла между функциями f, g ∈ C[0;1]:   f(x) = 2x + 1 и g(x) = x − 1 в евклидовом пространстве со скалярным произведением (f,g) = ∫10f(x)·g(x)dx.
Б)
Найдите косинус угла и сам угол между функциями f(x) = x и g(x) = 3x − 2 в C[0;1] с тем же скалярным произведением. Что можно сказать об этих функциях?

2. Дополнение до ортонормированного базиса в R³

Как решать. Третий вектор ортогонален обоим: решить систему из двух уравнений (c,a) = 0, (c,b) = 0 или взять векторное произведение a × b. Затем каждый вектор разделить на его длину.
А)
В пространстве L = R³ в стандартном базисе i, j, k заданы два вектора a = (2, 1, −2) и b = (1, 2, 2). Убедитесь, что они ортогональны, и дополните их третьим вектором до ортонормированного базиса. В ответе укажите все три вектора.
Б)
То же для a = (1, 1, 1) и b = (1, −2, 1).

3. Ранг квадратичной формы

Как решать. Ранг формы = ранг её симметричной матрицы. На диагонали — коэффициенты при xi², вне диагонали — половина коэффициента при xixj. Ранг — элементарными преобразованиями строк.
А)
Найдите ранг квадратичной формы f(x1, x2, x3) = x1² + 4x2² + 16x3² + 6x1x2 + 12x1x3 + 16x2x3.
Б)
То же для f = x1² + 5x2² + 2x3² − 4x1x2 − 2x1x3 + 6x2x3.
В)
То же для f = x1² + 4x2² + 9x3² + 4x1x2 − 6x1x3 − 12x2x3.

4. Базис и размерность пространства решений однородной системы

Как решать. Привести к ступенчатому виду, найти ранг r. Тогда dimL = n − r (n — число неизвестных). Свободным неизвестным по очереди даём значения (1, 0, 0), (0, 1, 0), (0, 0, 1) — получаем фундаментальную систему решений.
А)
Найдите какой-нибудь базис и установите размерность пространства решений однородной системы x1 − x2 + 2x3 + x4 − x5 = 0;x2 + x3 − 2x4 + 3x5 = 0.
Б)
То же для системы x1 + 2x2 − x3 + x4 + 3x5 = 0;2x1 + 5x2 − x3 + 4x4 + 4x5 = 0;x1 + 3x2 + 3x4 + x5 = 0.

5. Матрица линейного оператора в пространстве матриц 2×2

Как решать. Стандартный базис M2×2: E1 = 1000, E2 = 0100, E3 = 0010, E4 = 0001. Находим f(Ek), раскладываем по базису — эти координаты пишем в столбец № k.
А)
Пусть L = M2×2. Найдите матрицу A линейного оператора f(M) = 2−113T·M в стандартном базисе пространства L.
Б)
То же для оператора f(M) = M·120−1 (умножение справа).

6. Длины и угол по матрице Грама

Как решать. (x,y) = XT·G·Y (строка × матрица × столбец),   ‖x‖ = √(x,x),   cosφ = (x,y)‖x‖·‖y‖.
А)
В базисе {e1, e2} дана матрица Грама скалярного произведения G = 3−1−12 и векторы x = 21, y = −13. Найдите длины векторов x и y, а также угол между ними.
Б)
То же для G = 4223, x = 5−6, y = 11. Отдельно ответьте: ортогональны ли x и y в этом скалярном произведении? А если бы скалярное произведение было обычным?

7. Координаты многочлена в новом базисе

Как решать. Записать p = c1f1 + c2f2 (+ …), раскрыть скобки и приравнять коэффициенты при одинаковых степенях x — получится система для c1, c2, …
А)
В линейном пространстве P1 многочленов степени не выше 1 в стандартном базисе (x; 1) заданы три многочлена: p(x) = 2x + 1;  f1(x) = x + 3;  f2(x) = 2x + 5. Найдите координаты многочлена p(x) в новом базисе f1; f2.
Б)
В пространстве P2 многочленов степени не выше 2 в стандартном базисе (x²; x; 1) даны p(x) = 2x² − x + 5 и f1 = x² + 1, f2 = x² + x, f3 = x + 1. Найдите координаты p(x) в базисе f1; f2; f3.

8. Матрица оператора в R³ и образ вектора

Как решать. Строка № i матрицы A — коэффициенты при x1, x2, x3 в i-й координате образа (если переменной нет — пишем 0). Образ: f(x) = A·X.
А)
Найдите матрицу A линейного оператора f((x1, x2, x3)) = (2x1 − x2 + 4x3;  x1 + 3x3;  −x1 + 5x2 − 2x3) в стандартном базисе пространства L = R³ и образ вектора x = (2; −1; 3).
Б)
То же для f((x1, x2, x3)) = (x2 − x3;  3x1 + x2;  x1 − 2x2 + 4x3) и x = (1; −2; 3).

9. К какому собственному значению относится вектор

Как решать. Умножить A на столбец координат вектора. Если AX = λX — вектор собственный, а λ — искомое значение. Если результат не пропорционален X — вектор не собственный.
А)
Линейный оператор f в базисе e1, e2, e3 задан матрицей A = 24131−1131. Вектор x = −e1 + e2 − e3 является собственным вектором оператора f. Найдите, к какому собственному значению он относится.
Б)
Оператор задан матрицей A = 4−11213−212. Какой из векторов x = e1 + 2e2 и y = e1 + e2 + e3 является собственным? К какому собственному значению он относится?

10. Собственный вектор для данного собственного значения

Как решать. Решить однородную систему (A − λE)X = 0: вычесть λ из диагонали, привести к ступенчатому виду, взять любое ненулевое решение. Проверка: AX = λX.
А)
Для линейного оператора, заданного матрицей A = 30−12103−11, найдите какой-нибудь собственный вектор, соответствующий собственному числу λ = 2.
Б)
Для матрицы A = 0−122−34−11−3 найдите какой-нибудь собственный вектор, соответствующий λ = −1. Сколько линейно независимых собственных векторов отвечает этому значению?

11. Канонический вид квадратичной формы ортогональным преобразованием

Как решать. 1) Матрица формы (вне диагонали — половина коэффициента при x1x2). 2) Корни |A − λE| = 0 — это коэффициенты канонического вида. 3) Для каждого λ — собственный вектор, нормировать. 4) Из нормированных векторов-столбцов составить матрицу перехода: X = P·Y.
А)
Приведите квадратичную форму Φ(x1, x2) = x1² + 5x2² + 4√3x1x2 к каноническому виду и укажите соответствующее ортогональное преобразование координат.
Б)
То же для Φ(x1, x2) = −x1² + 4x2² + 12x1x2.
