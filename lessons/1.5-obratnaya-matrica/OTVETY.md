Везде используется алгоритм учебника: `1° |A| → 2° A' → 3° Ã → 4° делим на |A| → 5° проверка`.

## Задачи с урока

### 1.

**а)** `|A| = 21 − 20 = 1 ≠ 0`, по формуле 2×2:
```
A⁻¹ = | 3  -4 |
      | -5  7 |
```
Проверка: `7·3 + 4·(−5) = 1` ✓; `7·(−4) + 4·7 = 0` ✓; `5·3 + 3·(−5) = 0` ✓; `5·(−4) + 3·7 = 1` ✓.

**б)** `|B| = 2·(−2) − (−1)·4 = −4 + 4 = 0` → **обратной не существует**: матрица вырожденная (вторая строка вдвое больше первой).

**в)** `|C| = 3·2 − 6·1 = 0` → **обратной не существует**.

### 2.

**1°.** `|C| = 1·(1·2 − 1·1) − 0·(0·2 − 1·1) + 2·(0·1 − 1·1) = 1 − 0 − 2 = −1 ≠ 0`

**2°.** Транспонируем:
```
C' = | 1  0  1 |
     | 0  1  1 |
     | 2  1  2 |
```

**3°.** Алгебраические дополнения элементов `C'`:
```
C'₁₁ = +(1·2 − 1·1) =  1     C'₁₂ = −(0·2 − 1·2) =  2     C'₁₃ = +(0·1 − 1·2) = −2
C'₂₁ = −(0·2 − 1·1) =  1     C'₂₂ = +(1·2 − 1·2) =  0     C'₂₃ = −(1·1 − 0·2) = −1
C'₃₁ = +(0·1 − 1·1) = −1     C'₃₂ = −(1·1 − 1·0) = −1     C'₃₃ = +(1·1 − 0·0) =  1
```
```
C̃ = |  1   2  -2 |
    |  1   0  -1 |
    | -1  -1   1 |
```

**4°.** Делим на `|C| = −1`:
```
C⁻¹ = | -1  -2   2 |
      | -1   0   1 |
      |  1   1  -1 |
```

**5°.** Проверка: `(C·C⁻¹)₁₁ = 1·(−1) + 0·(−1) + 2·1 = 1` ✓; `(C·C⁻¹)₁₂ = 1·(−2) + 0·0 + 2·1 = 0` ✓; `(C·C⁻¹)₃₃ = 1·2 + 1·1 + 2·(−1) = 1` ✓.

### 3.

**1°.** `|D| = 2·(3·2 − 1·2) − 1·(1·2 − 1·0) + 0·(1·2 − 3·0) = 8 − 2 = 6 ≠ 0`

**2°.**
```
D' = | 2  1  0 |
     | 1  3  2 |
     | 0  1  2 |
```

**3°.**
```
D'₁₁ = +(3·2 − 2·1) =  4     D'₁₂ = −(1·2 − 2·0) = −2     D'₁₃ = +(1·1 − 3·0) =  1
D'₂₁ = −(1·2 − 0·1) = −2     D'₂₂ = +(2·2 − 0·0) =  4     D'₂₃ = −(2·1 − 1·0) = −2
D'₃₁ = +(1·2 − 0·3) =  2     D'₃₂ = −(2·2 − 0·1) = −4     D'₃₃ = +(2·3 − 1·1) =  5
```

**4°.**
```
          1     |  4  -2   1 |     |  2/3  -1/3   1/6 |
D⁻¹  =  ─────  · | -2   4  -2 |  =  | -1/3   2/3  -1/3 |
          6     |  2  -4   5 |     |  1/3  -2/3   5/6 |
```
Множитель `1/6` удобнее не раскрывать до самого конца.

**5°.** Проверка: `(D·D⁻¹)₁₁ = (1/6)·(2·4 + 1·(−2) + 0·2) = 1` ✓; `(D·D⁻¹)₁₂ = (1/6)·(2·(−2) + 1·4 + 0·(−4)) = 0` ✓; `(D·D⁻¹)₃₃ = (1/6)·(0·1 + 2·(−2) + 2·5) = 1` ✓.

### 4.

`|A| = 2·3 − 5·1 = 1`, `A⁻¹ = | 3 −5 ; −1 2 |`.
```
X = A⁻¹·B = | 3  -5 | · | 1 | = | 3 - 10 | = | -7 |
            | -1  2 |   | 2 |   | -1 + 4 |   |  3 |
```
Проверка: `2·(−7) + 5·3 = −14 + 15 = 1` ✓; `1·(−7) + 3·3 = 2` ✓.

*Если бы уравнение было `X·A = B`, то `X = B·A⁻¹`, и `B` должна была бы быть строкой — иначе размеры не согласуются.*

### 5.

a) `|A⁻¹| = 1/5` (свойство 1).
b) `|2A| = 2³·5 = 40`, поэтому `|(2A)⁻¹| = 1/40`.
c) `(A³)⁻¹ = (A⁻¹)³` (свойство 3).
d) Умножаем `A² = A` слева на `A⁻¹`: `(A⁻¹A)·A = A⁻¹A`, то есть `E·A = E`, значит `A = E`. ∎
e) Нет. Если `AX = E`, умножим слева на `A⁻¹`: `X = A⁻¹`. Аналогично для `YA = E` умножением справа. Другой обратной быть не может.
