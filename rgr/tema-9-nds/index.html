4. Главные площадки и главные напряжения

По найденным направляющим косинусам строим главный элемент — параллелепипед, гранями которого служат главные площадки. От центра каждой грани откладываем нормаль νi и действующее на этой площадке главное напряжение σi: σ₁ > 0 — стрелка от грани, σ₂ и σ₃ < 0 — стрелки к грани.

5. Экстремальные касательные напряжения

Они действуют на площадках, наклонённых под ±45° к главным площадкам:

τ12 = −(σ₁ − σ₂)/2 = −½·(105,96 + 7,15) = −56,56 МПа τ23 = −(σ₂ − σ₃)/2 = −½·(−7,15 + 178,81) = −85,83 МПа τ31 = −(σ₃ − σ₁)/2 = −½·(−178,81 − 105,96) = +142,38 МПа

Наибольшее по абсолютной величине — τ31 = 142,38 МПа; оно действует на площадке, равнонаклонённой к первому и третьему главным направлениям. Знак касательного напряжения показывает его направление: если τij > 0, стрелка направлена от оси j к оси i, если τij < 0 — наоборот. На тех же диагональных плоскостях действуют и нормальные напряжения:

σ12 = (σ₁ + σ₂)/2 = ½·(105,96 − 7,15) = 49,40 МПа σ23 = (σ₂ + σ₃)/2 = ½·(−7,15 − 178,81) = −92,98 МПа σ31 = (σ₁ + σ₃)/2 = ½·(105,96 − 178,81) = −36,42 МПа

Со стороны внешней нормали знак «+» означает, что напряжение направлено от сечения (растяжение), знак «−» — в сечение (сжатие).

б) Относительные угловые деформации

Величина γij показывает изменение прямого угла между соответствующими осями: если знак «+», прямой угол уменьшился; если знак «−» — увеличился. Каждая из трёх угловых деформаций относится к своей координатной плоскости, поэтому показываю их на трёх отдельных элементах: у первого сдвиг в плоскости xOy, у второго — в yOz, у третьего — в zOx. Закрашенная грань каждого куба и лежит в соответствующей плоскости, а у ближней к наблюдателю вершины видно, как исходный прямой угол превращается в острый (γ > 0) или тупой (γ < 0).

7. Полная удельная потенциальная энергия упругой деформации

Удельная энергия — энергия, приходящаяся на единицу объёма. Она складывается из двух составляющих: энергии изменения объёма и энергии изменения формы. Размерность удельной энергии совпадает с размерностью напряжения: Дж/м³ = Н·м/м³ = Н/м² = Па, поэтому результат записывается в МПа.

U₀ = U₀об + U₀ф

Полная энергия

U₀ = 1/(2E) · [σ₁² + σ₂² + σ₃² − 2ν·(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Обе суммы в квадратных скобках — это в точности инварианты тензора напряжений, поэтому беру их не через округлённые корни, а точно:

σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = (−80)² − 2·(−18425) = 6400 + 36850 = 43250 МПа² σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = −18425 МПа²
U₀ = [43250 − 2·0,3·(−18425)] / (2·2,1·10⁵) = = (43250 + 11055) / 4,2·10⁵ = 54305 / 4,2·10⁵ = 0,1293 МПа

Энергия изменения формы

U₀ф = (1 + ν)/(6E) · [(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²]
σ₁ − σ₂ = 113,1101 МПа; σ₂ − σ₃ = 171,6544 МПа; σ₃ − σ₁ = −284,7646 МПа (σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)² = 2·(I₁н² − 3·I₂н) = 2·(6400 + 55275) = 123350 МПа² контроль по корням: 113,1101² + 171,6544² + 284,7646² = 123350,0 — сходится U₀ф = 1,3/(6·2,1·10⁵)·123350 = 1,3·123350 / 1,26·10⁶ = 0,12727 МПа

Энергия изменения объёма

U₀об = U₀ − U₀ф = 0,12930 − 0,12727 = 0,00203 МПа проверка по независимой формуле: U₀об = (1 − 2ν)/(6E)·I₁н² = 0,4·6400/1,26·10⁶ = 0,00203 МПа — совпало точно

Вывод

U₀ = 0,1293 МПа > U₀ф = 0,12727 МПа. На формоизменение уходит 98,4 % всей энергии, на изменение объёма — 1,6 %: состояние близко к чистому сдвигу.

Почему не 0,13018. Ту же энергию можно записать через компоненты: U₀ = 1/(2E)·[σx²+σy²+σz² − 2ν(σxσy+σyσz+σzσx)] + 1/(2G)·(τxy²+τyz²+τzx²). При G = 0,8·10⁵ из задания выйдет 0,03752 + 0,09266 = 0,13018 МПа. Разница в том, что G в задании округлён: согласованное с E и ν значение G = E/[2(1+ν)] = 0,80769·10⁵ МПа даёт 0,03752 + 0,09177 = 0,1293 МПа — ровно то же, что и по главным напряжениям. Формула по главным напряжениям от G не зависит, поэтому в отчёт идёт 0,1293 МПа, а 0,13018 — та же величина с округлённым G (расхождение 0,68 %).

8. Проверка прочности по IV (энергетической) теории

Формулировка. Опасное состояние наступает тогда, когда удельная энергия формоизменения достигает того же значения, что и в момент наступления опасного состояния при простом одноосном напряжённом состоянии. Используется модель Фёппля — Мизеса.

σэквIV = (1/√2)·√[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²] ≤ R·γc
σэквIV = (1/√2)·√123350 = √61675 = 248,34 МПа R·γc = 210·0,9 = 189,0 МПа

Условие прочности не выполняется

σэквIV = 248,34 МПа > R·γc = 189,0 МПа — расчётное напряжение превышает предельное в 1,314 раза, то есть на 31,4 %. Прочность тела в окрестности рассматриваемой точки не обеспечена: требуется снизить уровень напряжений либо применить сталь с более высоким расчётным сопротивлением R.

По закону парности τxy = τyx = −30 МПа. Для двухосного состояния тензор вырождается в матрицу 2×2:

Tн = σxτxyτyxσy = −85−30−30−30 [МПа]

Плоское напряжённое состояние возникает в тонкой пластине, размеры которой в плане много больше толщины (h ≪ a, b), нагруженной силами, лежащими в её плоскости. На площадках с нормалью z, то есть на лицевых поверхностях пластины, нагрузки нет, поэтому σz = 0 и τzx = τzy = 0; из-за малой толщины это справедливо и внутри пластины.

Оба нормальных напряжения отрицательны, поэтому стрелки направлены к граням (сжатие); касательные напряжения тоже отрицательны и потому направлены противоположно положительному направлению осей. Так как из шести компонент отличны от нуля только три, элемент достаточно изобразить плоским — проекцией на плоскость xOy.

2. Главные напряжения

Используем то же кубическое уравнение (1):

I₁н = σx + σy = −85 + (−30) = −115 МПа I₂н = σx·σy − τxy² = (−85)·(−30) − (−30)² = 2550 − 900 = 1650 МПа² I₃н = 0 — при двухосном состоянии третьего инварианта нет

Уравнение распадается:

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0

Корень σ = 0 отвечает площадке с нормалью z: по условию на ней нет ни нормальных, ни касательных напряжений, значит ось z — главная. Квадратное уравнение даёт два оставшихся корня:

σ1,2 = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²]
(σx + σy)/2 = (−85 − 30)/2 = −57,5 МПа (σx − σy)/2 = (−85 + 30)/2 = −27,5 МПа √[(−27,5)² + (−30)²] = √(756,25 + 900) = √1656,25 = 40,6971 МПа σ′ = −57,5 + 40,70 = −16,80 МПа σ″ = −57,5 − 40,70 = −98,20 МПа

Располагаем все три корня от большего к меньшему (σ₁ ≥ σ₂ ≥ σ₃):

Главные напряжения

3. Углы наклона главных площадок к оси x

На главной площадке касательных напряжений нет, поэтому для двухосного состояния условия на нормали дают систему:

(σx − σi)·li + τxy·mi = 0(a) τyx·li + (σy − σi)·mi = 0(b)

где li = cos(σi^x), mi = cos(σi^y). Ось y направлена вниз, поэтому

li = cos αi; mi = cos(αi + 90°) = −sin αi

Подставляем в (b) и делим на cos αi:

τyx·cos αi − (σy − σi)·sin αi = 0 → tg αi = τyx / (σy − σi)(5)
при i = 2 (σ₂ = −16,80 МПа): tg α₂ = −30 / (−30 + 16,8029) = −30 / (−13,1971) = 2,2732 → α₂ = +66,26° при i = 3 (σ₃ = −98,20 МПа): tg α₃ = −30 / (−30 + 98,1971) = −30 / 68,1971 = −0,4399 → α₃ = −23,74°
