# Функции и их свойства — план занятия на 90 минут

**Запрос ученика:** «позанимаемся функциями и их описанием», учебник Алимова, 10–11 класс.
**Где в учебнике:** глава II «Степенная функция», §6 «Степенная функция, её свойства и график» (с. 39) и начало §7 «Взаимно обратные функции». Схема описания функции из этого занятия дальше работает во всех главах: показательная, логарифмическая, тригонометрические функции.
**Уровень:** 10 класс, первая встреча со «взрослым» описанием функции. Опирается на функции 7–9 класса: `y = kx + b`, `y = ax² + bx + c`, `y = k/x`, `y = √x`, `y = |x|`.

> **Сверьте номера параграфов по своему изданию.** Тексты учебника из среды, где готовился материал, недоступны; номера §6 и §7 подтверждены оглавлением издания «Просвещения», остальное — по структуре учебника. Если ученик в 11 классе и под «функциями» имеет в виду тригонометрические (глава «Тригонометрические функции»), схема та же, меняются только примеры.

## Обозначения — как у Алимова

Алимов почти всегда пишет промежутки **неравенствами**, а не скобками. Держимся этого, а в ответах даём оба вида, чтобы ученик узнавал запись из интернета и ОГЭ-сборников.

| У Алимова | Часто пишут иначе | Что это |
|---|---|---|
| «область определения: x ≥ 0» | `D(f) = [0; +∞)`, `D(y)` | при каких `x` формула имеет смысл |
| «множество значений: y ≥ 0» | `E(f) = [0; +∞)`, «область значений» | какие `y` функция принимает |
| «возрастает на промежутке x ≥ 0» | «возрастает на `[0; +∞)`», `f↑` | промежуток возрастания |
| «множество R» | `ℝ`, `(−∞; +∞)` | все действительные числа |
| `x^(1/3)` определена при `x ≥ 0` | в части источников `x^(1/3) = ∛x` при всех `x` | см. ловушку в блоке A |

**Что ученик должен уметь к концу занятия:**

1. отличать функцию от «не функции» (по правилу и по графику);
2. находить область определения по формуле;
3. находить множество значений, нули и промежутки знакопостоянства;
4. проверять чётность в два шага — сначала область определения, потом `f(−x)`;
5. указывать промежутки возрастания и убывания и знать шесть случаев степенной функции `y = xᵖ`;
6. описывать функцию по схеме из семи пунктов — по графику и по формуле.

**Нужно на уроке:** лист в клетку, карандаш, линейка. Калькулятор не нужен.

## Вход (0–5). Что такое функция

**Говорим ученику:**

> Функция — это правило, которое каждому допустимому `x` даёт **ровно одно** `y`. Не «формула» — формула только один из способов задать правило. Сегодня научимся по формуле или по графику рассказывать о функции всё: где она живёт, какие значения принимает, где растёт и где падает. Это и называется «описать функцию».

Способы задания: формулой, графиком, таблицей, словами.

**Четыре устных вопроса — функция или нет:**

1. Каждому ученику класса сопоставлен его рост. → **функция**: у человека один рост.
2. Каждому числу `x` сопоставлены числа, квадрат которых равен `x`. → **не функция**: числу 4 соответствуют сразу 2 и −2.
3. Каждому натуральному числу сопоставлена его последняя цифра. → **функция**: разные числа могут дать одну цифру, это разрешено.
4. Задаёт ли уравнение `x² + y² = 25` переменную `y` как функцию `x`? → **нет**: при `x = 3` получаем `y = 4` и `y = −4`.

**Проверка по графику:** любая вертикальная прямая пересекает график функции не больше чем в одной точке. Окружность из вопроса 4 эту проверку не проходит.

Вопрос 3 важен: ученики путают «одному `x` одно `y`» с «одному `y` одно `x`». Второе функции не требуется.

## Входная диагностика (5–12)

```
1. f(x) = x² − 3x. Найдите f(−2).
2. Найдите область определения функции y = 1/(x − 4).
3. Найдите область определения функции y = √(x + 3).
4. Найдите нули функции y = x² − 9.
5. Найдите множество значений функции y = x² + 2.
6. Является ли чётной функция y = x⁴ + 1?
7. Возрастает или убывает функция y = −2x + 5?
8. Принадлежит ли точка (−2; −8) графику функции y = x³?
```

**Ответы:** 1) 10 2) x ≠ 4 3) x ≥ −3 4) −3; 3 5) y ≥ 2 6) да, чётная 7) убывает на всей числовой прямой 8) да, `(−2)³ = −8`

**Как читать результат:**
- ошибка в 1 или 8 → нет понятия «значение функции», начинаем с него и не торопимся;
- ошибка в 2–3 → блок A полностью;
- ошибка в 4–5 → в блоке B главное — не путать нули с множеством значений;
- ошибка в 6 → блок C с самого определения;
- ошибка в 7 → в блоке D повторить линейную функцию: знак `k` решает всё;
- всё верно за 5 минут → блоки A–C бегло, время отдаём блокам D и E.

## Блок A. Область определения (12–24)

**Область определения** — все значения `x`, при которых формула имеет смысл. Если функция задана графиком — проекция графика на ось `Ox`.

### Что может «сломать» формулу в 10 классе

```
дробь                          знаменатель ≠ 0
√ (и корень любой чётной степени)   подкоренное выражение ≥ 0
√ в знаменателе                подкоренное выражение > 0
x⁻ⁿ = 1/xⁿ                     x ≠ 0
xᵖ, p > 0 нецелое              x ≥ 0          ← по Алимову, §6
xᵖ, p < 0 нецелое              x > 0          ← по Алимову, §6
∛ и корни нечётной степени     ограничений нет
```

Условий несколько — выполняться должны **все сразу**: пишем систему.

### Ловушка учебника: `∛x` и `x^(1/3)` — разные функции

У Алимова степень с нецелым показателем определена только для неотрицательного основания. Поэтому `y = ∛x` определена при всех `x`, а `y = x^(1/3)` — только при `x ≥ 0`. Задачи A10–A11 и C14–C15 стоят парами именно ради этого. В других источниках встречается иное соглашение — ученику достаточно знать, что в его учебнике так.

### Разбор на доске

```
y = √(x + 2) + 1/(x − 3)

корень:  x + 2 ≥ 0   →  x ≥ −2
дробь:   x − 3 ≠ 0   →  x ≠ 3
вместе:  x ≥ −2, x ≠ 3          [−2; 3) ∪ (3; +∞)
```

Проговорить: «нашёл одно условие — ищу следующее». Вторую половину теряют чаще всего (ошибка Э1).

### Практика — 14 задач (8 минут)

```
 1. y = 3x − 7                  8. y = x^(2/5)
 2. y = 5/(x + 2)               9. y = x^(−1/2)
 3. y = (x + 1)/(x² − 16)      10. y = ∛(x − 8)
 4. y = √(6 − 2x)              11. y = (x − 8)^(1/3)
 5. y = √(x² − 25)             12. y = √(x + 2) + 1/(x − 3)
 6. y = 1/√(x − 1)             13. y = √x + √(4 − x)
 7. y = x⁻³                    14. y = (x − 5)/(x² + 4)
```

**Ответы:** 1) R 2) x ≠ −2 3) x ≠ −4, x ≠ 4 4) x ≤ 3 5) x ≤ −5 или x ≥ 5 6) x > 1 7) x ≠ 0 8) x ≥ 0 9) x > 0 10) R 11) x ≥ 8 12) x ≥ −2, x ≠ 3 13) 0 ≤ x ≤ 4 14) R

**№ 14 — ловушка:** ученик видит дробь и ищет, что исключить. Но `x² + 4 ≥ 4`, знаменатель нулём не бывает, ответ — все числа.
**№ 5** требует квадратного неравенства. Если застрял — нарисовать параболу `y = x² − 25` и посмотреть, где она выше оси.

## Блок B. Значения, нули, знаки (24–36)

### Четыре вопроса к функции

```
значение f(a)            подставить a вместо x
нули функции             решить f(x) = 0 и проверить, что корни входят в область определения
знаки                    где f(x) > 0, где f(x) < 0 — метод интервалов
множество значений       какие y получаются; по графику — проекция на ось Oy
```

### Как искать множество значений без графика

```
x² ≥ 0,  √x ≥ 0,  |x| ≥ 0          → «отсюда снизу не бывает меньше…»
парабола: вершина x₀ = −b/(2a), y₀ = f(x₀)
          a > 0 → y ≥ y₀;   a < 0 → y ≤ y₀
k/x ≠ 0 никогда                     → y = k/x + b не принимает значение b
```

### Разбор на доске

```
y = (x² − 9)/(x − 3)

x² − 9 = 0  →  x = −3  или  x = 3
x = 3 не входит в область определения (знаменатель 0)
нуль функции один: x = −3
```

### Практика — 16 задач (10 минут)

```
Значения
 1. f(x) = 2x² − x. Найдите f(3), f(−1), f(1/2).
 2. f(x) = x² − 2x. При каких x значение f(x) равно 3?
 3. f(x) = √(x + 5). При каком x значение f(x) равно 4?

 4. y = x² − 5x + 6          7. y = (x + 4)·√(x − 1)
 5. y = x³ − 4x              8. y = x² + 1
 6. y = (x² − 9)/(x − 3)

Множество значений
 9. y = x² − 4              12. y = 3 − √x
10. y = −x² + 6x            13. y = 1/x + 1
11. y = √x + 2              14. y = 5 − x⁴

```

**Ответы:**
1) 15; 3; 0 2) x = −1 или x = 3 3) x = 11
4) 2; 3 5) −2; 0; 2 6) −3 7) 1 8) нулей нет

**№ 6 и № 7** — нули за пределами области определения. В № 7 множитель `x + 4` обнуляется при `x = −4`, но там корень `√(−5)` не существует.
**№ 13:** ученик пишет «все числа». Спросить: может ли `1/x` равняться нулю? Нет — значит, `y` никогда не равен 1.

## Блок C. Чётность и нечётность (36–48)

### Определения

```
чётная:    f(−x) = f(x)    для всех x из области определения
нечётная:  f(−x) = −f(x)   для всех x из области определения
```

График чётной функции симметричен относительно оси `Oy`, нечётной — относительно начала координат.

### Алгоритм — строго в два шага

```
Шаг 1. Симметрична ли область определения относительно нуля?
       (вместе с каждым x в неё входит −x?)
       НЕТ  →  функция ни чётная, ни нечётная. Стоп, шаг 2 не нужен.
Шаг 2. Найти f(−x), упростить и сравнить с f(x) и с −f(x).
```

**Шаг 1 пропускают почти все.** `y = x²` на отрезке `−2 ≤ x ≤ 3` не чётная: `f(3)` есть, а `f(−3)` не существует.

### Проверка на числах

Одна пара `f(1)` и `f(−1)` может **опровергнуть** чётность, но **не доказать** её. `f(x) = x³ + x² − x`: `f(1) = f(−1) = 1`, но `f(2) = 10`, а `f(−2) = −2`. Это задача Н4.

### Практика — 16 задач (10 минут)

```
 1. y = x⁶ − 3x²              9. y = x², −2 ≤ x ≤ 3
 2. y = x⁵ + x               10. y = (x + 1)²
 3. y = x³ + 1               11. y = x³/(x² + 1)
 4. y = 2/x                  12. y = x⁴ − x³
 5. y = x²/(x² − 4)          13. y = (x − 2)/(x + 2)
 6. y = |x| + x²             14. y = x^(2/3)
 7. y = x·|x|                15. y = ∛(x²)
 8. y = √x

16. Функция задана на отрезке 0 ≤ x ≤ 4 ломаной через точки (0; 0), (2; 3), (4; 1).
    Достройте её график на отрезке −4 ≤ x ≤ 0, если функция а) чётная; б) нечётная.
```

**Ответы:** 1) чётная 2) нечётная 3) ни та ни другая 4) нечётная 5) чётная 6) чётная 7) нечётная 8) ни та ни другая (область x ≥ 0 несимметрична) 9) ни та ни другая (область несимметрична) 10) ни та ни другая 11) нечётная 12) ни та ни другая 13) ни та ни другая (область x ≠ −2 несимметрична) 14) ни та ни другая (по Алимову область x ≥ 0) 15) чётная

**№ 13** — одна выколотая точка `x = −2` ломает симметрию: `f(2) = 0` есть, `f(−2)` нет.
**№ 14 и № 15** — формулы «про одно и то же», а ответы разные. Возвращаемся к ловушке блока A.

## Блок D. Монотонность, ограниченность, степенная функция (48–64)

### Определения

```
возрастает на промежутке:  x₂ > x₁  ⇒  f(x₂) > f(x₁)   (больше x — больше y)
убывает на промежутке:     x₂ > x₁  ⇒  f(x₂) < f(x₁)   (больше x — меньше y)
ограничена снизу:  есть число m, что f(x) ≥ m при всех x
ограничена сверху: есть число M, что f(x) ≤ M при всех x
```

### Знакомые функции

```
y = kx + b     k > 0 — возрастает на R;  k < 0 — убывает на R
y = ax² + …    ветви вверх: убывает до вершины, возрастает после; ветви вниз — наоборот
y = k/x, k > 0 убывает при x < 0 и убывает при x > 0 — но НЕ на всей области определения!
```

Последняя строка — ошибка Э6. Контрпример: `−1 < 1`, но `4/(−1) = −4 < 4 = 4/1`. Промежутки монотонности через `∪` не объединяют.

### Степенная функция `y = xᵖ` (§6)

| Показатель `p` | Область определения | Множество значений | Чётность | Монотонность | Пример |
|---|---|---|---|---|---|
| чётное натуральное | R | y ≥ 0 | чётная | убывает при x ≤ 0, возрастает при x ≥ 0 | `x⁴` |
| нечётное натуральное | R | R | нечётная | возрастает на R | `x³` |
| отрицательное чётное | x ≠ 0 | y > 0 | чётная | возрастает при x < 0, убывает при x > 0 | `x⁻²` |
| отрицательное нечётное | x ≠ 0 | y ≠ 0 | нечётная | убывает при x < 0 и при x > 0 | `x⁻¹` |
| положительное нецелое | x ≥ 0 | y ≥ 0 | ни та ни другая | возрастает при x ≥ 0 | `x^(1/2)` |
| отрицательное нецелое | x > 0 | y > 0 | ни та ни другая | убывает при x > 0 | `x^(−1/2)` |

Все графики проходят через точку `(1; 1)`. Таблицу не зубрить: каждая строка восстанавливается по одному эскизу.

### Сравнение чисел через монотонность

Возрастающая функция **сохраняет** знак неравенства, убывающая — **меняет**.

```
Сравнить 0,7⁻³ и 0,8⁻³.
y = x⁻³ убывает при x > 0;  0,7 < 0,8  ⇒  0,7⁻³ > 0,8⁻³
```

Проговорить три шага: какая функция → на каком промежутке лежат оба числа → возрастает или убывает там.
