# Задание 19 профильного ЕГЭ-2027: первые задачи с параметром

Для ученицы, которая на занятии разобрала самые лёгкие параметры и теперь учится решать их сама.

| Файл | Что внутри |
|---|---|
| `Параметры, первые шаги — разбор.pdf` | как думать о параметре, 8 примеров с подробным решением и чертежами, типичные ошибки, видео |
| `Параметры, первые шаги — задачи ученику.pdf` | 20 задач-аналогов по тем же типам + 3 «найди ошибку», без ответов |
| `Параметры, первые шаги — задачи с ответами.pdf` | то же с ответом под каждой задачей |
| `razbor.html`, `zadachi.html` | версии ученику для публикации как Artifact |
| `OTVETY.md` | ответы и где ждать ошибок |
| `sborka.py`, `proverka.py` | сборка и проверка перебором параметра |

## Типы (одинаковые в разборе и задачах)

1. Линейное уравнение `kx = b`: три случая.
2. Квадратное, параметр при x²: сначала случай A = 0.
3. Произведение с корнем, дробь: кандидаты, ОДЗ, совпадения, выколотые точки.
4. Графический метод `f(x) = a`: горизонтальная прямая.
5. Вращающаяся прямая через фиксированную точку.
6. Окружность и прямая: расстояние от центра или дискриминант.
7. Лёгкая задача уровня ЕГЭ: всё вместе.

Условия — в `sborka.py`.
