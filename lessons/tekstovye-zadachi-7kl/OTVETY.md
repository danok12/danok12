## Найди ошибку

- **А.** Минуты смешаны с км/ч: 40 мин = 2/3 ч. `(2/3)x + 2(x + 6) = 52` → `x = 15` км/ч.
- **Б.** 20 % отнимали от старой цены: `0,8x = 8000` → `x = 10 000`. Проверка ответа 9600: 9600 − 20 % = 7680 ≠ 8000.
- **В.** Ответ не на тот вопрос: 14 — скорость медленного, быстрого 20 км/ч.

## Квадратное уравнение

- Разминка: а) D = 4, корни 3 и 5; б) D = 49, корни 1,5 и −2; в) D = 0, корень 3.
- Разбор: `x² + 6x − 432 = 0`, D = 1764, x = 18 (−24 отброшен).
- «Попробуй сам»: `x` — скорость второго; `180/x − 180/(x + 15) = 1` → `x² + 15x − 2700 = 0`, D = 11 025, √D = 105, x = 45 (−60 отброшен). **Ответ: 60 км/ч** (скорость первого). Проверка: 4 ч и 3 ч. Подбором: 45 · 60 = 2700.
