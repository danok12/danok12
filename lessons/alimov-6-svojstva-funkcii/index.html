О чём занятие

Запрос ученика: «позанимаемся функциями и их описанием», учебник Алимова 10–11. В учебнике это глава II «Степенная функция»: §6 «Степенная функция, её свойства и график» и начало §7 «Взаимно обратные функции». Схема описания функции отсюда дальше работает во всех главах: показательная, логарифмическая, тригонометрические функции.

Главная мысль занятия

Описать функцию — значит ответить на семь вопросов, всегда в одном порядке. Кто знает вопросы, тот описывает любую функцию, даже незнакомую. Кто учит свойства каждой функции отдельно, путается уже на третьей.

Схема описания функции
  1. Область определенияпри каких x формула имеет смысл; по графику — проекция на ось Ox
  2. Множество значенийкакие y функция принимает; по графику — проекция на ось Oy
  3. Чётность или нечётностьсимметрия графика относительно оси Oy или начала координат
  4. Нулипри каких x значение равно нулю; точки пересечения с осью Ox
  5. Промежутки знакопостоянствагде y > 0 и где y < 0
  6. Промежутки возрастания и убываниягде график идёт вверх и где вниз, если смотреть слева направо
  7. Наибольшее и наименьшее значения; ограниченностьсамая высокая и самая низкая точки графика, если они есть

Периодичность появится в тригонометрии, точки максимума и минимума — в главе о производной.

0–5 мин

Что такое функция

Говорим ученику Функция — это правило, которое каждому допустимому x даёт ровно одно y. Не «формула»: формула только один из способов задать правило. Сегодня научимся по формуле или по графику рассказывать о функции всё — где она живёт, какие значения принимает, где растёт и где падает.
Определение

Функция — правило, по которому каждому значению x из некоторого множества ставится в соответствие единственное число y. Пишут y = f(x); x — аргумент, y — значение функции.

Задать функцию можно формулой, графиком, таблицей или словами. Проверка по графику: любая вертикальная прямая пересекает график функции не больше чем в одной точке.

Разминка: функция или нет?

  1. Каждому ученику класса сопоставлен его рост.
  2. Каждому числу x сопоставлены числа, квадрат которых равен x.
  3. Каждому натуральному числу сопоставлена его последняя цифра.
  4. Задаёт ли уравнение x² + y² = 25 переменную y как функцию x?
Ответы

1) функция: у человека один рост   2) не функция: числу 4 соответствуют 2 и −2   3) функция: разные числа могут дать одну цифру, это разрешено   4) нет: при x = 3 получаем y = 4 и y = −4

Вопрос 3 важен: ученики путают «одному x одно y» с «одному y одно x». Второе функции не требуется.

Ловушка учебника: ∛x и x1/3 — разные функции

У Алимова степень с нецелым показателем определена только для неотрицательного основания. Поэтому y = ∛x определена при всех x, а y = x1/3 — только при x ≥ 0. Задачи A10–A11 и C14–C15 стоят парами именно ради этого.

Разбор на доске

y = √(x + 2) + 1/(x − 3)

корень: x + 2 ≥ 0 → x ≥ −2 дробь: x − 3 ≠ 0 → x ≠ 3 вместе: x ≥ −2, x ≠ 3 [−2; 3) ∪ (3; +∞)

Проговорить: «нашёл одно условие — ищу следующее». Вторую половину теряют чаще всего (ошибка Э1).

Блок C. Чётность и нечётность

Определения
чётнаяf(−x) = f(x) для всех x из области определения; график симметричен относительно оси Oy нечётнаяf(−x) = −f(x) для всех x из области определения; график симметричен относительно начала координат
Алгоритм — строго в два шага
Шаг 1. Симметрична ли область определения относительно нуля? (вместе с каждым x в неё входит −x?) НЕТ → ни чётная, ни нечётная. Стоп, шаг 2 не нужен. Шаг 2. Найти f(−x), упростить, сравнить с f(x) и с −f(x).

Шаг 1 пропускают почти все. y = x² на отрезке −2 ≤ x ≤ 3 не чётная: f(3) есть, а f(−3) не существует.

Числа опровергают, но не доказывают

Одна пара f(1) и f(−1) может опровергнуть чётность, но доказать её не может. У f(x) = x³ + x² − x значения f(1) = f(−1) = 1, а f(2) = 10 и f(−2) = −2.

Промежутки монотонности не склеивают

y = 4/x убывает на каждом из промежутков x < 0 и x > 0, но не на всей области определения: −1 < 1, а 4/(−1) = −4 < 4 = 4/1. Запись «убывает на (−∞; 0) ∪ (0; +∞)» — ошибка.

Сравнение чисел через монотонность

Возрастающая функция сохраняет знак неравенства, убывающая — меняет.

Н1. Область определения y = √(x + 2) + 1/(x − 3)

x + 2 ≥ 0, значит x ≥ −2. Ответ: x ≥ −2.

Разбор

Потеряно второе условие: дробь требует x ≠ 3. Верно: x ≥ −2, x ≠ 3.

Н2. Нули функции y = (x² − 9)/(x − 3)

x² − 9 = 0, x = ±3. Ответ: −3; 3.

Разбор

x = 3 обнуляет знаменатель и в область определения не входит. Верно: один нуль x = −3.

Н3. Множество значений y = √(x − 5)

Подкоренное выражение неотрицательно: x − 5 ≥ 0, x ≥ 5. Ответ: x ≥ 5.

Разбор

Найдена область определения, а спрашивали значения. Квадратный корень принимает все неотрицательные значения: y ≥ 0.

Н4. Чётна ли f(x) = x³ + x² − x?

f(1) = 1 + 1 − 1 = 1, f(−1) = −1 + 1 + 1 = 1. Так как f(−1) = f(1), функция чётная.

Разбор

Одна пара чисел чётность не доказывает: f(2) = 10, а f(−2) = −2. f(−x) = −x³ + x² + x не совпадает ни с f(x), ни с −f(x). Верно: ни та ни другая.

Н5. Чётна ли y = x², −2 ≤ x ≤ 3?

(−x)² = x², значит f(−x) = f(x), функция чётная.

Разбор

Пропущен шаг 1: область −2 ≤ x ≤ 3 несимметрична — f(3) = 9 есть, f(−3) нет. Верно: ни та ни другая.

Н6. Промежутки монотонности y = 4/x

Гипербола в первой и третьей четвертях убывает. Ответ: убывает на всей области определения, то есть при x ≠ 0.

Разбор

Промежутки склеены. −1 < 1, но f(−1) = −4 < 4 = f(1) — определение убывания нарушено. Верно: убывает при x < 0 и при x > 0, каждый промежуток отдельно.

Н7. Описать y = (x + 3)² − 2

Парабола y = x², сдвинутая на 3 вправо и на 2 вниз. Вершина (3; −2), наименьшее значение −2 при x = 3.

Разбор

x + 3 — сдвиг влево. Вершина (−3; −2), наименьшее −2 при x = −3. Проверка подстановкой: f(3) = 36 − 2 = 34, а не −2.

Н8. Сравнить (−5)⁻³ и (−4)⁻³

y = x⁻³ убывает при x < 0. Так как −5 < −4, то (−5)⁻³ < (−4)⁻³.

Разбор

Убывающая функция меняет знак неравенства: (−5)⁻³ > (−4)⁻³. Проверка: −1/125 = −0,008, −1/64 = −0,015625, и −0,008 > −0,015625.
