# Обратная матрица — каталог ошибок и задачи «найди ошибку»

Файл для преподавателя. Обозначения учебника: `|A|`, `A'`, `Ã`.

> **Одно правило важнее всех задач.** В этой теме ответ проверяется умножением: `A·A⁻¹` обязано дать `E`. Ученик, который делает проверку, не может сдать неверное решение — он ловит себя сам. Почти каждая ошибка ниже переживает решение только потому, что проверку пропустили.

---

## Часть 1. Каталог ошибок

### Э1. Обращает матрицу поэлементно

**Как выглядит:** `A = |2 5; 1 3|` → `A⁻¹ = |1/2 1/5; 1 1/3|`.
**Откуда:** значок `⁻¹` читается как «единица делить на», и рука сама делит каждое число.
**Как поймать:** умножить на исходную: `2·½ + 5·1 = 6` вместо единицы.
**Что сказать:** `A⁻¹` — это *имя* матрицы, а не операция над её клетками. В определении сказано только одно: произведение должно дать `E`.
**Антидот:** Тема 1, Тема 3.

### Э2. Умножает не с той стороны

**Как выглядит:** `X·A = B` решает как `X = A⁻¹·B`.
**Откуда:** у чисел `xa = b` даёт `x = b/a`, и сторона не важна. У матриц `AB ≠ BA`.
**Как поймать:** по размерам. Если `B` — строка `1×2`, то `A⁻¹·B` вида `(2×2)·(1×2)` вообще не существует.
**Что сказать:** «обратная лечит соседа» — смотри, с какой стороны от `X` стоит `A`, с той же и умножай.
**Антидот:** Тема 8 (особенно 8.2 и 8.3).

### Э3. Транспонирует дважды или ни разу

**Как выглядит:** берёт `A'`, считает дополнения и «на всякий случай» транспонирует ещё раз. Либо считает дополнения самой `A` и на этом останавливается.
**Откуда:** учебник транспонирует **до** дополнений, интернет и большинство задачников — **после**. Ученик видит оба рецепта и складывает их.
**Как поймать:** проверка даёт симметрично неправильную матрицу; у несимметричной `A` ответ вдруг вышел симметричным.
**Что сказать:** транспонирование встречается **ровно один раз**. Выбери маршрут и держись:
```
учебник:  A → A' → дополнения → Ã
другие:   A → дополнения → транспонировать → Ã
```
**Антидот:** Тема 4, задача Н2.

### Э4. Останавливается на присоединённой матрице

**Как выглядит:** в ответе `Ã` — правильная, но не поделённая на `|A|`.
**Откуда:** шаг 3° самый долгий; когда он закончен, кажется, что закончена и задача.
**Как поймать:** проверка даёт `|A|·E` — на диагонали стоит сам определитель.
**Что сказать:** одинаковые числа на диагонали в проверке — подпись именно этой ошибки.
**Антидот:** задача Н3, Тема 6.

### Э5. Теряет знаки алгебраических дополнений

**Как выглядит:** дополнения посчитаны как чистые миноры, множитель `(-1)^(i+j)` забыт у четырёх элементов из девяти.
**Как поймать:** не ловить, а предотвращать — писать знак **перед скобкой до** арифметики.
**Что сказать:** нарисуй шахматную доску `+ − + / − + − / + − +` в углу листа и не стирай до конца задачи.
**Антидот:** Тема 4 — она тренирует только дополнения.

### Э6. Плюсует все три слагаемых в определителе 3×3

**Как выглядит:** `|A| = a₁₁M₁₁ + a₁₂M₁₂ + a₁₃M₁₃` вместо `a₁₁M₁₁ − a₁₂M₁₂ + a₁₃M₁₃`.
**Почему худшая ошибка темы:** портит всё решение, потому что `|A|` стоит в знаменателе.
**Что сказать:** разложение по строке — те же знаки шахматной доски, её первая строка `+ − +`.
**Антидот:** Тема 2, задача Н5.

### Э7. Делит на определитель не все элементы

**Как выглядит:** поделена только первая строка; либо множитель `1/|A|` вынесен и потом потерян.
**Как поймать:** в проверке сходится одна строка, остальные нет.
**Что сказать:** не раскрывай дроби — пиши ответ как `(1/5)·| … |`, тогда делить нечего и терять нечего.
**Антидот:** Тема 6.

### Э8. Считает дроби признаком ошибки

**Как выглядит:** получает `1/5`, решает, что «так не бывает», и ломает верное решение пересчётом.
**Откуда:** на уроках примеры нарочно берут с `|A| = ±1`.
**Что сказать:** целый ответ бывает ровно при `|A| = ±1`, во всех остальных случаях дроби обязаны появиться.
**Антидот:** Тема 6 — там дробный ответ в каждой задаче.

### Э9. Изобретает несуществующие формулы

```
(A + B)⁻¹ = A⁻¹ + B⁻¹      ← такой формулы НЕТ
(A · B)⁻¹ = A⁻¹ · B⁻¹      ← порядок обязан смениться
(2A)⁻¹    = 2A⁻¹           ← на самом деле ½·A⁻¹
```
**Как поймать:** подставить `A = B = E`. Для суммы слева `½E`, справа `2E`.
**Что сказать:** любую сомнительную формулу проверяй на `E` и на диагональных матрицах.
**Антидот:** Тема 7.

### Ещё три, пореже

- **Ищет обратную у прямоугольной матрицы.** Вопрос: какого размера `A·A⁻¹` и какого `A⁻¹·A`? Они обязаны совпасть.
- **Получил `|A| = 0` и продолжает считать.** Определитель считается первым именно чтобы остановиться.
- **Вычёркивает не ту строку или столбец.** Признак — в миноре остался сам элемент `aᵢⱼ`. Лечится пальцем: физически закрыть строку и столбец рукой.

## Часть 2. Найди ошибку

Задание всегда одно: **не решай заново — найди, на каком шаге сломалось, и объясни почему.** По три минуты на задачу.

### Н1

`A = |2 5; 1 3|`, решение: `A⁻¹ = |1/2 1/5; 1 1/3|`.

**Разбор.** Ошибка Э1. `(A·X)₁₁ = 2·(1/2) + 5·1 = 6 ≠ 1`. Верно: `|A| = 1`, `A⁻¹ = |3 −5; −1 2|`.

### Н2

```
A = | 1  2  3 |     |A| = 1,   решение:  A⁻¹ = | -24   20   -5 |
    | 0  1  4 |                                |  18  -15    4 |
    | 5  6  0 |                                |   5   -4    1 |
```
Все девять дополнений посчитаны верно, но ответ неправильный. Почему?

**Разбор.** Ошибка Э3: матрицу дополнений не транспонировали. Проверка:
```
A · X = |  27  -22   6 |
        |  38  -31   8 |   ≠ E
        | -12   10  -1 |
```
Верный ответ — та же матрица, транспонированная: `| -24 18 5 ; 20 -15 -4 ; -5 4 1 |`.
**Ценность задачи:** показывает, что «все вычисления верны» и «ответ верен» — разные вещи.

### Н3

```
A = | 1  -1   1 |    |A| = 5,   решение:  A⁻¹ = |  1   3  -2 |
    | 2   1   1 |                               | -3   1   1 |
    | 1   1   2 |                               |  1  -2   3 |
```

**Разбор.** Ошибка Э4: в ответе стоит `Ã`, шаг 4° пропущен. Проверка даёт подпись ошибки:
```
A · Ã = | 5  0  0 |
        | 0  5  0 |  = 5·E = |A|·E
        | 0  0  5 |
```
Верно: `(1/5)·Ã`. **Вопрос ученику:** что стояло бы на диагонали, будь `|A| = 7`?

### Н4

```
Решить X·A = B,  A = | 2  5 |,  B = | 1  2 |  (строка)
                     | 1  3 |

Решение:  X = A⁻¹·B = | 3  -5 | · | 1  2 | = ...
                      | -1  2 |
```

**Разбор.** Ошибка Э2, и ловится до всякого счёта: `(2×2)·(1×2)` не перемножаются, выражение не существует. `A` стоит справа от `X`, значит и `A⁻¹` идёт справа: `X = B·A⁻¹ = |1 −1|`.
Проверка: `|1 −1|·|2 5; 1 3| = |1 2|` ✓

### Н5

```
A = | 1  -1   1 |
    | 2   1   1 |
    | 1   1   2 |

|A| = 1·(1·2 - 1·1) + (-1)·(2·2 - 1·1) + 1·(2·1 - 1·1) = 1 - 3 + 1 = -1
```

**Разбор.** Ошибка Э6: у среднего слагаемого не поставлен минус разложения. Верно:
```
|A| = 1·(1·2 - 1·1) - (-1)·(2·2 - 1·1) + 1·(2·1 - 1·1) = 1 + 3 + 1 = 5
```
Два минуса — минус разложения и минус самого элемента `a₁₂ = −1` — дают плюс; ученик увидел один и решил, что это и есть «тот самый» знак.
**Почему худшая:** дальше всё будет верно, но поделят на `−1` вместо `5`.

### Н6

```
|A| = 6,  Ã = |  4  -2   1 |    решение:  A⁻¹ = | 4/6  -2/6  1/6 |
              | -2   4  -2 |                    |  -2     4   -2 |
              |  2  -4   5 |                    |   2    -4    5 |
```

**Разбор.** Ошибка Э7: поделена только первая строка. В проверке первая строка сойдётся, остальные нет.
Лекарство: писать `A⁻¹ = (1/6)·| 4 −2 1 ; −2 4 −2 ; 2 −4 5 |` и не раскрывать дробь.

## Часть 3. Что давать, если увидел ошибку

| Что сделал ученик | Ошибка | Что дать |
|---|---|---|
| Разделил единицу на каждый элемент | Э1 | Н1, затем Тема 1 |
| Перепутал сторону умножения | Э2 | Н4, Тема 8 (8.2, 8.3) |
| Ответ «почти правильный», но переставленный | Э3 | Н2, Тема 4 |
| В проверке на диагонали стоит `\|A\|` | Э4 | Н3, Тема 6 |
| Половина дополнений с неверным знаком | Э5 | Тема 4 (4.1, 4.2) |
| Определитель 3×3 не сходится | Э6 | Н5, Тема 2 |
| В проверке сходится только одна строка | Э7 | Н6, Тема 6 |
| Переписывает верное решение из-за дробей | Э8 | Тема 6 |
| Пишет `(A+B)⁻¹ = A⁻¹+B⁻¹` | Э9 | Тема 7 (7.1, 7.3) |
| Считает уверенно, но не понимает зачем | — | Тема 10 |

### Как построить занятие на разбор ошибок (45 минут)

- **10 мин** — две задачи «найди ошибку» из части 2, те, что отвечают ошибкам ученика;
- **15 мин** — тема-антидот из банка задач, начиная с уровня «разминка»;
- **15 мин** — одна полная задача уровня «норма» со всеми пятью шагами и обязательной проверкой;
- **5 мин** — ученик сам формулирует, в чём была ошибка и как он теперь её ловит. Эта формулировка ценнее любого решённого примера.
