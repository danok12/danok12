# Правоведение и противодействие коррупции: ст. 39 и ст. 40 ГрК РФ

Две презентации по 12 слайдов. План повторяет доклад по ст. 18.8 КоАП РФ: что это за статья → почему выбрана и какие сложности применения → два кейса → выводы. Текст выступления лежит в заметках к слайдам, примерно 5–6 минут на каждую презентацию.

| Файл | Что внутри |
|---|---|
| `Ст. 39 ГрК РФ — презентация.pptx` / `.pdf` | Разрешение на условно разрешённый вид использования |
| `Ст. 40 ГрК РФ — презентация.pptx` / `.pdf` | Отклонение от предельных параметров разрешённого строительства |
| `content.js` | тексты слайдов и заметки |
| `build.js` | вёрстка (pptxgenjs) |

Пересборка: `npm i pptxgenjs react react-dom react-icons sharp` в любой папке, затем `NODE_PATH=<та папка>/node_modules node build.js`.
