## 1. Угол между функциями в C[0;1]

**1А.** Найдите косинус угла между функциями f, g ∈ C[0;1]:   f(x) = 2x + 1 и g(x) = x − 1 в евклидовом пространстве со скалярным произведением (f,g) = ∫₀¹ f(x)·g(x)dx.

**Ответ:** cosφ = (−5)/2√13 = (−5√13)/26

_(f,g) = ∫₀¹ (2x² − x − 1)dx = 2/3 − 1/2 − 1 = (−5)/6;   ‖f‖² = ∫₀¹ (4x² + 4x + 1)dx = 13/3;   ‖g‖² = ∫₀¹ (x − 1)²dx = 1/3;   ‖f‖·‖g‖ = √13/3._

**1Б.** Найдите косинус угла и сам угол между функциями f(x) = x и g(x) = 3x − 2 в C[0;1] с тем же скалярным произведением. Что можно сказать об этих функциях?

**Ответ:** cosφ = 0,  φ = 90°: функции ортогональны

_(f,g) = ∫₀¹ (3x² − 2x)dx = 1 − 1 = 0; нормы считать уже не нужно (‖f‖ = 1/√3, ‖g‖ = 1)._

> **Типичная ошибка.** Забывают брать корень: в знаменатель ставят ‖f‖²·‖g‖² вместо ‖f‖·‖g‖. Второе — ошибки при раскрытии (x − 1)²: пишут x² − 1. Ловить проверкой |cosφ| ≤ 1.

## 2. Дополнение до ортонормированного базиса в R³

**2А.** В пространстве L = **R**³ в стандартном базисе ī, j̄, k̄ заданы два вектора ā = (2, 1, −2) и b̄ = (1, 2, 2). Убедитесь, что они ортогональны, и дополните их третьим вектором до ортонормированного базиса. В ответе укажите все три вектора.

**Ответ:** ē1 = 1/3(2, 1, −2);   ē2 = 1/3(1, 2, 2);   ē3 = 1/3(2, −2, 1)

_(a,b) = 2 + 2 − 4 = 0.   a × b = (6, −6, 3) ∥ (2, −2, 1). Все три длины равны 3. Годится и ē3 = 1/3(−2, 2, −1)._

**2Б.** То же для ā = (1, 1, 1) и b̄ = (1, −2, 1).

**Ответ:** ē1 = 1/√3(1, 1, 1);   ē2 = 1/√6(1, −2, 1);   ē3 = 1/√2(1, 0, −1)

_(a,b) = 1 − 2 + 1 = 0.   a × b = (3, 0, −3) ∥ (1, 0, −1). Длины: √3, √6, √2. Знак у ē3 любой._

> **Типичная ошибка.** Нормируют только третий вектор, а a и b оставляют как есть — базис ортогональный, но не ортонормированный. Или делят на сумму координат вместо длины.

## 3. Ранг квадратичной формы

**3А.** Найдите ранг квадратичной формы f(x₁, x₂, x₃) = x₁² + 4x₂² + 16x₃² + 6x₁x₂ + 12x₁x₃ + 16x₂x₃.

**Ответ:** r = 2

_Матрица (1 3 6; 3 4 8; 6 8 16): третья строка = 2 · вторая, а минор (1 3; 3 4) = −5 ≠ 0._

**3Б.** То же для f = x₁² + 5x₂² + 2x₃² − 4x₁x₂ − 2x₁x₃ + 6x₂x₃.

**Ответ:** r = 2

_Матрица (1 −2 −1; −2 5 3; −1 3 2): третья строка = первая + вторая, минор (1 −2; −2 5) = 1 ≠ 0._

**3В.** То же для f = x₁² + 4x₂² + 9x₃² + 4x₁x₂ − 6x₁x₃ − 12x₂x₃.

**Ответ:** r = 1

_Матрица (1 2 −3; 2 4 −6; −3 −6 9): все строки пропорциональны первой. Действительно, f = (x₁ + 2x₂ − 3x₃)²._

> **Типичная ошибка.** Главная ошибка — ставить в матрицу полный коэффициент при xᵢxⱼ (6, 12, 16), а не половину (3, 6, 8). Ранг при этом может получиться 3. Ловить: матрица обязана быть симметричной, а xᵀAx должен вернуть исходную форму.

## 4. Базис и размерность пространства решений однородной системы

**4А.** Найдите какой-нибудь базис и установите размерность пространства решений однородной системы { x₁ − x₂ + 2x₃ + x₄ − x₅ = 0;;  x₂ + x₃ − 2x₄ + 3x₅ = 0. }

**Ответ:** dimL = 3;   e₁ = (−3; −1; 1; 0; 0),  e₂ = (1; 2; 0; 1; 0),  e₃ = (−2; −3; 0; 0; 1)

_Свободные x₃, x₄, x₅.  x₂ = −x₃ + 2x₄ − 3x₅;  x₁ = x₂ − 2x₃ − x₄ + x₅ = −3x₃ + x₄ − 2x₅._

**4Б.** То же для системы { x₁ + 2x₂ − x₃ + x₄ + 3x₅ = 0;;  2x₁ + 5x₂ − x₃ + 4x₄ + 4x₅ = 0;;  x₁ + 3x₂ + 3x₄ + x₅ = 0. }

**Ответ:** dimL = 3;   e₁ = (3; −1; 1; 0; 0),  e₂ = (3; −2; 0; 1; 0),  e₃ = (−7; 2; 0; 0; 1)

_Третье уравнение = второе − первое, поэтому r = 2, а не 3. После вычитания: x₂ = −x₃ − 2x₄ + 2x₅;  x₁ = 3x₃ + 3x₄ − 7x₅._

> **Типичная ошибка.** В варианте Б считают уравнения, а не ранг: «три уравнения — значит dim = 5 − 3 = 2». Каждый найденный вектор подставить в исходную систему — это 30 секунд и ловит почти всё.

## 5. Матрица линейного оператора в пространстве матриц 2×2

**5А.** Пусть L = M₂×₂. Найдите матрицу A линейного оператора f(M) = (2 −1; 1 3)ᵀ·M в стандартном базисе пространства L.

**Ответ:** A = (2 0 1 0; 0 2 0 1; −1 0 3 0; 0 −1 0 3)

_Сначала транспонировать: (2 −1; 1 3)ᵀ = (2 1; −1 3). f(E₁) = (2 0; −1 0) → столбец (2; 0; −1; 0), и т.д._

**5Б.** То же для оператора f(M) = M·(1 2; 0 −1) (умножение **справа**).

**Ответ:** A = (1 0 0 0; 2 −1 0 0; 0 0 1 0; 0 0 2 −1)

_f(E₁) = (1 2; 0 0) → (1; 2; 0; 0);   f(E₂) = (0 −1; 0 0) → (0; −1; 0; 0); E₃, E₄ — то же во второй строке._

> **Типичная ошибка.** Записывают образы базисных матриц в строки, а не в столбцы — получается Aᵀ. Второе — в варианте А забывают транспонировать матрицу из условия. Проверка: A·(координаты M) должно дать координаты f(M) для любой M, например M = (1 1; 1 1).

## 6. Длины и угол по матрице Грама

**6А.** В базисе {ē1, ē2} дана матрица Грама скалярного произведения G = (3 −1; −1 2) и векторы x̄ = (2; 1), ȳ = (−1; 3). Найдите длины векторов x̄ и ȳ, а также угол между ними.

**Ответ:** ‖x̄‖ = √10,  ‖ȳ‖ = √27 = 3√3,  cosφ = (−5)/(√10·√27) = (−5)/3√30

_GY = (−6; 7), (x̄,ȳ) = 2·(−6) + 1·7 = −5.   GX = (5; 0), (x̄,x̄) = 10.   GY·Y = 6 + 21 = 27._

**6Б.** То же для G = (4 2; 2 3), x̄ = (5; −6), ȳ = (1; 1). Отдельно ответьте: ортогональны ли x̄ и ȳ в этом скалярном произведении? А если бы скалярное произведение было обычным?

**Ответ:** ‖x̄‖ = √88 = 2√22,  ‖ȳ‖ = √11,  cosφ = 0 — ортогональны; в обычном скалярном произведении 5 − 6 = −1 ≠ 0, не ортогональны

_GY = (6; 5), (x̄,ȳ) = 30 − 30 = 0.   GX = (8; −8), (x̄,x̄) = 40 + 48 = 88._

> **Типичная ошибка.** Считают обычное скалярное произведение 2·(−1) + 1·3, забывая про G. Или берут только диагональ G. Ловить: (x,x) по матрице Грама обязано быть > 0.

## 7. Координаты многочлена в новом базисе

**7А.** В линейном пространстве P₁ многочленов степени не выше 1 в стандартном базисе (x; 1) заданы три многочлена: p(x) = 2x + 1;  f₁(x) = x + 3;  f₂(x) = 2x + 5. Найдите координаты многочлена p(x) в новом базисе f₁; f₂.

**Ответ:** p(x) = −8f₁ + 5f₂ = (−8; 5)

_{ x:  c₁ + 2c₂ = 2;  1:  3c₁ + 5c₂ = 1 }   Проверка: −8(x + 3) + 5(2x + 5) = 2x + 1 ✓_

**7Б.** В пространстве P₂ многочленов степени не выше 2 в стандартном базисе (x²; x; 1) даны p(x) = 2x² − x + 5 и f₁ = x² + 1, f₂ = x² + x, f₃ = x + 1. Найдите координаты p(x) в базисе f₁; f₂; f₃.

**Ответ:** p(x) = 4f₁ − 2f₂ + f₃ = (4; −2; 1)

_{ x²:  c₁ + c₂ = 2;  x:  c₂ + c₃ = −1;  1:  c₁ + c₃ = 5 }   Проверка: 4x² + 4 − 2x² − 2x + x + 1 = 2x² − x + 5 ✓_

> **Типичная ошибка.** В ответ пишут коэффициенты самого p (2; 1) — это координаты в старом базисе. Проверка подстановкой c₁f₁ + c₂f₂ обязательна.

## 8. Матрица оператора в R³ и образ вектора

**8А.** Найдите матрицу A линейного оператора f((x₁, x₂, x₃)) = (2x₁ − x₂ + 4x₃;  x₁ + 3x₃;  −x₁ + 5x₂ − 2x₃) в стандартном базисе пространства L = **R**³ и образ вектора x̄ = (2; −1; 3).

**Ответ:** A = (2 −1 4; 1 0 3; −1 5 −2);   f(x̄) = (17; 11; −13)

_Во второй координате нет x₂ — в матрице 0.   4 + 1 + 12 = 17;  2 + 0 + 9 = 11;  −2 − 5 − 6 = −13._

**8Б.** То же для f((x₁, x₂, x₃)) = (x₂ − x₃;  3x₁ + x₂;  x₁ − 2x₂ + 4x₃) и x̄ = (1; −2; 3).

**Ответ:** A = (0 1 −1; 3 1 0; 1 −2 4);   f(x̄) = (−5; 1; 17)

_−2 − 3 = −5;  3 − 2 = 1;  1 + 4 + 12 = 17._

> **Типичная ошибка.** Пропущенная переменная: в строку (x₁ + 3x₃) пишут (1, 3) и сдвигают столбцы. Всегда три числа в строке.

## 9. К какому собственному значению относится вектор

**9А.** Линейный оператор f в базисе ē1, ē2, ē3 задан матрицей A = (2 4 1; 3 1 −1; 1 3 1). Вектор x̄ = −ē1 + ē2 − ē3 является собственным вектором оператора f. Найдите, к какому собственному значению он относится.

**Ответ:** λ = −1

_X = (−1; 1; −1),  AX = (1; −1; 1) = −1·X._

**9Б.** Оператор задан матрицей A = (4 −1 1; 2 1 3; −2 1 2). Какой из векторов x̄ = ē1 + 2ē2 и ȳ = ē1 + ē2 + ē3 является собственным? К какому собственному значению он относится?

**Ответ:** x̄ — собственный, λ = 2;  ȳ — не собственный

_AX = (2; 4; 0) = 2·(1; 2; 0).   AY = (4; 6; 1) — не пропорционален (1; 1; 1)._

> **Типичная ошибка.** Координаты вектора −e₁ + e₂ − e₃ пишут без знаков или пропускают нулевую координату (в оригинале −2e₁ + 2e₃ → (−2; 0; 2)). Ищут λ через характеристический многочлен — долго и не нужно.

## 10. Собственный вектор для данного собственного значения

**10А.** Для линейного оператора, заданного матрицей A = (3 0 −1; 2 1 0; 3 −1 1), найдите какой-нибудь собственный вектор, соответствующий собственному числу λ = 2.

**Ответ:** r̄ = (1; 2; 1)  (или любой ненулевой кратный)

_A − 2E = (1 0 −1; 2 −1 0; 3 −1 −1), ранг 2 (третья строка = первая + вторая): x₃ = x₁, x₂ = 2x₁.   A·(1; 2; 1) = (2; 4; 2) ✓_

**10Б.** Для матрицы A = (0 −1 2; 2 −3 4; −1 1 −3) найдите какой-нибудь собственный вектор, соответствующий λ = −1. Сколько линейно независимых собственных векторов отвечает этому значению?

**Ответ:** например, (1; 1; 0) или (−2; 0; 1);  таких независимых векторов два

_A + E = (1 −1 2; 2 −2 4; −1 1 −2) — все строки пропорциональны, ранг 1, остаётся одно уравнение x₁ − x₂ + 2x₃ = 0: две свободные переменные._

> **Типичная ошибка.** Вычитают λ из всех элементов, а не только из диагонали. Или для λ = −1 вычитают −1 «в ту же сторону» и получают A − E. Нулевой вектор в ответ — не собственный вектор.

## 11. Канонический вид квадратичной формы ортогональным преобразованием

**11А.** Приведите квадратичную форму Φ(x₁, x₂) = x₁² + 5x₂² + 4√3x₁x₂ к каноническому виду и укажите соответствующее ортогональное преобразование координат.

**Ответ:** Φ(y₁, y₂) = −y₁² + 7y₂²,  (x₁; x₂) = (√3/2 1/2; (−1)/2 √3/2)(y₁; y₂)

_A = (1 ['2', ]; ['2', ] 5),  λ² − 6λ − 7 = 0, λ = −1; 7. Для −1: x₁ = −√3x₂ → (√3; −1)/2; для 7: x₂ = √3x₁ → (1; √3)/2. Это поворот на −30°._

**11Б.** То же для Φ(x₁, x₂) = −x₁² + 4x₂² + 12x₁x₂.

**Ответ:** Φ(y₁, y₂) = −5y₁² + 8y₂²,  (x₁; x₂) = (3/√13 2/√13; (−2)/√13 3/√13)(y₁; y₂)

_A = (−1 6; 6 4),  λ² − 3λ − 40 = 0, λ = −5; 8. Для −5: 4x₁ + 6x₂ = 0 → (3; −2)/√13; для 8: −9x₁ + 6x₂ = 0 → (2; 3)/√13._

> **Типичная ошибка.** Снова «половина коэффициента»: для 12x₁x₂ в матрицу идёт 6, а не 12 (и 2√3, а не 4√3). Собственные векторы забывают нормировать или ставят их в строки матрицы P. Проверка: сумма коэффициентов канонического вида = следу матрицы (−1 + 7 = 1 + 5), произведение = её определителю.
