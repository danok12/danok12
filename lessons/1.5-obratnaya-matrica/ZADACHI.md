# Банк задач по теме «Обратная матрица»

Для печати ученику. Ответы — в `ZADACHI-OTVETY.md`.
Уровни: **[Р]** разминка · **[Н]** норма · **[Т]** трудно

---

## Тема 1. Проверка по определению **[Р]**

Ничего не вычисляем — только умножаем и сверяем с `E`.

**1.1.** Обратна ли `|2 −5; −1 3|` матрице `|3 5; 1 2|`?

**1.2.** Обратна ли `|4 −2; −3 1|` матрице `|1 2; 3 4|`?

**1.3.** Может ли матрица размера `2×3` иметь обратную? Обосновать размерами.

**1.4.** Ученик проверил только `A·B = E` и остановился. Достаточно ли этого?

## Тема 2. Есть ли обратная **[Р]**

Только определитель и вывод.

**2.1.** `|4 6; 2 3|`, `|1 2; 3 7|`, `|2 −3; −4 6|`

**2.2.** `|1 2 3; 4 5 6; 7 8 9|`

**2.3.** Найти определители `|2 0 0; 0 3 0; 0 0 5|` и `|1 2 3; 0 4 5; 0 0 6|`, а для первой — сразу и обратную, не пользуясь алгоритмом.

**2.4.** При каких `λ` не существует обратной к `|λ−1 2; 3 λ−2|`?

## Тема 3. Матрицы 2×2 **[Р] [Н]**

Каждый ответ проверять умножением.

**3.1.** `|3 5; 1 2|`, `|2 7; 1 4|`, `|4 1; 3 1|`, `|3 1; 5 2|` — все с определителем 1.

**3.2.** `|2 4; 1 3|`, `|1 2; 3 4|` — определитель не единица, множитель оставить перед матрицей.

**3.3.** `|5 0; 0 2|`, `|0 1; 1 0|` — найти обратные и объяснить результат.

## Тема 7. Свойства **[Р] [Н]**

**7.1.** `|A| = −2`, порядок 3. Найти `|A⁻¹|`, `|A²|`, `|(A')⁻¹|`, `|3A|`, `|(3A)⁻¹|`.

**7.2.** Даны `A⁻¹ = |1 2; 0 1|` и `B⁻¹ = |1 0; 3 1|`. Найти `(AB)⁻¹`.

**7.3.** Верно ли, что `(2A)⁻¹ = 2A⁻¹`? А чему равно на самом деле?

**7.4.** Доказать: если `A` симметрична (`A' = A`) и обратима, то `A⁻¹` тоже симметрична.

**7.5.** Доказать: `(A²)⁻¹ = (A⁻¹)²`.

## Тема 8. Матричные уравнения **[Н] [Т]**

**8.1.** `A·X = B`, где `A = |2 5; 1 3|`, `B = |1 3; 2 4|`.

**8.2.** `X·A = B`, та же `A`, `B = |1 2|` (строка).

**8.3.** **[Т]** `A·X·B = C`, где `A = |1 1; 0 1|`, `B = |2 0; 0 1|`, `C = |1 2; 3 4|`.

**8.4.** **[Т]** `A·X = 2X + B`, где `A = |4 1; 2 5|`, `B = |1; 2|`.

## Тема 10. Со звёздочкой **[Т]**

**10.2.** Может ли быть обратимой матрица, у которой `A³ = 0`?

**10.3.** Пусть `A² = 0`. Доказать, что `E − A` обратима, и найти обратную.

**10.4.** При каких `λ` не существует обратной к `|λ 1 0; 0 λ 1; 1 0 λ|`?

**10.5.** `A` и `B` обратимы и перестановочны (`AB = BA`). Доказать, что их обратные тоже перестановочны.
