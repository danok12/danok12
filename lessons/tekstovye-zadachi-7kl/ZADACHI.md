# Текстовые задачи на уравнения — задачи для ученика

Клим, 7 класс. Ответы у преподавателя (`OTVETY.md`).

## Как составить уравнение

1. **Обозначь неизвестное буквой.** Обычно за `x` берут то, о чём спрашивают, или самую маленькую величину. Запиши словами: «`x` км/ч — скорость второго».
2. **Вырази через `x` всё остальное.** «На 5 больше» — `x + 5`, «вдвое больше» — `2x`, «на 20 % больше» — `1,2x`. Для движения и работы рисуй таблицу.
3. **Найди фразу, где что-то чему-то равно**: «всего прошёл», «встретились», «на час меньше».
4. **Реши уравнение.**
5. **Проверь и ответь на вопрос задачи**: про `x` или про `x + 6`, в часах или в минутах.

| Тип | Формула | Что помнить |
|---|---|---|
| Движение | `s = v · t` | единицы должны совпадать |
| Навстречу | `v₁ + v₂` | скорости складываются |
| Вдогонку | `v₁ − v₂` | сокращение расстояния — разность скоростей |
| Река | по течению `v + u`, против `v − u` | `u` — скорость течения |
| Работа | `A = p · t` | всю работу считаем за 1 |
| Проценты | `+p %` → `·(1 + p/100)` | процент от того, что было ДО изменения |
| Смеси | вещество = масса · доля | вода соль не добавляет |

### Разбор

Из двух городов, расстояние между которыми 390 км, навстречу друг другу вышли два поезда. Второй вышел на 1 час позже первого. Скорость первого 60 км/ч. Поезда встретились через 3 часа после выхода второго. Найди скорость второго поезда.

```
Пусть x км/ч — скорость второго поезда.
            v      t       s
первый      60     3+1=4   240
второй      x      3       3x
240 + 3x = 390  →  3x = 150  →  x = 50
Проверка: 240 + 150 = 390 ✓      Ответ: 50 км/ч.
```

## Уровень 1. Разминка

1. Сумма трёх чисел равна 61. Второе число на 5 больше первого, а третье вдвое больше первого. Найди наибольшее из этих чисел.
2. Мама старше дочки на 26 лет. Через 4 года мама будет старше дочки ровно в 3 раза. Сколько лет дочке сейчас?
3. Три тетради и две ручки стоят вместе 230 рублей. Ручка на 15 рублей дороже тетради. Сколько стоит тетрадь?

## Уровень 2. Движение

4. Из двух посёлков, расстояние между которыми 72 км, одновременно навстречу друг другу выехали два велосипедиста. Скорость одного на 4 км/ч больше скорости другого. Они встретились через 2 часа. Найди скорость более быстрого велосипедиста.
5. Пешеход вышел из деревни со скоростью 5 км/ч. Через 1,5 часа по той же дороге вслед за ним выехал велосипедист со скоростью 14 км/ч. Через сколько минут после своего выезда велосипедист догонит пешехода?
6. Катер шёл 3 часа по течению реки и 4 часа против течения и прошёл всего 152 км. Скорость течения 2 км/ч. Найди скорость катера в стоячей воде.

## Уровень 3. Работа, проценты, смеси

7. Первая бригада может выполнить заказ за 10 дней, вторая — за 15 дней. За сколько дней они выполнят заказ, работая вместе? *(Весь заказ — это 1.)*
8. Цену куртки сначала повысили на 20 %, а потом понизили на 20 %. После этого куртка стала стоить 9600 рублей. Сколько она стоила сначала?
9. Есть 30 кг раствора соли с концентрацией 10 %. Сколько килограммов воды надо добавить, чтобы концентрация стала 6 %?
10. Сплав, содержащий 20 % меди, смешали со сплавом, содержащим 50 % меди, и получили 30 кг сплава, содержащего 40 % меди. Сколько килограммов первого сплава взяли?

## Уровень 4. Потруднее

11. Автомобиль проехал первую половину пути со скоростью 60 км/ч, а вторую — со скоростью 90 км/ч. Найди среднюю скорость на всём пути. *(Средняя скорость = весь путь : всё время.)*
12. Первый рабочий может выполнить работу за 12 часов, второй — за 24 часа. Первый проработал один 3 часа, затем к нему присоединился второй. Сколько часов они работали вместе до конца работы?
13. Поезд проезжает мимо столба за 15 секунд, а мост длиной 450 м — за 45 секунд. Найди длину поезда в метрах.

## Найди ошибку

В каждом решении есть ошибка. Найди её, объясни словами и реши правильно.

**А.** Велосипедист ехал 40 минут по грунтовке и 2 часа по шоссе. По шоссе его скорость была на 6 км/ч больше. Всего он проехал 52 км. Найди скорость по грунтовке.
```
Пусть x км/ч — скорость по грунтовке.
40x + 2(x + 6) = 52  →  42x + 12 = 52  →  x = 40/42 ≈ 0,95
Ответ: 0,95 км/ч.
```

**Б.** После снижения цены на 20 % телефон стоит 8000 рублей. Сколько он стоил до снижения?
```
20 % от 8000 = 1600;  8000 + 1600 = 9600.   Ответ: 9600 рублей.
```

**В.** Из двух городов, расстояние между которыми 102 км, одновременно навстречу друг другу выехали два велосипедиста. Скорость одного на 6 км/ч больше. Они встретились через 3 часа. Найди скорость более быстрого.
```
Пусть x км/ч — скорость медленного.
3(x + x + 6) = 102  →  6x + 18 = 102  →  x = 14.   Ответ: 14 км/ч.
```

## Квадратное уравнение

```
ax² + bx + c = 0,  a ≠ 0

D = b² − 4ac
x = (−b + √D) / (2a)   и   x = (−b − √D) / (2a)

D > 0 — два корня,  D = 0 — один корень −b/(2a),  D < 0 — корней нет
```

Порядок: всё влево, справа 0 → выписать `a, b, c` со знаками → `D` → корни → проверка → в задаче отбросить корень, не подходящий по смыслу.

**Пример.** `x² − 5x − 14 = 0`: `a = 1, b = −5, c = −14`; `D = 25 + 56 = 81`, `√D = 9`; `x = (5 ± 9)/2`, то есть `7` и `−2`.

Знаки: если `b = −5`, то `−b = 5`, `b² = 25`; если `c < 0`, то `−4ac` — плюс.

### Разбор задачи в стиле ЕГЭ

Велосипедист проехал 72 км от посёлка до города. Обратно он ехал со скоростью на 6 км/ч больше и потратил на дорогу на 1 час меньше. Найди скорость на пути в город.

```
            v        s      t
в город     x        72     72/x
обратно     x + 6    72     72/(x + 6)

72/x − 72/(x + 6) = 1                 ← туда ехал на час дольше
умножаем обе части на x(x + 6):
72(x + 6) − 72x = x(x + 6)
432 = x² + 6x
x² + 6x − 432 = 0

D = 36 + 1728 = 1764,  √1764 = 42     (40² = 1600, 45² = 2025, оканчивается на 2 или 8 → 42)
x₁ = (−6 + 42)/2 = 18
x₂ = (−6 − 42)/2 = −24                ← скорость не бывает отрицательной
Проверка: 72 : 18 = 4 ч, 72 : 24 = 3 ч, разница 1 ч ✓      Ответ: 18 км/ч.
```

Проверка без формулы: `x(x + 6) = 432` — два числа, отличающиеся на 6, с произведением 432: `18 · 24`.

### Разминка на формулу

а) `x² − 8x + 15 = 0`  б) `2x² + x − 6 = 0` (здесь `2a = 4`)  в) `x² − 6x + 9 = 0`
