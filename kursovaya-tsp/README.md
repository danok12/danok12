## Расчёт по методичке

### Принятые решения

- Рабочие отметки h1…h24 — таблица вариантов, вариант 2; вершины построчно слева направо, сверху вниз. h = Hкр − Hчёрн: «−» — выемка (ПВ), «+» — насыпь (ПН).
- Грунт — супесь (по указанию преподавателя; в таблице Задания 4 для варианта 2 — глина тяжёлая). Kо.р = 1,04 (прил. 2: 1,03–1,05).
- Объёмы планировки — методом с доски: Vi = Fi · hср, hср — среднее |h| по вершинам фигуры, точки нуля входят нулями (решение пользователя; призмы по формулам с. 9–10 дали бы выемку на 4,0 % и насыпь на 2,2 % больше).
- Откосы по контуру площадки — по формуле с. 10: ΣV = (Σh/n)² · Σl · m/2, Σh и n — рабочие отметки вершин контура в зоне, Σl — длина контура в зоне, m = 0,25 (супесь, до 1,5 м, прил. 3).
- Глубина котлована — по формуле с. 11 с растительным слоем 0,2 м: hк = Нк − hр.сл − hр (решение пользователя); hр — в центре котлована (котлован в насыпи, с. 12, вариант 3).
- Съезд (пандус) — один, с двусторонним движением, bп = 6 м: так и по методичке (с. 14: 6 м — двусторонний проезд), и по лекции 09.10 (один съезд — 6 м, два — по 3,5–4 м); уклон i = 0,1 (m' = 10: методичка 0,10–0,15, лекция m' = 8…15).
- Со стороны съезда от фундаментной плиты до низа откоса c = 1 + 2r + 1 = 7 м (лекция: место для крана, r = 2,5 м — радиус поворотной платформы); с остальных сторон — по схеме задания (0,5 м от подготовки, 0,7 м от плиты ≥ 0,6 м).
- Объём съезда — по формуле лекции (сверх откоса котлована): Vс = hк²/6 · (3bп + 2m·hк·(m' − m)/m') · (m' − m); котлован без съезда — hк/3 · (Fк.н + Fк.в + √(Fк.н·Fк.в)) (методичка, с. 14; та же формула в лекции).
- Обратная засыпка: пазухи — привозным песком (лекция: грунт площадки не песок; решение пользователя), съезд — грунтом котлована из отвала. В сводном балансе (табл. 2) в насыпи котлована поэтому только засыпка съезда.
- Δh — с точностью 0,0001 м; окончательные отметки h' = h + Δh (с. 15).
