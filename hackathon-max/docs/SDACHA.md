# Чек-лист сдачи онлайн-этапа

Сверено с разделом «Формат сдачи» кейса. Отмечено, что готово, а что
заполняете вы перед загрузкой.

## Обязательно для всех решений

| № | Что требуется | Где взять | Статус |
|---|---|---|---|
| 1 | Ссылка или иной способ доступа к чат-боту / мини-приложению в MAX | появится после получения токена от организаторов и развёртывания | ⛔ нужен токен |
| 2 | Зафиксированная версия исходного кода: Git-репозиторий с commit hash **либо** архив с контрольной суммой | ветка `claude/nice-albattani-hctolx` либо архив `profil10-team870-<commit>.zip` + SHA-256 | ✅ |
| 3 | `README.md` со всеми требуемыми разделами | в корне решения | ✅ |
| 4 | Файл зависимостей | `api/requirements.txt`, `bot/requirements.txt`, `miniapp/package-lock.json` | ✅ |
| 5 | Docker-конфигурация: Dockerfile, compose, `.dockerignore`, `.env.example` без секретов | в корне решения | ✅ конфигурация готова, сборку прогнать у себя |
| 6 | Презентация в PDF | `docs/presentation.pdf` | ✅ кроме заглушек на первом слайде |

## Только для решений с собственным API

## Тестовые доступы (персональных данных не содержат)

| Роль | Значение |
|---|---|
| Ученик | коды классов `9A-114`, `9B-114`, `9A-ALM7` |
| Классный руководитель | коды кураторов `KUR-114-9A`, `KUR-114-9B`, `KUR-ALM7-9A` |

`9B-114` намеренно пустой — на нём видно работу порога k-анонимности.

## Что заполнить перед загрузкой

Первый слайд презентации (служебный, продуктовой оценке не подлежит):

1. Ссылка на чат-бота в MAX.
2. Адрес развёртывания — подставляется в `PUBLIC_BASE_URL`, из него же
   получаются адреса мини-приложения (`/app/`) и API (`/api`).
3. Commit hash сдаваемой версии.
4. Контактное лицо команды для вопросов по проверке.
5. Значения `MAX_BOT_TOKEN`, `APP_SECRET`, `INTERNAL_KEY` — кейс требует
   указать их на служебном слайде, но **не в репозитории**.

## Перед загрузкой прогнать

```bash
docker compose --env-file .env.demo --profile demo up --build -d
pip install -r requirements-dev.txt
python3 -m pytest tests -q
python3 tools/api_contract_check.py --base http://localhost:8080
INTERNAL_KEY=demo-only-not-a-secret-1111111111 REMINDER_DEMO_DELAY=20 \
  python3 tools/scenario_check.py
```

Ожидается: `31 passed`, `пройдено 14, не пройдено 0`, `успешно 35, неуспешно 0`.

## Риск, который закрывается только токеном

По критериям допуска решение получает 0 баллов и дальше не оценивается,
если чат-бот или мини-приложение в MAX не запускается, не отвечает или
основной сценарий невозможно проверить. Всё остальное готово, поэтому
получение токена у организаторов — задача номер один.
