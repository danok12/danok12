# Тема № 9. Исследование НДС в окрестности точки тела (РГР)

Вариант: задача 1 — строка 14 (σx, σy, τxy) и строка 11 (σz, τyz, τzx);
задача 2 — σx по строке 29, σy по строке 8, τxy по строке 25.

Документ собран целиком: **задача 1 — пункты 1–8**, **задача 2 — пункты 1–9**,
выводы. Порядок решения и обозначения повторяют разбор на практическом занятии:
U₀ = U₀^об + U₀^ф через главные напряжения, σ_экв^IV по модели Фёппля — Мизеса,
главные напряжения задачи 2 — из кубического уравнения с I₃н = 0, углы — по формуле
tg αi = τyx/(σy − σi) при оси y, направленной вниз.

## Оформление

Документ свёрстан **как обычная расчётная работа**: белый лист, чёрный текст,
Times New Roman, формулы в тексте с отступом, таблицы с рамкой, схемы чёрно-белые,
подписи «Таблица N — …» сверху и «Рис. N — …» снизу. Палитра серии занятий
(`CLAUDE.md`, раздел про Artifact) здесь намеренно не используется — это отчёт
на печать, а не страница занятия.

## Схемы

| рисунок | что показывает |
|---|---|
| 1.1 | напряжения на гранях элементарного параллелепипеда (аксонометрия) |
| 1.2 | главный элемент, построенный по найденным направляющим косинусам |
| 1.3 | диагональная площадка с наибольшим касательным τ31 |
| 1.4 | линейные деформации: контур до и после |
| 1.5 | **угловые деформации: три куба, на каждом сдвиг в своей плоскости (xOy, yOz, zOx)** |
| 2.1 | тонкая пластина, нагруженная по контуру, и выделенный объёмный элемент |
| 2.2 | напряжения на гранях элемента при плоском состоянии |
| 2.3 | главный элемент задачи 2, углы α₂ и α₃ от оси x |

Аксонометрия: z вверх, x вправо, y на зрителя — как на схеме элемента в тетради.
В рис. 1.5 каждый куб деформируется простым сдвигом (один недиагональный член,
как на плоских схемах) с увеличением углов примерно в 240 раз; вершина угла
выбирается автоматически — ближайшая к наблюдателю. Знаки проверяются скриптом:
при γ > 0 угол на рисунке действительно уменьшается, при γ < 0 увеличивается.

## Проверка чисел

Три независимых уровня:

1. `raschet.py` — расчёт в точной арифметике (`Fraction`), корни уравнений
   ньютоновскими итерациями с 50 знаками.
2. `sverka.py` — сверка всех чисел с предыдущей версией решения, до последнего
   разряда, с учётом округления.
3. `proverka.py` — **перепроверка другими методами**: корни — подстановкой
   в det(Tн − σE) = 0, направляющие косинусы — из условия Tн·ν = σ·ν (невязка
   ~10⁻¹⁴), удельная энергия — свёрткой ½·σij·εij, эквивалентное напряжение —
   через девиатор √(3/2·sij·sij), τmax — как (σ1 − σ3)/2. Допуск в каждом
   сравнении — половина единицы последнего разряда, округлённого в тексте.

## Обрезка схем

`../obrezka-svg.py` открывает схемы в Chromium, берёт `svg.getBBox()`
и переписывает `viewBox` по фактическому содержимому. Без этого снизу
остаётся пустое поле: на экране незаметно, а в PDF рисунок из-за него
выходит мельче. Запускать после `figures.py`:

```bash
python3 ../obrezka-svg.py .
```
