# Параллелограмм: биссектриса и признаки — задачи

## Найди ошибку

В каждом решении есть ошибка. Найдите её, объясните и решите правильно.

**1.** Биссектриса острого угла делит сторону в отношении 3 : 5 от вершины тупого угла, P = 66.
```
AB = BE = 3x,   BC = 5x
2(3x + 5x) = 66
16x = 66,   x = 4,125
Стороны 12,375 и 20,625
```

**2.**
```
AB = 3x,   BC = 8x
3x + 8x = 66
x = 6
Стороны 18 и 48
```

**3.**
```
BE = 3x,   EC = 5x
Треугольник ECD равнобедренный, поэтому CD = EC = 5x
AB = CD = 5x,   BC = 8x
2(5x + 8x) = 66,   x = 33/13
```

**4.** Доказательство к задаче «лучи AM и CK, ∠BAM = ∠DCK»:
```
△ABM = △CDK по второму признаку, значит AM = CK.
MC ∥ AK, потому что лежат на параллельных прямых.
У AMCK две стороны равны, а две другие параллельны,
значит, это параллелограмм.
```

**5.**
```
△ABM = △CDK по первому признаку:
AB = CD, BM = DK, ∠B = ∠D.
```
