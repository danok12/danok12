## 2. Главные напряжения

На главной площадке касательных напряжений нет (σ ≠ 0, τ = 0). Условия для
нормали ν дают однородную систему:

```
(σx − σ)·l + τxy·m + τxz·n = 0
τyx·l + (σy − σ)·m + τyz·n = 0        (2)
τzx·l + τzy·m + (σz − σ)·n = 0
```

Ненулевое решение существует только при равенстве нулю определителя, что даёт
кубическое уравнение

σ³ − I₁н·σ² + I₂н·σ − I₃н = 0   (1)

### Инварианты

* I₁н = σx + σy + σz = −80 + 60 + (−60) = **−80 МПа**
* I₂н = σxσy + σyσz + σzσx − τxy² − τyz² − τzx² = −4800 − 3600 + 4800 − 8100 − 2500 − 4225 = **−18425 МПа²**
* I₃н = σxσyσz + 2τxyτyzτzx − σxτyz² − σyτzx² − σzτxy² = 288000 − 585000 + 200000 − 253500 + 486000 = **135500 МПа³**

Подставляя в (1): σ³ + 80σ² − 18425σ − 135500 = 0.

### Решение по теореме Виета

Приведённое кубическое σ³ + bσ² + cσ + d = 0, где b = −I₁н = 80, c = I₂н = −18425,
d = −I₃н = −135500. Соотношения Виета — это и есть инварианты:

```
σ₁ + σ₂ + σ₃ = −b = I₁н
σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = c = I₂н        (3)
σ₁·σ₂·σ₃ = −d = I₃н
```

Если известен хотя бы один корень, два других находятся из квадратного уравнения.

**Шаг 1.** Целый корень обязан быть делителем свободного члена (135500 = 2²·5³·271).
Подстановка показывает, что ни один делитель корнем не является: f(1) = −153844;
f(−1) = −116996; f(5) = −225500; f(−5) = −41500; f(271) = 20649116; f(−271) = −9169556.
Значит корни иррациональные; первый находим подстановкой по перемене знака:

## 3. Косинусы и углы наклона главных площадок

### б) Относительные угловые деформации

или тупой (γ < 0).

## 7. Полная удельная потенциальная энергия упругой деформации

Размерность удельной энергии совпадает с размерностью напряжения:
Дж/м³ = Н·м/м³ = Н/м² = Па, поэтому результат записывается в МПа.

**U₀ = U₀^об + U₀^ф**

### Полная энергия

U₀ = 1/(2E)·[σ₁² + σ₂² + σ₃² − 2ν·(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Суммы в скобках — инварианты, поэтому беру их точно:

* σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = 6400 + 36850 = **43250 МПа²**
* σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = **−18425 МПа²**

U₀ = (43250 + 11055)/(4,2·10⁵) = 54305/(4,2·10⁵) = **0,1293 МПа**

### Энергия изменения формы

U₀^ф = (1 + ν)/(6E)·[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²]

σ₁ − σ₂ = 113,1101; σ₂ − σ₃ = 171,6544; σ₃ − σ₁ = −284,7646 МПа.

Сумма квадратов разностей = 2·(I₁н² − 3·I₂н) = 2·61675 = **123350 МПа²**
(контроль по корням: 113,1101² + 171,6544² + 284,7646² = 123350,0).

U₀^ф = 1,3·123350/(1,26·10⁶) = **0,12727 МПа**

### Энергия изменения объёма

U₀^об = U₀ − U₀^ф = 0,12930 − 0,12727 = **0,00203 МПа**

Проверка по независимой формуле: U₀^об = (1 − 2ν)/(6E)·I₁н² = 0,4·6400/(1,26·10⁶) =
0,00203 МПа — совпало точно.

**Вывод:** U₀ = 0,1293 > U₀^ф = 0,12727 МПа. На формоизменение уходит 98,4 %
всей энергии, на изменение объёма — 1,6 %.

> **Почему не 0,13018.** Ту же энергию можно записать через компоненты:
> U₀ = 1/(2E)·[σx²+σy²+σz² − 2ν(σxσy+σyσz+σzσx)] + 1/(2G)·(τxy²+τyz²+τzx²).
> При G = 0,8·10⁵ из задания выйдет 0,03752 + 0,09266 = 0,13018 МПа. Разница в том,
> что G в задании округлён: согласованное с E и ν значение G = E/[2(1+ν)] = 0,80769·10⁵
> даёт 0,03752 + 0,09177 = 0,1293 МПа — ровно то же, что и по главным напряжениям.
> Формула по главным напряжениям от G не зависит, поэтому в отчёт идёт 0,1293 МПа,
> а 0,13018 — та же величина с округлённым G (расхождение 0,68 %).

## 8. Проверка прочности по IV (энергетической) теории

**Формулировка.** Опасное состояние наступает тогда, когда удельная энергия
формоизменения достигает того же значения, что и в момент наступления опасного
состояния при простом одноосном напряжённом состоянии. Модель Фёппля — Мизеса.

σ_экв^IV = (1/√2)·√[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²] ≤ R·γc

σ_экв^IV = (1/√2)·√123350 = √61675 = **248,34 МПа**

R·γc = 210·0,9 = **189,0 МПа**

σ_экв^IV = 248,34 МПа **> R·γc = 189,0 МПа** — **условие прочности не выполняется**,
превышение **31,4 %**. Прочность в окрестности точки не обеспечена: требуется снизить
уровень напряжений либо применить сталь с более высоким R.

Связь пунктов 7 и 8: U₀^ф = σ_экв²/(6G) = 248,3445²/(6·0,80769·10⁵) = 0,12727 МПа —
то же число, что в п. 7.

## Дано

## 1. Тензор напряжений и напряжения на гранях элемента

По закону парности τxy = τyx = −30 МПа.

Tн = | σx  τxy ; τyx  σy | = | −85  −30 ; −30  −30 |  [МПа]

Плоское напряжённое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной
силами в её плоскости. На лицевых поверхностях пластины нагрузки нет, поэтому
σz = 0 и τzx = τzy = 0 (рис. 2.1).

Оба нормальных напряжения отрицательны, стрелки направлены к граням (сжатие);
касательные тоже отрицательны и направлены противоположно положительному
направлению осей. Отличны от нуля только три компоненты, поэтому элемент достаточно
изобразить плоским — проекцией на плоскость xOy (рис. 2.2).

## 2. Главные напряжения

Используем то же кубическое уравнение (1):

* I₁н = σx + σy = **−115 МПа**
* I₂н = σx·σy − τxy² = 2550 − 900 = **1650 МПа²**
* I₃н = **0** — при двухосном состоянии третьего инварианта нет

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0.

Корень σ = 0 отвечает площадке с нормалью z: на ней нет ни нормальных, ни
касательных напряжений, значит ось z — главная. Квадратное уравнение даёт:

σ₁,₂ = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx + σy)/2 ± √[((σx − σy)/2)² + τxy²]

* (σx + σy)/2 = −57,5 МПа; (σx − σy)/2 = −27,5 МПа
* √(756,25 + 900) = √1656,25 = 40,6971 МПа
* σ′ = −16,80 МПа; σ″ = −98,20 МПа

Располагаем от большего к меньшему:

**σ₁ = 0; σ₂ = −16,80 МПа; σ₃ = −98,20 МПа**

> В примере с занятия оба плоских корня были ненулевыми и разного знака, поэтому
> они и оказались σ₁ и σ₂. Здесь оба отрицательны, так что нулевой корень —
> наибольший, и он становится σ₁.
