# Квадратные уравнения — ответы

Все ответы посчитаны программой: `python3 build.py --check`.

## 1. Раскройте скобки и приведите подобные

1. `x² + x − 12`
2. `4x² − 20x + 25`
3. `−x + 8`
4. `x² + x + 1/4`

## 2. Решите неполные квадратные уравнения

1. `x = −4; 4`
2. `x = −3; 3` — x² − 9 = 0
3. `корней нет`
4. `x = −7/2; 0`
5. `x = 0; 3` — x² − 3x = 0
6. `x = −1/2; 1/2`

## 3. Решите уравнения через дискриминант

1. `x = 2; 3` — D = 1
2. `x = −5; 3` — D = 64
3. `x = −1/2; 2` — D = 25
4. `x = 3` — D = 0
5. `корней нет` — D = −19
6. `x = −2; 1/3` — D = 49
7. `x = −1; 5` — x² − 4x − 5 = 0; D = 36
8. `x = 2 ± √3` — D = 12

## 4. Раскройте скобки и решите уравнения

1. `x = −4; 5` — x² − x − 20 = 0; D = 81
2. `x = −6; 1` — x² + 5x − 6 = 0; D = 49
3. `x = 0; 2` — x² − 2x = 0
4. `x = −2; 3` — x² − x − 6 = 0; D = 25
5. `x = −3; 2` — x² + x − 6 = 0; D = 25

## 5. Решите уравнения с дробными коэффициентами

1. `x = −2; 4` — x² − 2x − 8 = 0; D = 36
2. `x = −1; 3` — x² − 2x − 3 = 0; D = 16
3. `x = −1; 3` — x² − 2x − 3 = 0; D = 16
4. `x = 1; 2` — x² − 3x + 2 = 0; D = 1
5. `x = −2; 13/4` — 4x² − 5x − 26 = 0; D = 441

## 6. Задачи

1. **7 и 12** — x(x + 5) = 84; корни −12; 7
2. **6 см и 9 см** — x(x + 3) = 54; корни −9; 6
3. **12 и 13** — x(x + 1) = 156; корни −13; 12
4. **5 см** — (x + 3)² = 64; корни −11; 5
5. **через 1 с и через 3 с (на подъёме и на спуске)** — 20t − 5t² = 15; корни 1; 3

## 7. Найдите ошибку

1. x = 0; 6 — делить на x нельзя — теряется корень 0; x(x − 6) = 0
2. x = −1/2; 3 — c = −3, поэтому D = 25 + 24 = 49
3. x = 1; 6 — (x − 2)² = x² − 4x + 4, а не x² − 4; дальше x² − 7x + 6 = 0
