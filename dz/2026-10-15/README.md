## Как устроено

Все условия и ответы записаны один раз в `zadachi.py`; из них собираются PDF, `ZADACHI.md` и `OTVETY.md`.

```bash
pip install sympy numpy mpmath
python3 zadachi.py check   # проверить ответы, ~25 с
python3 zadachi.py build   # проверить и пересобрать PDF и md
```

Проверка тригонометрии: уравнение разбирается из той же строки, что печатается в листе,
и решается численно на [−6π; 6π] с учётом ОДЗ. Каждая точка каждой серии ответа обязана
быть корнем, и каждый найденный корень обязан попасть в серию. Пункты б, отбор на
промежутке, сумма корней и задача с параметром сверяются так же. Перед выдачей
проверку прогоняли на заведомо неверных ответах (потерянная серия, корень вне ОДЗ,
«корней нет» при sin x = π/4, лишний корень на отрезке) — все ловятся.

Дроби 6 класса считаются через `Fraction`, ответ печатается из результата вычисления.
