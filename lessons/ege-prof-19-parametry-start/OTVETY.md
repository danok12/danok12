# Задание 19 (параметр), первые шаги — ответы

Только для преподавателя. Ответы проверены `proverka.py`: для каждой задачи значение параметра
перебирается по сетке с шагом 1/8 на [−12; 16] плюс каждая граничная точка и её окрестность ± 1/1000;
при каждом значении уравнение решается точно (sympy) и число корней сверяется с ответом.
PDF с ответами под каждой задачей: `Параметры, первые шаги — задачи с ответами.pdf`.
