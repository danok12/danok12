# Стереометрия, 10 класс — вариант I: ответы

Все ответы проверены программой на явных координатах, точной арифметикой: `python3 build.py --check`.

## 1.

- `PE ⊂ (ADB)` (P на DE, а `DE ⊂ (ADB)`); `MK ⊂ (DBC)`; `DB ⊂ (ADB), (DBC)`; `AB ⊂ (ABC), (ADB)`.
- `(ADB)`: A, B, D, E, P, M; `(DBC)`: B, C, D, M, K; в обеих — B, D, M (прямая DB).
- `(ABC) ∩ (DCB) = BC`; `(ABD) ∩ (CDA) = AD`; `(PDB) ∩ (ABC) = AB`, потому что `(PDB) = (ADB)`.

## 2.

`MN ∥ AC` (средняя линия); MN пересекает α ⇒ по лемме о двух параллельных прямых AC тоже пересекает α.
Пересекает именно прямая: на рисунке отрезок AC лежит по одну сторону от α, точка пересечения X —
на продолжении AC за A, `X = KN ∩ AC`, где `K = AB ∩ α`.

## 3. **AC = 15**

`α ∩ (ABC) = A₁C₁`, и `A₁C₁ ∥ AC`, потому что `AC ∥ α` (плоскость через прямую, параллельную другой
плоскости, пересекает её по параллельной прямой). Угол D общий, `∠DA₁C₁ = ∠DAC` ⇒ `ΔC₁DA₁ ∼ ΔCDA`,
`k = DA₁ / DA = 4/10`; `AD = BC = 10`; `AC = A₁C₁ / k = 6 · 10 / 4 = 15`.

Ловушка: `DA₁ : A₁A = 4 : 6` вместо `4 : 10` даёт неверное `AC = 9`.

## Аналог задачи 3. **BD = 21**

`β ∩ (ABC) = KM`, `KM ∥ BD` (так как `BD ∥ β`). Угол A общий, `∠AKM = ∠ABD` ⇒ `ΔAKM ∼ ΔABD`;
`AB = CD = 14`, `k = AK / AB = 4/14 = 2/7`, `BD = KM / k = 6 · 14 / 4 = 21`.

Ловушка: `AK : KB = 4 : 10` даёт неверное `BD = 15`. Вариант посложнее — дать `KB = 10` вместо `AK = 4`,
ответ тот же.
