0. Условие и расчётная схема

l, мP, кН2P, кН3P, кНP/2, кН
441428427

Требуется: определить опорные реакции VA, HA, VB, HB и усилия во всех стержнях.

  • Размеры панелей на карточке не проставлены. Схема начерчена в масштабе, и по чертежу панели квадратные: d = l/6 = 44/6 = 7,333 м по горизонтали и по вертикали. Высота до верхнего пояса 3d = l/2 = 22 м совпадает с размером на карточке.
  • Опоры A и B шарнирно-неподвижные, на одном уровне. Консоли выступают за опоры на одну панель d.
  • Ключевой шарнир C — узел верхнего пояса посередине пролёта (x = 3d = l/2).
  • Все нагрузки узловые: P в верхнем узле над опорой A и в конце левой консоли, 3P в нижнем узле левой половины у шарнира, 2P в верхнем узле правой половины, P вправо в конце правой консоли, P/2 вправо в узле распорки правой «ноги».
Почему это трёхшарнирная система. Левая половина (все стержни от консоли до шарнира C вместе с «ногой» над опорой A) — геометрически неизменяемая ферма, то есть жёсткий диск. Правая половина — второй такой диск. Диски соединены между собой только шарниром C и прикреплены к земле шарнирно-неподвижными опорами A и B — это та же схема, что у трёхшарнирной арки. Проверка по формуле для ферм: W = 2У − С − С0 = 2·23 − 42 − 4 = 0 (23 узла, 42 стержня, 4 опорных стержня) — система статически определима.

Правило знаков

  • В уравнениях моментов: вращение по часовой стрелке — «+», против часовой — «−» (как на паре).
  • Реакции: VA, VB — вверх; HA — вправо, HB — влево (внутрь пролёта, как распор арки).
  • Усилие в стержне N > 0 — растяжение. При вырезании узла все неизвестные усилия направляем от узла (как растягивающие). Если ответ отрицательный — стержень сжат.

Шаг 1. Вертикальные опорные реакции

Пояснение. Опоры на одном уровне, поэтому HA и HB лежат на прямой AB и не дают момента ни относительно A, ни относительно B. Из ΣMA = 0 сразу находится VB, из ΣMB = 0 — VA. Плечи вертикальных сил — горизонтальные расстояния, плечи горизонтальных сил (P в узле 9′ и P/2 в узле F) — их высота над линией AB: 2d и d. Все плечи кратны d, поэтому d сокращается.
ΣMA = −VB·6d − P·d + 3P·2d + 2P·5d + P·2d + (P/2)·d = 0
P в узле 2 проходит через A — момента нет; P в узле 1′ левее A, вниз — против часовой («−»); 3P и 2P правее A, вниз — по часовой («+»); P и P/2 вправо выше A — по часовой («+»); VB правее A, вверх — против часовой («−»).
VB = P·d·(−1 + 6 + 10 + 2 + 0,5) / (6d) = 17,5·P/6 = 17,5·14/6 = 245/6 = 40,833 кН
ΣMB = VA·6d − P·6d − P·7d − 3P·4d − 2P·d + P·2d + (P/2)·d = 0
VA левее B, вверх — по часовой («+»); все вертикальные нагрузки левее B, вниз — против часовой («−»); P и P/2 вправо выше B — по часовой («+»).
VA = P·d·(6 + 7 + 12 + 2 − 2 − 0,5) / (6d) = 24,5·P/6 = 24,5·14/6 = 343/6 = 57,167 кН
Проверка: ΣY = VA + VB − P − P − 3P − 2P = 343/6 + 245/6 − 7·14 = 588/6 − 98 = 98 − 98 = 0 ✓

Шаг 2. Распоры HA и HB

Пояснение. Шарнир C не передаёт момент, поэтому сумма моментов относительно C всех сил, приложенных к одной полураме, равна нулю — так же, как в арке. Из левой полурамы находим HA, из правой — HB. В отличие от арки из конспекта, здесь есть горизонтальные нагрузки (P и P/2), поэтому распоры разные: HA ≠ HB. Уравнение ΣX = 0 для всей рамы становится проверкой. Шарнир C лежит на высоте 3d над опорами; плечо HA и HB относительно C равно 3d.

Левая полурама

ΣMCлев = VA·3d − HA·3d − P·3d − P·4d − 3P·d = 0
VA левее C, вверх — по часовой («+»); HA вправо, ниже C на 3d — против часовой («−»); P в узле 2 (левее C на 3d), P в узле 1′ (на 4d) и 3P в узле 4′ (на d) — вниз левее C, против часовой («−»).
HA = VA − (3 + 4 + 3)·P/3 = 343/6 − 10·14/3 = 343/6 − 280/6 = 63/6 = 10,5 кН

Правая полурама

ΣMCправ = −VB·3d + HB·3d + 2P·2d − P·d − (P/2)·2d = 0
VB правее C, вверх — против часовой («−»); HB влево, ниже C на 3d — по часовой («+»); 2P правее C на 2d, вниз — по часовой («+»); P вправо в узле 9′ (ниже C на d) и P/2 вправо в узле F (ниже C на 2d) — против часовой («−»).
HB = VB − (4 − 1 − 1)·P/3 = 245/6 − 2·14/3 = 245/6 − 56/6 = 189/6 = 31,5 кН
Проверка: ΣX = HA − HB + P + P/2 = 10,5 − 31,5 + 14 + 7 = 0 ✓

Шаг 4. Усилия в стержнях — вырезание узлов

Пояснение. Вырезаем узел и составляем для него два уравнения равновесия: ΣX = 0 и ΣY = 0. Поэтому начинать надо с узла, где неизвестных усилий не больше двух, и дальше идти так, чтобы в каждом следующем узле тоже оставалось не больше двух. Порядок: 1′ → 1 → 2 → A → D → E → 2′ → 3′ → 3 → 4 → 4′ → C → 6 → 6′ → 9′ → 9 → B → F → G → 8 → 8′ → 7′ → 7. Реакции уже известны, поэтому последние узлы дают четыре лишних уравнения — это проверки всего расчёта.
На схемах узлов неизвестные усилия выделены цветом, уже найденные — серые. Все направлены от узла (растяжение). Проекция усилия раскоса на оси: N·cos 45° и N·sin 45°; наклонного стержня «ноги» — N·cos α и N·sin α.

Конец левой консоли: два стержня под прямым углом и сила P. Начинаем с него — неизвестных два.

ΣX = N1′–2′ = 0
ΣY = N1–1′ − P = 0
из ΣX: ⇒ N1′–2′ = 0
из ΣY: ⇒ N1–1′ = P = 14,000 кН
ΣX = N1–2 + N1–2′·cos 45° = 0
ΣY = −N1–1′ − N1–2′·sin 45° = 0
из ΣY: ⇒ N1–2′ = −N1–1′ / sin 45° = −14,000 / 0,70711 = −19,799 кН
из ΣX: ⇒ N1–2 = −N1–2′·cos 45° = −(−19,799)·0,70711 = 14,000 кН
ΣX = −N1–2 + N2–3 = 0
ΣY = −N2–2′ − P = 0
из ΣX: ⇒ N2–3 = N1–2 = 14,000 кН
из ΣY: ⇒ N2–2′ = −P = −14,000 кН

Опорный узел: реакции VA, HA уже известны, неизвестных два.

ΣX = NE–A·cos α + HA = 0
ΣY = ND–A + NE–A·sin α + VA = 0
из ΣX: ⇒ NE–A = −HA / cos α = −10,500 / 0,44721 = −23,479 кН
из ΣY: ⇒ ND–A = −NE–A·sin α − VA = −(−23,479)·0,89443 − 57,167 = −36,167 кН

Горизонтальный стержень D–E — единственный с проекцией на ось x, а внешних сил нет, поэтому ND–E = 0.

ΣX = ND–E = 0
ΣY = N2′–D − ND–A = 0
из ΣX: ⇒ ND–E = 0
из ΣY: ⇒ N2′–D = ND–A = −36,167 кН

Оба неизвестных стержня наклонные и входят в оба уравнения — решаем их совместно.

ΣX = N3′–E·cos α − NE–A·cos α − ND–E − N2′–E·cos α = 0
ΣY = N3′–E·sin α − NE–A·sin α + N2′–E·sin α = 0
ΣX : cos α ⇒ N3′–E − N2′–E = NE–A + ND–E / cos α = (−23,479) + 0 = −23,479
ΣY : sin α ⇒ N3′–E + N2′–E = NE–A = −23,479
⇒ складываем: N3′–E = (−23,479 + (−23,479)) / 2 = −23,479 кН; N2′–E = −23,479 − (−23,479) = 0 кН
ΣX = −N1′–2′ + N2′–3′ − N1–2′·cos 45° + N2′–3·cos 45° + N2′–E·cos α = 0
ΣY = N2–2′ + N1–2′·sin 45° + N2′–3·sin 45° − N2′–D − N2′–E·sin α = 0
из ΣY: ⇒ N2′–3 = (−N2–2′ − N1–2′·sin 45° + N2′–D + N2′–E·sin α) / sin 45° = (−(−14,000) − (−19,799)·0,70711 + (−36,167)) / 0,70711 = −11,550 кН
из ΣX: ⇒ N2′–3′ = N1′–2′ + N1–2′·cos 45° − N2′–3·cos 45° − N2′–E·cos α = (−19,799)·0,70711 − (−11,550)·0,70711 = −5,833 кН
ΣX = −N2′–3′ + N3′–4′ − N3′–E·cos α = 0
ΣY = N3–3′ − N3′–E·sin α = 0
из ΣX: ⇒ N3′–4′ = N2′–3′ + N3′–E·cos α = (−5,833) + (−23,479)·0,44721 = −16,333 кН
из ΣY: ⇒ N3–3′ = N3′–E·sin α = (−23,479)·0,89443 = −21,000 кН

Шаг 5. Проверка методом сечений (способ Риттера)

Пояснение. Независимая проверка: проводим сечение через три стержня 3–4, 3–4′, 3′–4′ и составляем для левой части уравнения, в каждое из которых входит только одно неизвестное. Для N3–4 берём моменты относительно узла 4′ (там пересекаются два других стержня), для N3′–4′ — относительно узла 3, для раскоса N3–4′ — ΣY (пояса горизонтальны и в ΣY не входят).
ΣM4′ = N3–4·d + VA·2d − HA·2d − P·2d − P·3d = 0
⇒ N3–4 = −2VA + 2HA + 5P = −343/3 + 21 + 70 = −70/3 = −23,333 кН  (узлы: −23,334 кН ✓)
ΣM3 = −N3′–4′·d + VA·d − HA·3d − P·d − P·2d = 0
⇒ N3′–4′ = VA − 3HA − 3P = 343/6 − 31,5 − 42 = −49/3 = −16,333 кН  (узлы: −16,333 кН ✓)
ΣY = VA − P − P − N3–4′·sin 45° = 0
⇒ N3–4′ = (VA − 2P) / sin 45° = (57,167 − 28) / 0,70711 = 41,248 кН  (узлы: 41,248 кН ✓)
