# Ответы и проверка (только для преподавателя)

Собрано и проверено скриптом `sborka.py`. Печатная версия с окружностями — PDF «ответы».

## Как принимать работу

- **Без окружности с отмеченными корнями работу не принимать** — вернуть на доработку, даже если ответ верный.
- На рисунке должны быть все точки ответа: серия с периодом π — две противоположные точки, с периодом π/2 — четыре.
- Где корень выпадает из-за тангенса, хорошо, если точка π/2 показана выколотой: видно, что её нашли и отбросили сознательно.
- Где корней нет, отмечать нечего — но должна быть записана причина (|sin x| ≤ 1, оценка суммы); голое «нет решений» не засчитывать.
- Нетабличные точки (arccos(−2/5) и т. п.) — примерно в своей четверти, с подписью.
- Любая равносильная запись ответа засчитывается: сверять по точкам на окружности.

## 1. Вычислите

2. arccos(−√2/2) − arcsin(−√2/2) = **π**
3. arctg(−√3) + arccos(−1/2) = **π/3**
4. arcsin(−√3/2) + (arccos 0)² = **π²/4 − π/3**

8. arcsin(sin(5π/6)) = **π/6**

## 2. Решите уравнение.

9. 2cos x + √3 = 0 → **x = ±5π/6 + 2πk**, k ∈ ℤ  
   на окружности: −5π/6, 5π/6
10. 2sin x + √2 = 0 → **x = −π/4 + 2πk; x = −3π/4 + 2πk**, k ∈ ℤ  
   на окружности: −3π/4, −π/4
11. √3 tg x − 1 = 0 → **x = π/6 + πk**, k ∈ ℤ  
   на окружности: −5π/6, π/6
12. 5 + 5sin x = 0 → **x = −π/2 + 2πk**, k ∈ ℤ  
   на окружности: −π/2  
   *частный случай sin x = −1: одна точка, период 2π*
13. 3sin x + 4 = 0 → **нет решений**  
   *sin x = −4/3 < −1*
14. 5cos x + 2 = 0 → **x = ±arccos(−2/5) + 2πk**, k ∈ ℤ  
   на окружности: −α, α (α = arccos(−2/5))  
   *нетабличное значение; годится и ±(π − arccos(2/5)) + 2πk*
15. tg x + 7 = 0 → **x = −arctg 7 + πk**, k ∈ ℤ  
   на окружности: −α, π − α (α = arctg 7)  
   *тангенс не ограничен — решения есть при любом числе*
16. cos x = π/3 → **нет решений**  
   *π/3 ≈ 1,05 > 1*
17. sin x = √3 − 1 → **x = arcsin(√3 − 1) + 2πk; x = π − arcsin(√3 − 1) + 2πk**, k ∈ ℤ  
   на окружности: α, π − α (α = arcsin(√3 − 1))  
   *√3 − 1 ≈ 0,73 — в пределах [−1; 1], решения есть*
18. 4sin²x = 3 → **x = ±π/3 + πk**, k ∈ ℤ  
   на окружности: −2π/3, −π/3, π/3, 2π/3  
   *sin x = ±√3/2 — обе ветки*
19. 2cos²x = 1 → **x = π/4 + πk/2**, k ∈ ℤ  
   на окружности: −3π/4, −π/4, π/4, 3π/4  
   *четыре точки через π/2*
20. 4cos²x = 5 → **нет решений**  
   *cos²x = 5/4 > 1*
21. 2sin x + cos x = 4 → **нет решений**
