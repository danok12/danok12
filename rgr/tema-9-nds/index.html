7Полная удельная потенциальная энергия упругой деформации

Удельная энергия — энергия, приходящаяся на единицу объёма. Она складывается из двух составляющих: энергии изменения объёма и энергии изменения формы.

U₀ = U₀об + U₀ф

Полная энергия

U₀ = 1/(2E) · [σ₁² + σ₂² + σ₃² − 2ν·(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Обе суммы в квадратных скобках — это в точности инварианты тензора напряжений, поэтому беру их не через округлённые корни, а точно:

σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = (−80)² − 2·(−18425) = 6400 + 36850 = 43250 МПа² σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = −18425 МПа²
U₀ = [43250 − 2·0,3·(−18425)] / (2·2,1·10⁵) = = (43250 + 11055) / 4,2·10⁵ = 54305 / 4,2·10⁵ = 0,1293 МДж/м³

Энергия изменения формы

U₀ф = (1 + ν)/(6E) · [(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²]
σ₁ − σ₂ = 113,1101 МПа; σ₂ − σ₃ = 171,6544 МПа; σ₃ − σ₁ = −284,7646 МПа

Сумма квадратов разностей тоже выражается через инварианты точно:

(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)² = 2·(I₁н² − 3·I₂н) = 2·(6400 + 55275) = 123350 МПа² контроль по корням: 113,1101² + 171,6544² + 284,7646² = 123350,0 — сходится
U₀ф = 1,3 / (6·2,1·10⁵) · 123350 = 1,3·123350 / 1,26·10⁶ = 0,12727 МДж/м³

Энергия изменения объёма

U₀об = U₀ − U₀ф = 0,12930 − 0,12727 = 0,00203 МДж/м³ проверка по независимой формуле: U₀об = (1 − 2ν)/(6E) · I₁н² = 0,4·6400 / 1,26·10⁶ = 0,00203 МДж/м³ — совпало точно
Вывод

U₀ = 0,1293 МДж/м³ > U₀ф = 0,12727 МДж/м³. На формоизменение уходит 98,4 % всей энергии, на изменение объёма — 1,6 %: состояние близко к чистому сдвигу (первый инвариант мал по сравнению со вторым).

Про модуль сдвига G. Ту же энергию можно записать через компоненты σx…τzx: U₀ = 1/(2E)·[σx²+σy²+σz² − 2ν(σxσy+σyσz+σzσx)] + 1/(2G)·(τxy²+τyz²+τzx²). При G из задания (0,8·10⁵) получится 0,03752 + 0,09266 = 0,13018 МДж/м³ — на 0,68 % больше. Это не ошибка: в задании G округлён, а согласованное с E и ν значение G = E/[2(1+ν)] = 0,80769·10⁵ МПа даёт 0,03752 + 0,09177 = 0,1293 МДж/м³ — ровно тот же результат, что и по главным напряжениям. В отчёт идёт 0,1293 МДж/м³: формула по главным напряжениям от G не зависит.

8Проверка условия прочности по IV теории

Формулировка. Опасное состояние наступает тогда, когда удельная энергия формоизменения достигает того же значения, что и в момент наступления опасного состояния при простом одноосном напряжённом состоянии. Используется модель Фёппля — Мизеса.

σэквIV = (1/√2) · √[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²] ≤ R·γc
σэквIV = (1/√2)·√123350 = √61675 = 248,34 МПа R·γc = 210·0,9 = 189,0 МПа
Условие прочности не выполняется

σэквIV = 248,34 МПа > R·γc = 189,0 МПа — расчётное напряжение превышает предельное в 1,314 раза, то есть на 31,4 %. Прочность тела в окрестности рассматриваемой точки не обеспечена: нужно либо снизить уровень напряжений, либо применить сталь с более высоким расчётным сопротивлением R.

Связь пунктов 7 и 8. U₀ф = σэкв²/(6G) = 248,3445² / (6·0,80769·10⁵) = 0,12727 МДж/м³ — то же число, что в п. 7. Это и есть содержание энергетической теории: σэкв — одноосное напряжение с такой же энергией формоизменения.

Задача 2 · двухосное напряжённое состояниеПлоское напряжённое состояние

По условию σz = 0; τzx = τxz = 0; τzy = τyz = 0, а σx ≠ 0, σy ≠ 0, τxy ≠ 0. Такое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной по контуру.

1Тензор напряжений и напряжения на гранях элемента

По закону парности касательных напряжений τxy = τyx = −30 МПа. Для двухосного состояния тензор вырождается в матрицу 2×2:

Tн = σxτxyτyxσy = −85−30−30−30 [МПа]

Оба нормальных напряжения отрицательны, поэтому стрелки направлены к граням (сжатие); касательные напряжения тоже отрицательны и потому направлены противоположно положительному направлению осей.

2Главные напряжения

Используем кубическое уравнение

σ³ − I₁н·σ² + I₂н·σ − I₃н = 0 (1)

где для двухосного состояния

I₁н = σx + σy = −85 + (−30) = −115 МПа I₂н = σx·σy − τxy² = (−85)·(−30) − (−30)² = 2550 − 900 = 1650 МПа² I₃н = 0 — при двухосном состоянии третьего инварианта нет: определитель матрицы с нулевой строкой и столбцом равен нулю

Уравнение (1) распадается:

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0 (2)

Корень σ = 0 отвечает площадке с нормалью z: по условию на ней нет ни нормальных, ни касательных напряжений, значит ось z — главная. Квадратное уравнение из (2) даёт два оставшихся корня:

σ1,2 = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²] (3)
(σx + σy)/2 = (−85 − 30)/2 = −57,5 МПа (σx − σy)/2 = (−85 + 30)/2 = −27,5 МПа √[(−27,5)² + (−30)²] = √(756,25 + 900) = √1656,25 = 40,6971 МПа σ′ = −57,5 + 40,70 = −16,80 МПа σ″ = −57,5 − 40,70 = −98,20 МПа

Располагаем все три корня от большего к меньшему (σ₁ ≥ σ₂ ≥ σ₃):

Главные напряжения

σ₁ = 0;   σ₂ = −16,80 МПа;   σ₃ = −98,20 МПа

В примере из тетради оба плоских корня были ненулевыми и разного знака, поэтому они и оказались σ₁ и σ₂. Здесь оба отрицательны, так что нулевой корень — наибольший, и он становится σ₁. Для дальнейших пунктов (τmax, σэкв) нумерация важна, поэтому она выписана явно.

3Углы наклона главных площадок к оси x

На главной площадке касательных напряжений нет, поэтому для двухосного состояния условия на нормали дают систему:

(σx − σi)·li + τxy·mi = 0 (a) τyx·li + (σy − σi)·mi = 0 (b) (4)

где li = cos(σi^x), mi = cos(σi^y) — направляющие косинусы нормали к i-й главной площадке. Ось y направлена вниз, поэтому

li = cos αi; mi = cos(αi + 90°) = −sin αi

Подставляем в (b) и делим на cos αi:

τyx·cos αi − (σy − σi)·sin αi = 0 → tg αi = τyx / (σy − σi) (5)
при i = 2 (σ₂ = −16,80 МПа): tg α₂ = −30 / (−30 + 16,8029) = −30 / (−13,1971) = 2,2732 → α₂ = +66,26° при i = 3 (σ₃ = −98,20 МПа): tg α₃ = −30 / (−30 + 98,1971) = −30 / 68,1971 = −0,4399 → α₃ = −23,74°

Проверка. Главные площадки взаимно перпендикулярны, поэтому

|α₂| + |α₃| = 66,26° + 23,74° = 90,00° ✓

Дополнительная проверка — подстановкой найденных косинусов обратно в систему (4):

Оба уравнения обращаются в нуль — углы найдены верно. Третья главная площадка — это площадка с нормалью z (σ₁ = 0): она совпадает с плоскостью пластины и перпендикулярна двум найденным.

Построение — как «Рисунок 2» в тетради. В разобранном на занятии примере σ₁ = 100 МПа было растягивающим, и стрелки шли от грани, а σ₂ = −25 МПа — сжимающим, стрелки шли к грани. Здесь растягивающих главных напряжений нет вовсе, поэтому обе пары стрелок направлены внутрь.

Сверка с «школьной» формулой. Тот же результат даёт tg 2α₀ = 2τxy/(σx − σy) = −60/−55 = 1,0909 → 2α₀ = 47,49°, α₀ = 23,74°. Эта формула записана для системы с осью y вверх и углом против часовой стрелки: там σ₃ = −98,20 МПа лежит под +23,74°, а σ₂ = −16,80 МПа — под 113,74°. Формула (5) из тетради использует ось y вниз, поэтому углы получаются зеркальными: −23,74° и +66,26°. Взаимное расположение площадок и величины напряжений одинаковы, различается только знак отсчёта угла. В отчёт идут углы по формуле (5), а рисунок выполняется в тех же осях, что и схема элемента.
