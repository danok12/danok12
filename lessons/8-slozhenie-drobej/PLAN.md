## Алгоритм

1. Разложить знаменатели (общий множитель, `a² − b²`, `(a ± b)²`).
2. Общий знаменатель: каждый множитель один раз.
3. Дополнительные множители — «уголком» над дробью.
4. Числитель вычитаемой дроби — **в скобках**.
5. Упростить, проверить сокращение, проверить подстановкой числа.

Знаки: `b − a = −(a − b)`; `1 + 3p = 3p + 1` (знак не меняется).

## Решения ДЗ

**№ 86** (общий знаменатель — произведение):
- а) `((b−c)(b+c) + b²)/(b(b+c)) = (2b² − c²)/(b(b+c))`
- б) `(x(x+1) − (x+3)(x−2))/(x(x−2)) = (x²+x − x²−x+6)/(…) = 6/(x(x−2))`
- в) `(m(m+n) − n(m−n))/(m²−n²) = (m²+n²)/(m²−n²)`
- г) `(2a(2a+1) − (2a−1))/(4a²−1) = (4a²+1)/(4a²−1)`
- д) `(a(a−2) − a(a+2))/(a²−4) = −4a/(a²−4)`
- е) `(p(3p+1) − p(3p−1))/(9p²−1) = 2p/(9p²−1)`

**№ 96**:
- а) `a²−2a = a(a−2)`, `a²−4 = (a−2)(a+2)`; `((a+4)(a+2) − a²)/(a(a−2)(a+2)) = (6a+8)/(a(a²−4)) = 2(3a+4)/(a(a²−4))`. Проверка при a = 3: 26/15 и 26/15.
- б) `16−x² = (4−x)(4+x)`; `(4 − x² − (x+1)(4−x))/(16−x²) = −3x/(16−x²) = 3x/(x²−16)`
- в) `(a+b)/a + (a−b)/a = 2a/a = 2` (a ≠ 0, a ≠ ±b)
- г) `(x+2)/5 − (x+2)/5 = 0` (x ≠ ±2)

## Типовые ошибки

| № | Как выглядит | Откуда | Как поймать |
|---|---|---|---|
| 1 | `−(y²−y−12)` → `−y² − y − 12` | знак сменили только у первого слагаемого | подстановка |
| 2 | `(b − b)/((b−5)(b+5)) = 0` | не домножили числители | b = 1: −1/4 − 1/6 ≠ 0 |
| 3 | `k/(1−2k)` → `k/(2k−1)` без смены знака дроби | `b − a = −(a − b)` | подстановка |
| 4 | `(5a+6)/(a(a+3)) = 11/(a+3)` | сокращение слагаемого | при a = 1 совпало случайно, при a = 2 — нет |
| 5 | `(x+y)² = x² + y²` | формула квадрата суммы | громоздкий ответ |

Заметка: подставлять 2–3 «некруглых» числа, не 0 и не 1 (ошибка 4 при a = 1 не ловится).
