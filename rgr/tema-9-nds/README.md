# Тема № 9. Исследование НДС в окрестности точки тела (РГР)

Задача 2 (двухосное напряжённое состояние): σx по строке 29,
σy по строке 8, τxy по строке 25.

Документ собран целиком: **пункты 1–9 и выводы**. Решение задачи 1 из
документа убрано по просьбе автора — оно осталось в истории git.

Порядок решения и обозначения повторяют разбор на практическом занятии:
главные напряжения нумеруются не по убыванию, а по конспекту (σ₁ и σ₂ — оба
в плоскости пластины, σ₃ = 0); углы — по формуле tg αi = τyx/(σy − σi) при оси y,
направленной вниз; U₀ = U₀^об + U₀^ф через главные напряжения;
σ_экв^IV по модели Фёппля — Мизеса; углы на круге Мора — через полюс K(σy; τxy),
как в конспекте.

## Схемы

Все семь схем черчатся в **едином масштабе**: одна единица `viewBox` =
0,187 мм на листе (`MM_NA_ED` в `sborka-pdf.py`). Круг Мора (рис. 7) при этом
выходит в натуральном масштабе тетради: `MPA = 1/0,187` единиц на 1 МПа, то есть
1 МПа = 1 мм, 1 см = 10 МПа; `proverka.py` снимает с чертежа координаты всех
точек и сверяет их с расчётом. Поэтому подписи на всех
схемах одного кегля — около 9 пт, чуть мельче основного текста, — а ширина
схемы определяется её содержимым, а не шириной полосы. Раньше каждая схема
растягивалась на всю полосу, и подписи выходили крупнее текста.

| рисунок | что показывает |
|---|---|
| 1 | тонкая пластина и вырезанный из неё объёмный элемент |
| 2 | заданные напряжения на гранях плоского элемента |
| 3 | главный элемент, углы α₁ и α₂ |
| 4 | площадки экстремальных касательных напряжений в плоскости |
| 5 | напряжения на площадках под α = 15° |
| 6 | линейные и угловая деформации элемента (аксонометрия) |
| 7 | круг Мора в масштабе 1 см = 10 МПа: построение, прямые из полюса K (1, 2, x₁, y₁, ν, t) и размеры координат P, P′ — на одной окружности |

Аксонометрия: z вверх, x вправо, y на зрителя — как на схеме элемента в тетради.
В рис. 6 каждый куб деформируется простым сдвигом (один недиагональный член,
как на плоских схемах) с увеличением углов примерно в 240 раз; вершина угла
выбирается автоматически — ближайшая к наблюдателю. Знаки проверяются скриптом:
при γ > 0 угол на рисунке действительно уменьшается, при γ < 0 увеличивается.

## Проверка чисел

Три независимых уровня:

1. `raschet.py` — расчёт в точной арифметике (`Fraction`), корни уравнений
   ньютоновскими итерациями с 50 знаками.
2. `proverka.py` — **перепроверка другими методами**: корни — подстановкой
   в det(Tн − σE) = 0, направляющие косинусы — из условия Tн·ν = σ·ν (невязка
   ~10⁻¹⁴), правило полюса круга Мора — наклоном отрезка от K до точки
   площадки, найденной прямым T·ν, удельная энергия — свёрткой ½·σij·εij, эквивалентное напряжение —
   через девиатор √(3/2·sij·sij), τmax — как (σ1 − σ3)/2. Допуск в каждом
   сравнении — половина единицы последнего разряда, округлённого в тексте.

## Пересчёт и пересборка

```bash
python3 raschet.py      # расчёт с проверками
python3 proverka.py     # независимая перепроверка
python3 figures.py      # перерисовать схемы
python3 ../obrezka-svg.py .   # подрезать viewBox по содержимому
python3 sborka-pdf.py   # index.html + print.html + PDF
```

## Обрезка схем

`../obrezka-svg.py` открывает схемы в Chromium, берёт `svg.getBBox()`
и переписывает `viewBox` по фактическому содержимому. Без этого снизу
остаётся пустое поле: на экране незаметно, а в PDF рисунок из-за него
выходит мельче. Запускать после `figures.py`:

```bash
python3 ../obrezka-svg.py .
```
