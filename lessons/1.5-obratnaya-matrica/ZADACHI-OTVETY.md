## Тема 1

**1.1.** Да: `3·2 + 5·(−1) = 1`, `3·(−5) + 5·3 = 0`, `1·2 + 2·(−1) = 0`, `1·(−5) + 2·3 = 1` — получилось `E`.

**1.2.** Нет: произведение равно `−2·E`. Это `Ã`, забыли поделить на `|A| = −2`. Верно: `|−2 1; 3/2 −1/2|`.

**1.3.** Нет. Если `A` имеет размер `2×3`, а `X` — `3×2`, то `A·X` будет `2×2`, а `X·A` — `3×3`. Обе не могут равняться одной и той же `E`.

**1.4.** Для квадратных матриц достаточно: из `A·B = E` автоматически следует `B·A = E`.

## Тема 7

**7.1.**
```
|A⁻¹|    = 1/(-2) = -1/2
|A²|     = (-2)²  = 4
|(A')⁻¹| = -1/2            (определитель при транспонировании не меняется)
|3A|     = 3³·(-2) = -54   (множитель выносится из КАЖДОЙ из трёх строк)
|(3A)⁻¹| = -1/54
```
Главная в списке — `|3A|`: почти все пишут `3·(−2)`.

**7.2.** `(AB)⁻¹ = B⁻¹·A⁻¹ = |1 0; 3 1|·|1 2; 0 1| = |1 2; 3 7|`. В неверном порядке вышло бы `|7 2; 3 1|` — другая матрица.

**7.3.** Неверно. `(2A)·(½A⁻¹) = E`, значит `(2A)⁻¹ = ½·A⁻¹`.

**7.4.** По свойству 5: `(A⁻¹)' = (A')⁻¹ = A⁻¹`. Матрица, равная своей транспонированной, симметрична. ∎

**7.5.** `A²·(A⁻¹)² = A·A·A⁻¹·A⁻¹ = A·E·A⁻¹ = E`. По единственности обратной это и есть `(A²)⁻¹`. ∎

## Тема 8

Проверка: `A·X = (3/2, 3)` и `2X + B = (3/2, 3)` ✓

## Тема 9

**9.1.** `|A| = 1`, `A⁻¹ = |2 −5; −1 3|`, отсюда `x = 2·8 − 5·3 = 1`, `y = −8 + 9 = 1`. Проверка: `3 + 5 = 8` ✓, `1 + 2 = 3` ✓

**9.2.** `x = 1·5 − 2·7 + 6·2 = 3`, `y = 7 − 3·2 = 1`, `z = 2`. Проверка: `3 + 2 = 5` ✓, `1 + 6 = 7` ✓
*Вопрос:* эту систему видно и без матриц, снизу вверх. Зачем метод? — При готовой `A⁻¹` можно мгновенно решить систему **с любой** правой частью, не начиная сначала.

**9.3.** `|A| = 4 − 4 = 0` — обратной нет, метод неприменим. Левая часть второго уравнения вдвое больше первого, а правая — нет: система несовместна, решений нет вовсе. `|A| = 0` означает «матричный метод не работает», а дальше нужны ранг и теорема Кронекера–Капелли — следующая тема учебника.

## Тема 10

**10.1.** `A² − 3A = −2E` → `A·(A − 3E) = −2E` → `A·(3E − A)/2 = E`, значит `A⁻¹ = (3E − A)/2`. Заодно доказано, что `A` обратима, хотя саму матрицу нам не показывали.

**10.2.** Нет. Из `A³ = 0` следует `|A|³ = 0`, значит `|A| = 0`. (Второй способ: будь `A⁻¹`, умножили бы `A³ = 0` на неё трижды и получили `E = 0`.)

**10.3.** `(E − A)(E + A) = E + A − A − A² = E − 0 = E`, значит `(E − A)⁻¹ = E + A`. Матричный аналог `1/(1−x) = 1 + x + x² + …`, где ряд обрывается, потому что `A² = 0`.

**10.4.** `|A| = λ·(λ² − 0) − 1·(0 − 1) + 0 = λ³ + 1`. Обратной нет при `λ³ = −1`, то есть при `λ = −1` (среди действительных — единственное значение).

**10.5.** Возьмём обратную от обеих частей `AB = BA`. Слева по свойству 4 получится `B⁻¹A⁻¹`, справа `A⁻¹B⁻¹`. Раз матрицы равны, равны и их обратные: `B⁻¹A⁻¹ = A⁻¹B⁻¹`. ∎
