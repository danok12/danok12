## Как проверены ответы

Задачи записаны в `src/` на LaTeX, ответы считаются из того же текста через sympy, а не набираются
руками. Если ответ всё же набран вручную (упрощение дроби, вычисление в градусах, ответ
параметрической задачи), сборка сверяет его с вычисленным и падает при расхождении.

- Уравнения: корни подставляются в исходное уравнение с проверкой ОДЗ (знаменатели, корни, логарифмы).
  Если sympy не справился сам, корни дополнительно ищутся численно на сетке.
- Ответы ЕГЭ части 1 обязаны быть целым числом или конечной десятичной дробью, иначе сборка падает.
- Тригонометрия части 2: каждая точка заявленных серий — корень, а численный поиск на $[-4\pi;\,4\pi]$
  не находит корней вне серий. Отбор на отрезке считается точно.
- Параметры: заявленный ответ сверяется с прямым подсчётом корней примерно при 100 значениях $a$,
  включая граничные точки и их окрестности $\pm0{,}001$.
- Формулы справочника Матвея проверены численно в случайных точках, таблицы значений и формул
  приведения сгенерированы sympy.
- Сечения: многоугольник считается пересечением плоскости с рёбрами. Невидимые рёбра на чертежах
  определяются по нормалям граней.

## Пересборка

```bash
pip install sympy antlr4-python3-runtime==4.11 mpmath
cd dz/2026-10-18/src
python3 build.py            # все листы + ответы (≈2 минуты)
python3 build.py Варвара    # один лист, без листа ответов
```

KaTeX лежит в `dz/_katex/`: формулы рендерятся без сети. Промежуточные HTML попадают в `_build/`,
в репозиторий они не коммитятся.
