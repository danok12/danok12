### 7. Полная удельная потенциальная энергия упругой деформации

Удельная энергия — энергия, приходящаяся на единицу объёма. Она складывается
из двух составляющих: энергии изменения объёма и энергии изменения формы:

**U₀ = U₀^об + U₀^ф**

**Полная энергия:**

U₀ = 1/(2E) · [σ₁² + σ₂² + σ₃² − 2ν·(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Суммы в квадратных скобках — это в точности инварианты тензора напряжений,
поэтому их беру не через округлённые корни, а точно:

* σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = (−80)² − 2·(−18425) = 6400 + 36850 = **43250 МПа²**;
* σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = **−18425 МПа²**.

U₀ = [43250 − 2·0,3·(−18425)] / (2·2,1·10⁵) = (43250 + 11055) / 4,2·10⁵ =
54305 / 4,2·10⁵ = **0,1293 МДж/м³**

**Энергия изменения формы:**

U₀^ф = (1 + ν)/(6E) · [(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²]

Разности главных напряжений:

σ₁ − σ₂ = 113,1101 МПа;  σ₂ − σ₃ = 171,6544 МПа;  σ₃ − σ₁ = −284,7646 МПа.

Сумма квадратов тоже выражается через инварианты точно:

(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)² = 2·(I₁н² − 3·I₂н) = 2·(6400 + 55275) = **123350 МПа²**

(контроль по корням: 113,1101² + 171,6544² + 284,7646² = 123350,0 — сходится).

U₀^ф = 1,3 / (6·2,1·10⁵) · 123350 = 1,3 · 123350 / 1,26·10⁶ = **0,12727 МДж/м³**

**Энергия изменения объёма:**

U₀^об = U₀ − U₀^ф = 0,12930 − 0,12727 = **0,00203 МДж/м³**

Проверка по независимой формуле:
U₀^об = (1 − 2ν)/(6E) · I₁н² = 0,4 · 6400 / 1,26·10⁶ = 0,00203 МДж/м³ — **совпало точно**.

**Вывод:** U₀ = 0,1293 МДж/м³ > U₀^ф = 0,12727 МДж/м³. На формоизменение уходит
98,4 % всей энергии, на изменение объёма — лишь 1,6 %: состояние близко к чистому
сдвигу (первый инвариант мал по сравнению со вторым).

> **Про G.** Ту же энергию можно записать через компоненты σ_x…τ_zx:
> U₀ = 1/(2E)·[σ_x²+σ_y²+σ_z² − 2ν(σ_xσ_y+σ_yσ_z+σ_zσ_x)] + 1/(2G)·(τ_xy²+τ_yz²+τ_zx²).
> При G из задания (0,8·10⁵) получится 0,03752 + 0,09266 = 0,13018 МДж/м³ — на 0,68 %
> больше. Расхождение не ошибка: в задании G округлён, а согласованное с E и ν значение
> G = E/[2(1+ν)] = 0,80769·10⁵ МПа даёт 0,03752 + 0,09177 = 0,1293 МДж/м³, то есть
> ровно тот же результат, что и по главным напряжениям. **В отчёт беру 0,1293 МДж/м³** —
> формула по главным напряжениям от G не зависит и потому точнее.

### 8. Проверка условия прочности по IV (энергетической) теории

**Формулировка.** Опасное состояние наступает тогда, когда удельная энергия
формоизменения достигает того же значения, что и в момент наступления опасного
состояния при простом одноосном растяжении. Используется модель Фёппля — Мизеса.

σ_экв^IV = (1/√2) · √[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²] ≤ R·γ_c

σ_экв^IV = (1/√2) · √123350 = √61675 = **248,34 МПа**

R·γ_c = 210 · 0,9 = **189,0 МПа**

σ_экв^IV = 248,34 МПа **> R·γ_c = 189,0 МПа**

**Условие прочности по IV теории НЕ выполняется:** расчётное напряжение превышает
предельное в 1,314 раза, то есть на **31,4 %**. Прочность тела в окрестности
рассматриваемой точки не обеспечена — нужно либо снизить уровень напряжений,
либо применить сталь с более высоким расчётным сопротивлением R.

Контроль связи пунктов 7 и 8: U₀^ф = σ_экв² / (6G) = 248,3445² / (6·0,80769·10⁵) =
0,12727 МДж/м³ — совпадает с п. 7.

## ЗАДАЧА 2. Двухосное (плоское) напряжённое состояние

### Дано

По условию σ_z = 0; τ_zx = τ_xz = 0; τ_zy = τ_yz = 0, а σ_x ≠ 0, σ_y ≠ 0, τ_xy ≠ 0.
Такое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной по контуру.

| Источник | σ_x | σ_y | τ_xy |
|---|---|---|---|
| Строка № 29 | −85 | — | — |
| Строка № 8 | — | −30 | — |
| Строка № 25 | — | — | −30 |
| **Принято к расчёту** | **−85** | **−30** | **−30** |

Все значения в МПа. Сталь: E = 2,1·10⁵ МПа; G = 0,8·10⁵ МПа; R = 210 МПа; γ_c = 0,9; ν = 0,3.

### 1. Тензор напряжений для двухосного состояния

По закону парности касательных напряжений τ_xy = τ_yx = −30 МПа.

Для двухосного состояния тензор вырождается в матрицу 2×2:

T_н = | σ_x  τ_xy ;  τ_yx  σ_y | = | −85  −30 ;  −30  −30 |  [МПа]

Напряжения на гранях элемента показаны на рис. 2.1. Оба нормальных напряжения
отрицательны, поэтому стрелки направлены **к граням** (сжатие); касательные
напряжения отрицательны и потому направлены противоположно положительному
направлению осей (рис. 2.1).

### 2. Главные напряжения и главные площадки

Используем кубическое уравнение

σ³ − I₁н·σ² + I₂н·σ − I₃н = 0,  (1)

где для двухосного состояния

* I₁н = σ_x + σ_y = −85 + (−30) = **−115 МПа**;
* I₂н = σ_x·σ_y − τ_xy² = (−85)·(−30) − (−30)² = 2550 − 900 = **1650 МПа²**;
* I₃н = 0 — **при двухосном состоянии третьего инварианта нет** (определитель
  матрицы с нулевой строкой и столбцом равен нулю).

Уравнение (1) распадается:

σ·(σ² − I₁н·σ + I₂н) = 0  →  σ = 0  или  σ² + 115σ + 1650 = 0.  (2)

Корень σ = 0 отвечает площадке с нормалью z: по условию на ней нет ни нормальных,
ни касательных напряжений, значит ось z — главная.

Квадратное уравнение из (2) даёт два оставшихся корня:

σ_1,2 = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σ_x + σ_y)/2 ± √[((σ_x − σ_y)/2)² + τ_xy²]  (3)

Подставляем:

* (σ_x + σ_y)/2 = (−85 − 30)/2 = −57,5 МПа;
* (σ_x − σ_y)/2 = (−85 + 30)/2 = −27,5 МПа;
* √[(−27,5)² + (−30)²] = √(756,25 + 900) = √1656,25 = 40,6971 МПа.

σ' = −57,5 + 40,70 = **−16,80 МПа**;  σ'' = −57,5 − 40,70 = **−98,20 МПа**.

Располагаем все три корня от большего к меньшему (σ₁ ≥ σ₂ ≥ σ₃):

**σ₁ = 0;  σ₂ = −16,80 МПа;  σ₃ = −98,20 МПа**

> В примере из тетради оба плоских корня были ненулевыми и разного знака, поэтому
> они и оказались σ₁ и σ₂. Здесь оба отрицательны, так что нулевой корень —
> наибольший, и он становится σ₁. Для дальнейших пунктов (τ_max, σ_экв) нумерация
> важна, поэтому она выписана явно.

**Проверка по инвариантам**

| инвариант | через компоненты | через главные напряжения |
|---|---|---|
| I₁н | σ_x + σ_y = −85 − 30 = **−115 МПа** | σ₁ + σ₂ + σ₃ = 0 − 16,8029 − 98,1971 = **−115 МПа** |
| I₂н | σ_x·σ_y − τ_xy² = 2550 − 900 = **1650 МПа²** | σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = 0 + 1650,0 + 0 = **1650 МПа²** |
| I₃н | 0 | σ₁·σ₂·σ₃ = **0** |

Все инварианты совпали — главные напряжения найдены верно.

**Вид напряжённого состояния:** оба ненулевых главных напряжения отрицательны,
третье равно нулю — **двухосное сжатие**.

### 3. Углы наклона главных площадок к оси x

Условие на главной площадке для двухосного напряжённого состояния (касательных
напряжений на ней нет):

(σ_x − σ_i)·l_i + τ_xy·m_i = 0  (a)
τ_yx·l_i + (σ_y − σ_i)·m_i = 0  (b)  (4)

где l_i = cos(σ_i^x), m_i = cos(σ_i^y) — направляющие косинусы нормали к i-й главной
площадке. Ось y направлена вниз (как на схеме элемента), поэтому

l_i = cos α_i;  m_i = cos(α_i + 90°) = −sin α_i.

Подставляем в (b) и делим на cos α_i:

τ_yx·cos α_i − (σ_y − σ_i)·sin α_i = 0  →  **tg α_i = τ_yx / (σ_y − σ_i)**  (5)

**Для σ₂ = −16,80 МПа:**

tg α₂ = −30 / (−30 + 16,8029) = −30 / (−13,1971) = 2,2732  →  **α₂ = +66,26°**

**Для σ₃ = −98,20 МПа:**

tg α₃ = −30 / (−30 + 98,1971) = −30 / 68,1971 = −0,4399  →  **α₃ = −23,74°**

**Проверка:** главные площадки взаимно перпендикулярны, поэтому

|α₂| + |α₃| = 66,26° + 23,74° = **90,00°** ✓

Дополнительная проверка — подстановкой косинусов обратно в систему (4):

| нормаль | l = cos α | m = −sin α | l² + m² | ур. (a) | ур. (b) |
|---|---|---|---|---|---|
| ν₂ (σ₂), α = 66,26° | 0,40266 | −0,91535 | 1,000000 | 0,000000 | 0,000000 |
| ν₃ (σ₃), α = −23,74° | 0,91535 | 0,40266 | 1,000000 | 0,000000 | 0,000000 |

Оба уравнения обращаются в нуль — углы найдены верно.

Третья главная площадка — это площадка с нормалью z (σ₁ = 0), она совпадает
с плоскостью пластины и перпендикулярна двум найденным.

**Главный элемент** (рис. 2.2) строится так же, как «Рисунок 2» в тетради:
от оси x вверх откладывается α₂ = 66,26°, перпендикулярно ему — направление
третьей нормали (α₃ = −23,74°); на этих направлениях и стоят грани главного
элемента. Оба главных напряжения сжимающие, поэтому стрелки направлены
**к граням** (в примере тетради σ₁ = 100 МПа было растягивающим и стрелки шли
от грани, а σ₂ = −25 МПа — сжимающим, стрелки к грани).

> **Сверка с «школьной» формулой.** Тот же результат даёт tg 2α₀ = 2τ_xy/(σ_x − σ_y) =
> −60/−55 = 1,0909 → 2α₀ = 47,49°, α₀ = 23,74°. Эта формула записана для правой
> системы с осью y **вверх** и углом, отсчитываемым против часовой стрелки: там
> σ₃ = −98,20 МПа лежит под +23,74°, а σ₂ = −16,80 МПа — под 113,74°. Формула (5)
> из тетради использует ось y **вниз**, поэтому углы получаются зеркальными:
> −23,74° и +66,26°. Взаимное расположение площадок и величины напряжений
> одинаковы, отличается только знак отсчёта угла. **В отчёт идут углы по формуле (5)
> тетради**, а рисунок выполняется в тех же осях, что и на схеме элемента.
