# Журнал ДЗ

Страница для учёта домашних заданий: кому выдано, что сдать, до какого числа.
Опубликована как Artifact: <https://claude.ai/artifact/RgvM5VVxATnFzx9f1SKiDu>

Здесь лежит исходник `index.html` — контейнер сессии временный, а страница должна пережить его.

## Что решает

Один взгляд отвечает на три вопроса:

| Вопрос | Где ответ |
|---|---|
| Выдано ли человеку ДЗ | цвет полоски слева и строка «ДЗ не выдано»; фильтр «Без ДЗ» со счётчиком |
| Что он должен сдать | колонка «Что сдать» — тема и примечание |
| До какого числа | колонка «Срок» — дата и словами: «просрочено 2 дня», «сдать завтра», «осталось 5 дней» |

Цвет считается от сегодняшней даты, вручную статусы не переставляются:

- красный — просрочено
- янтарный — сдавать сегодня или завтра
- петролевый — в работе
- зелёный — сдано
- серый — задания нет

Строки по умолчанию идут по срочности: просроченные сверху, «без ДЗ» и «сдано» внизу.

## Работа с таблицей

- **Выдать ДЗ группе.** Отметить галочками нужных (или выбрать всех в текущем фильтре
  верхней галочкой) → «Выдать одно ДЗ» → тема, срок, примечание. Одна форма на 30 человек.
- **Отметить сдачу.** Кнопка «Сдал ✓» в строке, либо массово по выбранным.
- **Карточка ученика** (кнопка «⋯») — переименовать, сменить группу, поправить тему и срок,
  продлить на 3 дня или неделю, снять отметку, убрать ДЗ, удалить ученика. Там же история
  прошлых заданий (последние 15).
- **Добавить учеников** — «+ Ученики», список ФИО по одному в строке, можно вставить все 40 разом.
- **CSV** — выгружает то, что сейчас на экране, с учётом фильтра и поиска; разделитель `;`,
  BOM в начале, чтобы Excel не ломал кириллицу.

## Где хранятся данные

**В самой странице.** Журнал лежит в начале документа как `var DATA = {...}`, а страница умеет
пересобрать свой полный исходник и переиздать себя новой версией (capability `artifact`).

Почему так, а не в базе: artifact с базой (`db`) платформа держит внутренним — публичной ссылки
у него быть не может, и незалогиненный человек не увидит данных вовсе. Хранение внутри страницы
снимает оба ограничения: ссылку можно сделать публичной, и она открывается где угодно без входа.

Как устроена пересборка: весь код — одна функция `APP(DATA)`, поэтому документ собирается как
статическая «шапка» + `APP.toString()` + текущие данные. Рекурсии нет, круг проверен: после
переиздания исходник функции совпадает символ в символ, `<` в данных экранируется в `<`,
чтобы не разорвать тег `script`.

Последствия, о которых стоит помнить:

- сохранение отложенное — через 2 секунды после последнего изменения, чтобы серия отметок
  ушла одним переизданием; в шапке видно «есть несохранённое» и кнопка «Сохранить сейчас»;
- **после сохранения страница перезагружается** на свежую версию — во всех открытых копиях;
- пока идёт сохранение, кнопки заблокированы, иначе правка потерялась бы при перезагрузке;
- если закрыть вкладку с несохранёнными правками, браузер переспросит;
- одновременная правка двумя людьми разрешается по принципу «кто успел»: проигравший получает
  сообщение и версию победителя, его правка теряется. Для одного преподавателя это неважно.

```js
DATA = { students: [ {
  id, name, group,
  hw: { title, due, issued, status: "issued|done", doneAt, note } | null,
  done: [ { title, due, status, doneAt } ]   // последние 15
} ], rev, savedAt }
```

## Публичная ссылка

Страница по умолчанию приватная. Чтобы открыть её всем: меню **Share** на странице →
общий доступ по ссылке. После этого ссылка работает у любого человека, без аккаунта и без входа.

Что важно понимать:

- **ссылку видно всем, кому её передали** — а вместе с ней все ФИО, темы и просрочки;
- **отмечать сдачу может только владелец** (и тот, кому выдан уровень Can edit). У остальных
  страница сама переходит в режим «только просмотр» — кнопки блокируются, данные не портятся;
- сами вы открываете её с любого устройства, войдя в свой аккаунт Claude, — и отмечаете оттуда.

Если публичность не нужна, а нужно показать паре коллег — вместо общей ссылки добавить их
поимённо в том же меню Share.

## Как обновлять исходник

Править `index.html` и публиковать поверх того же артефакта, передав его URL. Учесть, что
страница переиздаёт себя сама: свежие данные живут в опубликованной версии, а не в этом файле,
поэтому перед правкой стоит забрать актуальный `DATA` из опубликованной страницы, иначе журнал
откатится к пустому.
