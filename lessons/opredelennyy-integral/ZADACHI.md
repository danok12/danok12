# Определённый интеграл — задачи

Первый курс. Формула Ньютона—Лейбница, свойства, замена переменной,
интегрирование по частям. 45 задач, пять блоков по нарастанию.

**Уровень:** ★ базовый · ★★ средний · ★★★ повышенный

**Как записаны пределы.** `∫(a..b) f(x) dx` — интеграл от `a` до `b`.

---

## Что понадобится

| f(x) | F(x) | | f(x) | F(x) |
|---|---|---|---|---|
| `xⁿ`, n ≠ −1 | `xⁿ⁺¹/(n+1)` | | `sin x` | `−cos x` |
| `1/x` | `ln\|x\|` | | `cos x` | `sin x` |
| `eˣ` | `eˣ` | | `1/cos²x` | `tg x` |
| `1/√x` | `2√x` | | `1/sin²x` | `−ctg x` |
| `1/(1+x²)` | `arctg x` | | `1/√(1−x²)` | `arcsin x` |

**Формула Ньютона—Лейбница:** `∫(a..b) f(x) dx = F(b) − F(a)`, где `F′ = f`,
а `f` **непрерывна на всём отрезке** `[a; b]`.

**Замена:** `∫(a..b) f(φ(t))·φ′(t) dt = ∫(φ(a)..φ(b)) f(x) dx` —
пределы пересчитываются вместе с переменной, возвращаться к старой не нужно.

**По частям:** `∫(a..b) u dv = uv|(a..b) − ∫(a..b) v du`.

## Блок F. Найди ошибку

В каждом решении ровно одна ошибка. Скажи, где она, почему это ошибка
и какой ответ верный.

**F1.** ★★

```
∫(0..2) x(x² + 1)³ dx
Замена t = x² + 1, dt = 2x dx:
= ½·∫(0..2) t³ dt = ½·t⁴/4 |(0..2) = ½·16/4 = 2
```

**F2.** ★★★

```
∫(−1..1) dx/x² = ∫(−1..1) x⁻² dx = −1/x |(−1..1) = −1 − 1 = −2
```

**F3.** ★★

```
∫(−2..−1) dx/x = ln x |(−2..−1) = ln(−1) − ln(−2)
```

**F4.** ★

```
∫(0..π) sin x dx = 0, потому что sin x — нечётная функция
```

**F5.** ★★

```
∫(0..π) x·sin x dx
u = x, dv = sin x dx  →  du = dx, v = −cos x
= ∫(0..π) cos x dx = sin x |(0..π) = 0
```
