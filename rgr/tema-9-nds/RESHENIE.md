## 1. Тензор напряжений и напряжения на гранях элемента

По закону парности τxy = τyx = −30 МПа.

Tн = | σx  τxy ; τyx  σy | = | −85  −30 ; −30  −30 |  [МПа]

Плоское напряжённое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной
силами в её плоскости. На лицевых поверхностях пластины нагрузки нет, поэтому
σz = 0 и τzx = τzy = 0 (рис. 1).

Оба нормальных напряжения отрицательны, стрелки направлены к граням (сжатие);
касательные тоже отрицательны и направлены противоположно положительному
направлению осей. Отличны от нуля только три компоненты, поэтому элемент достаточно
изобразить плоским — проекцией на плоскость xOy (рис. 2).

## 2. Главные напряжения

Главные напряжения — корни характеристического уравнения
`σ³ − I₁н·σ² + I₂н·σ − I₃н = 0` (1). Для плоского состояния
инварианты сворачиваются к двум:

* I₁н = σx + σy = **−115 МПа**
* I₂н = σx·σy − τxy² = 2550 − 900 = **1650 МПа²**
* I₃н = **0** — при двухосном состоянии третьего инварианта нет

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0.

Корень σ = 0 отвечает площадке с нормалью z: на ней нет ни нормальных, ни
касательных напряжений, значит ось z — главная. Квадратное уравнение даёт:

σ₃,₂ = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx + σy)/2 ± √[((σx − σy)/2)² + τxy²]

* (σx + σy)/2 = −57,5 МПа; (σx − σy)/2 = −27,5 МПа
* √(756,25 + 900) = √1656,25 = 40,6971 МПа
* σ′ = −16,80 МПа; σ″ = −98,20 МПа

Нумеруем как на занятии: σ₁ и σ₂ — оба корня в плоскости пластины
(σ₁ — больший), третье главное напряжение равно нулю:

**σ₃ = 0; σ₁ = −16,80 МПа; σ₂ = −98,20 МПа**

> В примере с занятия оба плоских корня были ненулевыми и разного знака, поэтому
> они и оказались σ₃ и σ₁. Здесь оба отрицательны, так что нулевой корень —
> наибольший, и он становится σ₃.

## 4. Экстремальные касательные напряжения

**Зачем этот пункт.** По главным площадкам касательных напряжений нет вовсе —
в этом их определение. Но рядом есть площадки, где касательное напряжение
наибольшее: по ним материал начинает течь. Такая площадка делит пополам прямой
угол между двумя главными направлениями, то есть наклонена к ним под ±45°.
Пар главных напряжений три — значит, и семейств площадок три.

```
τij = ±(σi − σj)/2,   σ' = (σi + σj)/2          (3)
```

Подставляем σ₁ = −16,8029; σ₂ = −98,1971; σ₃ = 0 МПа:

```
пара σ₁, σ₂ — площадки в плоскости пластины:
  τ₁₂ = ±(−16,8029 + 98,1971)/2 = ±81,3942/2 = ±40,70 МПа
  σ'  =  (−16,8029 − 98,1971)/2 = −115,0000/2 = −57,50 МПа

пара σ₂, σ₃ — площадки наклонены к плоскости пластины:
  τ₂₃ = ±(−98,1971 − 0)/2 = ±98,1971/2 = ±49,10 МПа
  σ'  =  (−98,1971 + 0)/2 = −49,10 МПа

пара σ₃, σ₁ — площадки наклонены к плоскости пластины:
  τ₃₁ = ±(0 + 16,8029)/2 = ±16,8029/2 = ±8,40 МПа
  σ'  =  (0 − 16,8029)/2 = −8,40 МПа
```

Наибольшее из трёх — вторая пара: **τmax = τ₂₃ = 49,10 МПа.**

> Первая строка, 40,70 МПа, — это радиус круга Мора по σx, σy, τxy: её и дала бы
> формула «в плоскости», если ограничиться одним кругом. Но наибольшее касательное
> в точке другое, 49,10 МПа: σ₃ = 0 больше обоих напряжений в плоскости, а они оба
> сжимающие, поэтому самая широкая пара — σ₂ и σ₃. Эта площадка наклонена
> к плоскости пластины, на плоском чертеже её не видно. Круг, который
> строится в п. 9, — это круг пары σ₁, σ₂, его радиус 40,70 МПа. В примере
> с занятия такого не возникает: там σ₁ = 100 МПа растягивающее, и наибольшей
> оказывается как раз пара в плоскости.

Элемент на площадках τ₁₂ повёрнут на α = 66,26° − 45° = 21,26° — рис. 4.

## 9. Круг напряжений (круг Мора)

**Что нужно получить.** Круг Мора — не отдельная задача, а геометрическая
интерпретация того же расчёта: с одного чертежа должны читаться **все**
результаты пп. 2–5. Не легла точка на окружность — значит, где-то ошибка
в аналитике. Ради этой проверки пункт и делается.

**Почему окружность.** Формулы поворота (4) и (5) переписываются так:

```
σν − (σx + σy)/2 = (σx − σy)/2·cos 2α − τxy·sin 2α
τtν              = (σx − σy)/2·sin 2α + τxy·cos 2α
```

Возводим в квадрат и складываем — члены с sin 2α·cos 2α уничтожаются:

```
[σν − (σx + σy)/2]² + τtν² = [(σx − σy)/2]² + τxy²        (7)
```

Это окружность в осях (σ; τ): центр на оси σ в точке (σx + σy)/2, радиус
√[((σx − σy)/2)² + τxy²]. Угол входит только как 2α — значит **повороту
площадки на α отвечает поворот точки по кругу на 2α**. Отсюда и построение.

**Порядок построения.** Масштаб как в конспекте: 1 см = 10 МПа, то есть
**1 МПа = 1 мм** (на рис. 7 выдержан точно — длины можно откладывать линейкой
в миллиметрах). Каждая точка окружности — одна площадка: абсцисса — нормальное
напряжение на ней, ордината — касательное.

**Шаг 1. Оси.** σ — вправо, τ — вверх, начало O. Все заданные напряжения
отрицательны, чертёж ляжет левее оси τ: нужно ~10 см влево от O и 4–5 см вверх
и вниз.

**Шаг 2. Точки D и B** — заданные нормальные напряжения, от O с учётом знака:

```
OD = σx = −85 МПа  →  85 мм влево от O   — точка D
OB = σy = −30 МПа  →  30 мм влево от O   — точка B
```

**Шаг 3. Центр C** — середина DB (по (7) центр на оси σ в точке (σx + σy)/2):

```
DC = CB = (σy − σx)/2 = (−30 + 85)/2 = 27,5 МПа  →  27,5 мм
OC = σx + DC = −85 + 27,5 = −57,50 МПа          →  57,5 мм влево от O
```

**Шаг 4. Точка K.** Из B перпендикулярно оси σ откладываем BK = τxy = −30 МПа:
минус — значит **вниз**, 30 мм. K(σy; τxy) = (−30; −30).

**Шаг 5. Радиус и окружность.** Треугольник CBK прямоугольный (прямой угол при B):

```
R = CK = √(CB² + BK²) = √(27,5² + 30²) = √(756,25 + 900) = √1656,25 = 40,70 МПа  →  40,7 мм
```

Циркуль в C, раствор до K, проводим окружность. Контроль: она проходит и через
X(σx; τxy) = (−85; −30) — под D на высоте K, симметрично K относительно вертикали
через C.

**Шаг 6. Главные напряжения** — пересечения с осью σ (там τ = 0):

```
σ₁ = OC + R = −57,50 + 40,70 = −16,80 МПа   — правая точка, 16,8 мм левее O
σ₂ = OC − R = −57,50 − 40,70 = −98,20 МПа   — левая точка, 98,2 мм левее O
```

**Шаг 7. Полюс K и главные направления.** K лежит на окружности и называется
**полюсом**. Правило полюса: *прямая из K под углом α к оси σ пересекает круг
в точке, координаты которой — σ и τ на площадке, нормаль которой наклонена под тем
же α к оси x*. Как в конспекте: K–σ₁ с продолжением за σ₁ — **луч 1**, K–σ₂
с продолжением за K — **луч 2**. Угол луча меряем транспортиром от оси σ (вправо):
против часовой — плюс, по часовой — минус. Аналитически:

```
луч 1:  tg α₁ = (0 − τxy)/(σ₁ − σy) = 30/(−16,8029 + 30) = 30/13,1971     =  2,2732  →  α₁ = +66,26°
луч 2:  tg α₂ = (0 − τxy)/(σ₂ − σy) = 30/(−98,1971 + 30) = 30/(−68,1971) = −0,4399  →  α₂ = −23,74°
```

Это формула (2) из п. 3, записанная как наклон отрезка K–σi. Лучи 1 и 2
перпендикулярны — угол при K опирается на диаметр σ₁σ₂ (tg α₁·tg α₂ = −1).
Почему правило верно для любой площадки: горизонталь через K попадает в X —
площадку x, α = 0; угол при K между KX и прямой на точку площадки вписанный,
опирается на ту же дугу, что центральный угол 2α, и потому равен α.

**Шаг 8. Экстремальные касательные и оси x₁, y₁.** Через C перпендикуляр к оси σ
до окружности — верхняя точка T₁ и нижняя T₂. Оси x₁, y₁ — как на рисунке 3
конспекта: оси элемента, повёрнутого на 45° от главных:

```
x₁:  α₁ + 45° = 66,26° + 45° = 111,26°        y₁:  α₁ − 45° = 66,26° − 45° = 21,26°
```

По правилу полюса прямая из K под 111,26° приходит в T₁, под 21,26° — в T₂:
K–T₁ с продолжением за T₁ — **ось x₁**, T₂–K с продолжением за K — **ось y₁**.

```
K–T₁:  tg = (40,697 + 30)/(−57,5 + 30) = 70,697/(−27,5) = −2,5708  →  180° − 68,74° = 111,26°  ✓
K–T₂:  tg = (−40,697 + 30)/(−57,5 + 30) = −10,697/(−27,5) =  0,3890  →  21,26°  ✓
T₁ (площадка x₁):  σx1 = OC = −57,50 МПа,   τ₁ = +R = +40,70 МПа
T₂ (площадка y₁):  σy1 = OC = −57,50 МПа,   τ₂ = −R = −40,70 МПа
```

Это п. 4, пара σ₁, σ₂. Ось y₁ (21,26°) — поворот элемента на рис. 4. τmax = 49,10 МПа
(пара σ₂, σ₃) на этом круге не видно.

**Шаг 9. Площадка под α = 15° — точка P, как снять σν и τtν:**

```
1) через полюс K — горизонталь до X (площадка x, α = 0; от неё отсчитывается угол)
2) транспортиром от горизонтали 15° против часовой стрелки — прямая ν через K
3) второе пересечение ν с окружностью — точка P (площадка с нормалью ν)
4) координаты P линейкой, 1 мм = 1 МПа:
   абсцисса: 66,3 мм, P левее O   →  σν  = −66,3 МПа   (размер под кругом)
   ордината: 39,7 мм, P ниже оси  →  τtν = −39,7 МПа   (размер слева)
```

Левее оси τ — σ < 0, ниже оси σ — τ < 0. Контроль расчётом (прямая
σ = σy + s·cos α, τ = τxy + s·sin α в (7); K на круге, второе решение s = KP):

```
s = −2[(σy − OC)·cos α + τxy·sin α]
  = −2[27,5·0,96593 + (−30)·0,25882] = −2·(26,5630 − 7,7646) = −37,597
P:   σν  = −30 + (−37,597)·0,96593 = −30 − 36,316 = −66,32 МПа
     τtν = −30 + (−37,597)·0,25882 = −30 −  9,731 = −39,73 МПа
```

**Шаг 10. Перпендикулярная площадка t — точка P′ и σt:**

```
1) через K прямая t перпендикулярно ν (угольником), т. е. под α + 90° = 105°
2) второе пересечение с окружностью — P′ (площадка с нормалью t)
```
