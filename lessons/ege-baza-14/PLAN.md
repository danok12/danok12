# ЕГЭ, базовый уровень. Задание 14 — план занятия на 90 минут

**Тема задания:** «Вычисления и преобразования». Формулировка всегда одна: *найдите значение выражения*. Ответ — число. 1 балл, по нормативам ~5 минут.

> **Сверьте номер по своей демоверсии.** Сайт ФИПИ недоступен из среды, где готовился материал; нумерация сверялась по нескольким справочным источникам — они сходятся на том, что в 2026–2027 годах № 14 базового уровня это «вычисления и преобразования», а структура КИМ 2027 года по сравнению с 2026-м не менялась. Содержание блоков от нумерации не зависит: если у вас под № 14 другая тема, меняется только заголовок.

## Четыре типа выражений

|---|---|---|
| A | обыкновенные и десятичные дроби | перевод, общий знаменатель, сокращение до умножения |
| B | степени, в том числе дробные и отрицательные | пять свойств степени, приведение к одному основанию |

## Главная мысль занятия

Задание 14 — это **не «посчитать», а «упростить так, чтобы считать почти не пришлось»**. Ученик, который бросается считать в столбик, теряет время и ошибается. Ученик, который сначала приводит всё к одному основанию или сокращает до умножения, получает ответ в одну строчку.

## Встроенная проверка

Ответ **всегда «хороший»**: целое число или короткая десятичная дробь. Если получилось `7,3333…` — это почти наверняка ошибка, а не «такое условие». Приучить ученика останавливаться и перепроверять на месте.

## Блок A. Дроби (12–28)

### Таблица наизусть

```
0,5 = 1/2    0,25 = 1/4    0,75 = 3/4     0,2 = 1/5
0,4 = 2/5    0,6 = 3/5     0,8 = 4/5      0,125 = 1/8
0,375 = 3/8  0,625 = 5/8   1,5 = 3/2      2,5 = 5/2
```

Половина ошибок блока — не арифметика, а перевод.

### Четыре действия

```
a/b ± c/d — общий знаменатель        a/b · c/d = (a·c)/(b·d)
a/b : c/d = a/b · d/c                многоэтажная дробь = деление
```

**Приём, экономящий всё время блока:** при умножении сокращать *до* перемножения, крест-накрест. В `(2/3)·(9/8)` сокращаем 3 с 9 и 2 с 8 — остаётся `3/4`.

### Разбор на доске

```
(1/2 + 1/3) : (1/2 − 1/3)

числитель:    1/2 + 1/3 = 3/6 + 2/6 = 5/6
знаменатель:  1/2 − 1/3 = 3/6 − 2/6 = 1/6
деление:      5/6 : 1/6 = 5/6 · 6/1 = 5
```

### Практика — 15 задач (10 минут)

```
 1. 0,4 + 1/5                  9. (3/5 + 0,4) : 0,2
 2. 3/4 − 0,25                10. (2,5 − 3/4)·4
 3. (2/3)·(9/8)               11. (1/3 + 1/6)·12
 4. (5/6) : (10/9)            12. (0,25 + 3/8) : (1/8)
 5. (0,8 + 1/4)·8             13. 8·(3/4 − 1/2)
 6. (1/2 + 1/3):(1/2 − 1/3)   14. (1 − 2/7)·14
 7. (7/12 − 1/4)·6            15. (5/8 − 0,125)·16
 8. 1,5·(2/3) + 0,5
```

**Ответы:** 1) 0,6 2) 0,5 3) 0,75 4) 0,75 5) 8,4 6) 5 7) 2 8) 1,5 9) 5 10) 7 11) 6 12) 5 13) 2 14) 10 15) 8

**№ 5 — единственная с «некруглым» ответом 8,4.** Именно на ней ученик начинает искать несуществующую ошибку. Повод уточнить: ответ короткий, но не обязательно целый.

## Блок B. Степени (28–46)

### Пять свойств и три определения

```
aᵐ · aⁿ = aᵐ⁺ⁿ        a⁰ = 1 (при a ≠ 0)
aᵐ : aⁿ = aᵐ⁻ⁿ        a⁻ⁿ = 1/aⁿ
(aᵐ)ⁿ = aᵐⁿ           a^(m/n) = ⁿ√(aᵐ)
(a·b)ⁿ = aⁿ·bⁿ
(a/b)ⁿ = aⁿ/bⁿ
```

### Главный приём: привести всё к одному основанию

```
4 = 2²    8 = 2³     16 = 2⁴    32 = 2⁵
9 = 3²    27 = 3³    81 = 3⁴    25 = 5²
0,5 = 2⁻¹ 0,2 = 5⁻¹  0,1 = 10⁻¹ 1000 = 10³
```

### Две ловушки

- `a⁻ⁿ` — это **дробь** `1/aⁿ`, а не отрицательное число: `2⁻³ = 0,125`, а не `−8`.
- Дробный показатель — это корень: `27^(2/3)` = «кубический корень из 27, потом в квадрат» = `3² = 9`.

### Разбор на доске

```
16^0,25 · 8^(1/3)

16 = 2⁴,  8 = 2³          ← к одному основанию
16^0,25 = 2^(4·0,25) = 2
8^(1/3) = 2^(3·1/3)  = 2
итого:  2 · 2 = 4
```

### Практика — 15 задач (10 минут)

```
 1. 2⁵·2³ : 2⁶          9. (2⁻³)⁻²
 2. 3⁴·3² : 3⁵         10. 6⁵ : (2⁵·3⁵)
 3. 5⁷ : (5³·5³)       11. 15³ : (5³·3²)
 4. (2³)² : 2⁴         12. 2⁻⁴·2⁷
 5. 7⁰ + 3⁻¹·3         13. (5²·5⁻⁵) : 5⁻⁴
 6. 0,2⁻²              14. (9^0,5)³
 7. 4^1,5              15. 16^0,25 · 8^(1/3)
 8. 27^(2/3)
```

**Ответы:** 1) 4 2) 3 3) 5 4) 4 5) 2 6) 25 7) 8 8) 9 9) 64 10) 1 11) 3 12) 8 13) 5 14) 27 15) 4

**№ 10 разобрать отдельно:** `2⁵·3⁵ = (2·3)⁵ = 6⁵`, поэтому дробь равна единице без единого умножения.

## Блок C. Корни (46–62)

```
√a · √b = √(ab)       (√a)² = a
√a : √b = √(a/b)      √(a²) = |a|
                      (√a)⁴ = a²

(√a − √b)(√a + √b) = a − b     ← закрывает половину блока
```

### Главный приём

Собрать всё под один корень и посмотреть, не получился ли точный квадрат. `√20·√5` выглядит как два иррациональных числа, а это `√100 = 10`. Приближённые вычисления в этом задании не нужны никогда.

```
√4=2  √9=3  √16=4  √25=5  √36=6  √49=7
√64=8 √81=9 √100=10 √121=11 √144=12 √169=13
```

### Ошибка, которую делают все

`√(a² + b²) ≠ a + b`. Корень «разваливается» только на произведении и частном, никогда на сумме. Проверить на числах: `√(9+16) = 5`, а `3+4 = 7`. Пусть ученик подставит сам.

### Практика — 15 задач (10 минут)

```
 1. √48 : √3                    9. (√11 − 3)(√11 + 3)
 2. √8 · √2                    10. √(3,6·10)
 3. (√7)² − 3                  11. (3√2)² : 2
 4. √(6² + 8²)                 12. √0,49 · 10
 5. √20 · √5                   13. ³√64
 6. (2√3)²                     14. √45 : √5
 7. √72 : √2                   15. (√6)⁴
 8. (√5 − √2)(√5 + √2)
```

**Ответы:** 1) 4 2) 4 3) 4 4) 10 5) 10 6) 12 7) 6 8) 3 9) 2 10) 6 11) 9 12) 7 13) 4 14) 3 15) 36

**№ 4 — специально поставленная ловушка.** `√(36+64) = 10`, а не `14`. Если ученик написал 14 — вернуться к правилу, это тот случай, когда его нужно прожить на своей ошибке.

## Блок D. Логарифмы (62–80)

### Определение — с него всё начинается

```
log_a b = c   ⟺   a^c = b
```

Читать вслух: **«в какую степень возвести a, чтобы получить b»**. Ученик, который проговаривает этот вопрос вместо того, чтобы вспоминать формулы, решает половину блока устно.

### Три свойства и два частных случая

```
log_a(x·y) = log_a x + log_a y      log_a 1 = 0
log_a(x/y) = log_a x − log_a y      log_a a = 1
log_a xⁿ = n·log_a x                a^(log_a b) = b   ← основное тождество
```

### Главный приём

Свернуть всё в один логарифм, потом задать вопрос «в какую степень».

```
log₆4 + log₆9 = log₆36 = 2
                       ↑ «6 в какой степени даёт 36?»
```

### Три ловушки

- `log(x + y) ≠ log x + log y` — свойство про произведение, не про сумму.
- `log_a 1 = 0`, а не 1. Проверяется определением: `a⁰ = 1`.
- Основание меньше единицы даёт отрицательный ответ: `log₀,₅8 = −3`. Минус здесь — норма.

### Практика — 15 задач (10 минут)

```
 1. log₂32               9. 2^(log₂7 + 1)
 2. log₃81              10. log₄64
 3. log₅125             11. log₀,₅8
 4. log₂8 + log₂4       12. log₂(1/16)
 5. log₆4 + log₆9       13. 9^(log₃2)
 6. log₃54 − log₃2      14. log₂₅5
 7. log₇49²             15. log₃15 − log₃5
 8. 5^(log₅3)
```

**Ответы:** 1) 5 2) 4 3) 3 4) 5 5) 2 6) 3 7) 4 8) 3 9) 14 10) 3 11) −3 12) −4 13) 4 14) 0,5 15) 1

**№ 13 — самая трудная.** Основания разные: `9 = 3²`, поэтому `9^(log₃2) = (3^(log₃2))² = 2² = 4`. Тот же приём, что в блоке B. Показать, что блоки не изолированы.

**№ 14 даёт 0,5** — ещё одно напоминание про «короткий, но не обязательно целый».

## Девять ошибок, на которых теряют балл

| Ученик пишет | На самом деле | Как объяснить |
|---|---|---|
| `2⁻³ = −8` | `0,125` | минус в показателе переворачивает дробь, а не меняет знак |
| `a⁰ = 0` | `a⁰ = 1` | из деления: `aⁿ : aⁿ = 1` |
| `√(9+16) = 7` | `= 5` | корень не разваливается на сумме |
| `(a+b)² = a²+b²` | есть удвоенное произведение | подставить 2 и 3: 25 против 13 |
| `log₂(4+4) = 2+2` | `log₂8 = 3` | свойство про произведение |
| `log_a 1 = 1` | `= 0` | вернуться к определению |
| переворачивает первую дробь при делении | переворачивается **вторая** | проверить на `1 : 1/2 = 2` |
| `0,2 = 1/2` | `= 1/5` | таблица переводов из блока A |
| считает столбиком и округляет | ответ извлекается точно | приближённые вычисления не нужны |

## Оформление ответа

- Только число, без единиц измерения и знака равенства.
- Десятичная дробь через запятую, запятая занимает отдельную клетку.
- Минус тоже занимает отдельную клетку (задачи 11 и 12 блока D специально дают отрицательный ответ).
- Ноль целых пишется: `0,5`, а не `,5`.
- Обыкновенную дробь в бланк не вписывают. Если она не переводится в короткую десятичную — ответ почти наверняка неверен.
