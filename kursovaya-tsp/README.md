### Принятые данные и допущения

- Отметки h1…h24 — приложение 1, столбец 2. Вершины нумеруются построчно слева направо, сверху вниз (проверено на примере из методички: лист Иминовой = вариант 12).
- h = Hкр − Hчёрн: «−» — выемка (ПВ), «+» — насыпь (ПН), как на примерах кафедры.
- Нумерация фигур: целый квадрат — «n»; разделённый ЛНР — выемка «n», насыпь «n′» (как 3′ на доске).
- hср фигуры = среднее |h| по её вершинам, точки нуля входят нулями (как hср3 = (0,47+0,64+0,45+0+0)/5 на доске).
- Kор = 1,04: супесь, остаточное разрыхление 3–5 % (табл. П2.1). Меняется в ячейке `Исходные данные!B4`.
- Шрифт — ГОСТ тип Б (`GOST_B.TTF`, семейство «GOST type B»). Шрифт должен быть установлен в Windows.

все отметки сдвинуты на −0,0232 — это и есть такая поправка.
