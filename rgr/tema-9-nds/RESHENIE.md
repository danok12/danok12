# ЗАДАЧА 2. Двухосное напряжённое состояние

## Дано

По условию σz = 0; τzx = τxz = 0; τzy = τyz = 0, а σx ≠ 0, σy ≠ 0, τxy ≠ 0.
Такое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной по контуру.

Сталь: E = 2,1·10⁵ МПа; G = 0,8·10⁵ МПа; R = 210 МПа; γc = 0,9; ν = 0,3.

## 1. Тензор напряжений и напряжения на гранях элемента

По закону парности τxy = τyx = −30 МПа.

Tн = | σx  τxy ; τyx  σy | = | −85  −30 ; −30  −30 |  [МПа]

Плоское напряжённое состояние возникает в тонкой пластине (h ≪ a, b), нагруженной
силами в её плоскости. На лицевых поверхностях пластины нагрузки нет, поэтому
σz = 0 и τzx = τzy = 0 (рис. 1).

Оба нормальных напряжения отрицательны, стрелки направлены к граням (сжатие);
касательные тоже отрицательны и направлены противоположно положительному
направлению осей. Отличны от нуля только три компоненты, поэтому элемент достаточно
изобразить плоским — проекцией на плоскость xOy (рис. 2).

## 2. Главные напряжения

Главные напряжения — корни характеристического уравнения
`σ³ − I₁н·σ² + I₂н·σ − I₃н = 0` (1). Для плоского состояния
инварианты сворачиваются к двум:

* I₁н = σx + σy = **−115 МПа**
* I₂н = σx·σy − τxy² = 2550 − 900 = **1650 МПа²**
* I₃н = **0** — при двухосном состоянии третьего инварианта нет

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0.

Корень σ = 0 отвечает площадке с нормалью z: на ней нет ни нормальных, ни
касательных напряжений, значит ось z — главная. Квадратное уравнение даёт:

σ₃,₂ = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx + σy)/2 ± √[((σx − σy)/2)² + τxy²]

* (σx + σy)/2 = −57,5 МПа; (σx − σy)/2 = −27,5 МПа
* √(756,25 + 900) = √1656,25 = 40,6971 МПа
* σ′ = −16,80 МПа; σ″ = −98,20 МПа

Нумеруем как на занятии: σ₁ и σ₂ — оба корня в плоскости пластины
(σ₁ — больший), третье главное напряжение равно нулю:

**σ₃ = 0; σ₁ = −16,80 МПа; σ₂ = −98,20 МПа**

> В примере с занятия оба плоских корня были ненулевыми и разного знака, поэтому
> они и оказались σ₃ и σ₁. Здесь оба отрицательны, так что нулевой корень —
> наибольший, и он становится σ₃.

Таблица 5 — проверка по инвариантам

|---|---|---|
| I₁н | σx + σy = −115 МПа | −16,8029 − 98,1971 + 0 = −115 МПа |
| I₂н | σxσy − τxy² = 1650 МПа² | 1650,0 + 0 + 0 = 1650 МПа² |

Вид напряжённого состояния — **двухосное сжатие**.

## 3. Углы наклона главных площадок к оси x

```
(σx − σi)·li + τxy·mi = 0    (a)
τyx·li + (σy − σi)·mi = 0    (b)
```

li = cos(σi^x), mi = cos(σi^y). Ось y направлена вниз, поэтому
li = cos αi, mi = cos(αi + 90°) = −sin αi. Подставляем в (b) и делим на cos αi:

**tg αi = τyx / (σy − σi)**   (2)

* при i = 1 (σ₁ = −16,80): tg α₁ = −30/(−13,1971) = 2,2732 → **α₁ = +66,26°**
* при i = 2 (σ₂ = −98,20): tg α₂ = −30/68,1971 = −0,4399 → **α₂ = −23,74°**

**Проверка:** |α₁| + |α₂| = 66,26° + 23,74° = **90,00°**

| ν₂ (σ₂), α = −23,74° | 0,91535 | 0,40266 | 1,000000 | 0,000000 | 0,000000 |

Третья главная площадка — с нормалью z (σ₃ = 0), совпадает с плоскостью пластины.
Главный элемент — рис. 3.

> **Сверка с формулой tg 2α₀.** tg 2α₀ = 2τxy/(σx − σy) = −60/−55 = 1,0909 →

## 4. Экстремальные касательные напряжения

**Зачем этот пункт.** По главным площадкам касательных напряжений нет вовсе —
в этом их определение. Но рядом есть площадки, где касательное напряжение
наибольшее: по ним материал начинает течь. Такая площадка делит пополам прямой
угол между двумя главными направлениями, то есть наклонена к ним под ±45°.
Пар главных напряжений три — значит, и семейств площадок три.

```
τij = ±(σi − σj)/2,   σ' = (σi + σj)/2          (3)
```

Подставляем σ₁ = −16,8029; σ₂ = −98,1971; σ₃ = 0 МПа:

```
пара σ₁, σ₂ — площадки в плоскости пластины:
  τ₁₂ = ±(−16,8029 + 98,1971)/2 = ±81,3942/2 = ±40,70 МПа
  σ'  =  (−16,8029 − 98,1971)/2 = −115,0000/2 = −57,50 МПа

пара σ₂, σ₃ — площадки наклонены к плоскости пластины:
  τ₂₃ = ±(−98,1971 − 0)/2 = ±98,1971/2 = ±49,10 МПа
  σ'  =  (−98,1971 + 0)/2 = −49,10 МПа

пара σ₃, σ₁ — площадки наклонены к плоскости пластины:
  τ₃₁ = ±(0 + 16,8029)/2 = ±16,8029/2 = ±8,40 МПа
  σ'  =  (0 − 16,8029)/2 = −8,40 МПа
```

Наибольшее из трёх — вторая пара: **τmax = τ₂₃ = 49,10 МПа.**

> Первая строка, 40,70 МПа, — это радиус круга Мора по σx, σy, τxy: её и дала бы
> формула «в плоскости», если ограничиться одним кругом. Но наибольшее касательное
> в точке другое, 49,10 МПа: σ₃ = 0 больше обоих напряжений в плоскости, а они оба
> сжимающие, поэтому самая широкая пара — σ₂ и σ₃. Эта площадка наклонена
> к плоскости пластины, на плоском чертеже её не видно. Круг, который
> строится в п. 9, — это круг пары σ₁, σ₂, его радиус 40,70 МПа. В примере
> с занятия такого не возникает: там σ₁ = 100 МПа растягивающее, и наибольшей
> оказывается как раз пара в плоскости.

Элемент на площадках τ₁₂ повёрнут на α = 66,26° − 45° = 21,26° — рис. 4.

## 5. Напряжения на площадках под углом α = 15° к осям Ox и Oy

```
σν  = σx·cos²α + σy·sin²α − τxy·sin 2α          (4)
τtν = (σx − σy)/2·sin 2α + τxy·cos 2α           (5)
σt  = σx + σy − σν                              (6)
```

При α = 15°: cos²α = 0,93301; sin²α = 0,06699; sin 2α = 0,5; cos 2α = 0,86603.

```
σν  = −85·0,93301 − 30·0,06699 + 30·0,5 = −79,31 − 2,01 + 15,00 = −66,32 МПа
τtν = (−55/2)·0,5 − 30·0,86603 = −13,75 − 25,98 = −39,73 МПа
σt  = −115 + 66,32 = −48,68 МПа
```

**Проверка по инвариантам** (поворот площадок их не меняет):

```
σν + σt      = −115,000000 МПа  = I₁н   ✓
σν·σt − τtν² =  1650,000000 МПа² = I₂н   ✓
```

Рис. 5. Угол 15° взят по разбору на занятии; при другом угле меняются только
четыре тригонометрические величины.

## 6. Относительные линейные и угловые деформации

E = 2,1·10⁵ МПа, ν = 0,3, G = 0,8·10⁵ МПа, σz = 0.

```
εx = (1/E)[σx − ν·σy] = (−85 + 9,0)/2,1·10⁵  = −36,19·10⁻⁵   укорочение dx
εy = (1/E)[σy − ν·σx] = (−30 + 25,5)/2,1·10⁵ =  −2,14·10⁻⁵   укорочение dy
εz = −(ν/E)(σx + σy)  = +34,5/2,1·10⁵        = +16,43·10⁻⁵   удлинение dz
θ  = εx + εy + εz = −21,90·10⁻⁵
контроль: θ = (1−2ν)/E·I₁н = (0,4/2,1·10⁵)·(−115) = −21,90·10⁻⁵   ✓
γxy = τxy/G = −30/0,8·10⁵ = −37,50·10⁻⁵;  γyz = γzx = 0
```

Материал выдавливается вдоль свободной оси z; объём уменьшился — как и должно
быть при двухосном сжатии. При согласованном G = E/[2(1+ν)] = 0,8077·10⁵ МПа
вышло бы γxy = −37,14·10⁻⁵ — расхождение 1 %, на выводы не влияет.

Рис. 6 — деформация элемента.

## 7. Удельная потенциальная энергия упругой деформации

Суммы берутся через инварианты, без округления корней:
σ₁² + σ₂² + σ₃² = I₁н² − 2I₂н = 9925 МПа²; σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = 1650 МПа².

```
U₀   = (1/2E)[9925 − 0,6·1650] = 8935/4,2·10⁵  = 0,021274 МПа
U₀ф  = ((1+ν)/6E)·2(I₁н² − 3I₂н) = 16550·1,3/1,26·10⁶ = 0,017075 МПа  (80,3 %)
U₀об = ((1−2ν)/6E)·I₁н² = 13225·0,4/1,26·10⁶          = 0,004198 МПа  (19,7 %)
контроль: U₀ф + U₀об = 0,021274 МПа = U₀   ✓
```

Доля объёмной части здесь заметная именно потому, что оба главных
напряжения в плоскости одного знака.

## 8. Проверка прочности по энергетической (IV) теории

```
σэкв^IV = (1/√2)·√[(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)²] = √(I₁н² − 3I₂н) = √8275 = 90,97 МПа
90,97 МПа ≤ R·γc = 210·0,9 = 189,0 МПа   ✓
```

**Условие прочности выполняется.** Использовано 48,1 % несущей способности,
запас 2,08. Связь с энергией: U₀ф = ((1+ν)/3E)·(σэкв)² = 0,017075 МПа — то же
число, что в п. 7.


## 9. Круг напряжений (круг Мора)

**Что нужно получить.** Круг Мора — не отдельная задача, а геометрическая
интерпретация того же расчёта: с одного чертежа должны читаться **все**
результаты пп. 2–5. Не легла точка на окружность — значит, где-то ошибка
в аналитике. Ради этой проверки пункт и делается.

**Почему окружность.** Формулы поворота (4) и (5) переписываются так:

```
σν − (σx + σy)/2 = (σx − σy)/2·cos 2α − τxy·sin 2α
τtν              = (σx − σy)/2·sin 2α + τxy·cos 2α
```

Возводим в квадрат и складываем — члены с sin 2α·cos 2α уничтожаются:

```
[σν − (σx + σy)/2]² + τtν² = [(σx − σy)/2]² + τxy²        (7)
```

Это окружность в осях (σ; τ): центр на оси σ в точке (σx + σy)/2, радиус
√[((σx − σy)/2)² + τxy²]. Угол входит только как 2α — значит **повороту
площадки на α отвечает поворот точки по кругу на 2α**. Отсюда и построение.

**Построение** (1 см = 10 МПа):

```
1. OD = σx = −85 МПа,  OB = σy = −30 МПа            — точки на оси σ
2. DC = CB = (σy − σx)/2 = (−30 + 85)/2 = 27,5 МПа
   OC = σx + DC = −85 + 27,5 = −57,50 МПа           — центр
3. BK = τxy = −30 МПа, от B вниз (знак минус)       — точка K
4. R = CK = √(CB² + BK²) = √(27,5² + 30²) = √1656,25 = 40,70 МПа
5. окружность радиуса R из центра C
```

**Что снимается с круга.** Каждая точка окружности — одна площадка: абсцисса
это нормальное напряжение, ордината — касательное.

| что ищем | где на круге | с круга | из расчёта |
|---|---|---|---|
| σ₁, σ₂ | пересечения с осью σ: OC ± R | −16,80 и −98,20 | п. 2: те же |
| α₁, α₂ | половина угла от радиуса CX до оси σ | +66,26° и −23,74° | п. 3: те же |
| τ₁, τ₂ | верхняя и нижняя точки круга | ±40,70 | п. 4: τ₁₂ = ±40,70 |
| σ' на них | абсцисса тех же точек, то есть OC | −57,50 | п. 4: −57,50 |
| σν, τtν при α = 15° | точка P: поворот радиуса CX на 2α = 30° | −66,32 и −39,73 | п. 5: те же |
| σt при α = 15° | точка P′ — другой конец диаметра | −48,68 | п. 5: −48,68 |

Точка X(σx; τxy) = (−85; −30) — площадка с нормалью x, то есть α = 0; от её
радиуса и отсчитываются углы, против часовой стрелки на 2α. Проверка: до σ₁
радиус CX поворачивается на 132,5° → α₁ = 66,26°; до σ₂ — на −47,5° →
α₂ = −23,74°. Совпало с п. 3.

**Главная проверка** — подставляем результат п. 5 в уравнение (7):

```
(σν − OC)² + τtν² = (−66,3157 + 57,5)² + (−39,7308)² = 77,72 + 1578,53 = 1656,25 МПа²
R² = 40,6971² = 1656,25 МПа²    ✓
```

Точка легла на окружность точно — пп. 2–5 согласованы между собой и с исходными
данными. Рис. 7.
