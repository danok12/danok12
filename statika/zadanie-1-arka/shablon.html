Требуется: определить опорные реакции VA, VB, HA, HB и внутренние усилия M, Q, N в сечениях K1 и K2.

  • Ось арки — дуга окружности, проходящая через опоры A, B и ключевой шарнир C: пролёт l = 44 м, высота f = 14 м, радиус R = $Rr м (шаг 3). Начало координат в опоре A, ось x вправо, ось y вверх.
  • Опоры A и B на одном уровне. Шарнир C — в вершине: x = l/2 = 22 м, y = f = 14 м.

Правило знаков

  • В уравнениях моментов: вращение по часовой стрелке — «+», против часовой — «−». Это правило только для составления уравнений.
  • N > 0 — растяжение: сила направлена от сечения. В арке N направлена по касательной к оси.
  • Q > 0 — вращает отсечённую часть по часовой стрелке. В арке Q направлена по нормали к оси.
  • M > 0 — растянуты нижние (внутренние) волокна. На правом торце левой части он направлен против часовой стрелки, на левом торце правой части — по часовой.
  • Если ответ получился со знаком «−», усилие направлено противоположно показанному на рисунке.

Шаг 1. Вертикальные опорные реакции

Пояснение. Неизвестных четыре (VA, HA, VB, HB), уравнений равновесия всей арки — три, четвёртое даёт шарнир C (шаг 2). Опоры стоят на одном уровне, поэтому распоры HA и HB действуют по прямой AB и проходят через обе опорные точки. В уравнение моментов относительно B не входят VB, HB и HA — остаётся одна неизвестная VA. Поэтому вертикальные реакции арки такие же, как у простой балки пролётом l с той же нагрузкой.
Нагрузку q заменяем равнодействующей Rq = q·l/2 = 10·22 = 220 кН. Она приложена в середине загруженного участка, при x = 3l/4 = 33 м; её плечо до B равно l/4 = 11 м, до A — 3l/4 = 33 м.
ΣMB = VA·l − P·3l/4 − 2P·l/4 − q·(l/2)·(l/4) = 0
VA вращает арку вокруг B по часовой стрелке («+»), P, 2P и Rq — против часовой («−»).
VA = (P·3l/4 + 2P·l/4 + q·(l/2)·(l/4)) / l = (14·33 + 28·11 + 10·22·11) / 44 =
   = (462 + 308 + 2420) / 44 = 3190 / 44 = 72,5 кН
ΣMA = −VB·l + P·l/4 + 2P·3l/4 + q·(l/2)·(3l/4) = 0
VB = (P·l/4 + 2P·3l/4 + q·(l/2)·(3l/4)) / l = (14·11 + 28·33 + 10·22·33) / 44 =
   = (154 + 924 + 7260) / 44 = 8338 / 44 = 189,5 кН
Проверка: ΣY = VA + VB − P − 2P − q·l/2 = 72,5 + 189,5 − 14 − 28 − 220 = 262 − 262 = 0 ✓

VB больше VA, потому что основная нагрузка (q и 2P) приложена к правой половине арки.

Шаг 2. Распор H

Пояснение. Все нагрузки вертикальные, поэтому из ΣX = HA − HB = 0 получаем HA = HB = H: распор с обеих сторон одинаковый. Недостающее уравнение даёт шарнир C. Он не передаёт изгибающий момент, поэтому сумма моментов относительно C всех сил, приложенных к одной полуарке, равна нулю. Силы взаимодействия XC, YC приложены в самой точке C и в это уравнение не входят.

Левая полуарка AC

На ней кроме реакций действует только сила P: нагрузки q на левой половине нет. Плечо P до C: l/2 − l/4 = l/4 = 11 м.

ΣMCлев = −HA·f + VA·l/2 − P·l/4 = 0
HA направлен вправо и приложен ниже C на f — вращает против часовой («−»); VA левее C, вверх — по часовой («+»); P левее C, вниз — против часовой («−»).

Проверка по правой полуарке CB

На ней нагрузка q на всей длине l/2 (равнодействующая q·l/2 = 220 кН, плечо до C — l/4) и сила 2P с плечом l/4.

Шаг 3. Геометрия сечений K1 и K2

Пояснение. Ось арки — дуга окружности через точки A, C и B. Центр O лежит на вертикали, проходящей через ключ C, ниже линии опор. Из прямоугольного треугольника OMA (рис. 5): R² = (l/2)² + (R − f)², откуда R = (l²/4 + f²) / (2f).
Для сечения с абсциссой x горизонтальное расстояние до вертикали OC равно l/2 − x. Из треугольника с гипотенузой R (радиус OK): sin φ = (l/2 − x) / R, cos φ = √(R² − (l/2 − x)²) / R, а высота сечения над опорами yK = √(R² − (l/2 − x)²) − (R − f). Здесь φ — угол между касательной к оси в сечении и горизонталью; он равен углу между радиусом и вертикалью, потому что радиус перпендикулярен касательной.
Замечание: это не полуокружность. У полуокружности высота равна половине пролёта (22 м); при f = 14 м дуга меньше половины окружности, и её центр лежит ниже опор.
R = (l²/4 + f²) / (2f) = (44²/4 + 14²) / (2·14) = (484 + 196) / 28 = 680/28 = 170/7 = $Rr м
R − f = $Rr − 14 = $RmF м  (на столько центр O ниже линии опор)
K1, x = l/4 = 11 м, l/2 − x = 22 − 11 = 11 м:
  R² − (l/2 − x)² = (170/7)² − 11² = 28900/49 − 121 = 22971/49
  √(R² − (l/2 − x)²) = √22971 / 7 = $sq / 7 = $root м
  yK1 = √22971/7 − 72/7 = ($sq − 72) / 7 = $Y м
  sin φ = (l/2 − x) / R = 11 / (170/7) = 77/170 = $S
  cos φ = √(R² − (l/2 − x)²) / R = (√22971/7) / (170/7) = $sq / 170 = $C
  tg φ = $S / $C = $tg;   φ = arcsin $S = $phi°
K2, x = 3l/4 = 33 м, l/2 − x = 22 − 33 = −11 м:
  yK2 = yK1 = $Y м  (симметрично K1)
  sin φ2 = −11 / (170/7) = −$S  →  φ2 = −$phi°
H·yK = 1441/14 · $Y = $Hy кН·м  (понадобится в шагах 4 и 5)

Знак «−» у φ2 означает, что в правой полуарке касательная опускается вправо. Сечения K1 и K2 симметричны относительно ключа, поэтому модуль угла у них одинаковый. Для сечения правой полуарки угол берём по модулю: φ = $phi°, sin φ = $S, cos φ = $C. Наклон касательной в другую сторону учитываем знаками в уравнениях проекций (рис. 7).

Шаг 4. Сечение K1 — рассматриваем левую часть AK1

Пояснение. Разрезаем арку по сечению K1 и рассматриваем левую часть: на ней меньше сил. Действие отброшенной правой части заменяем усилиями M1, Q1, N1, направленными в положительную сторону (рис. 2).
Сила P приложена точно в K1, поэтому Q и N в этой точке меняются скачком. Считаем их дважды: бесконечно близко слева от P (P в рассматриваемую часть не входит, индекс «л») и справа от P (P входит, индекс «п»). Изгибающий момент скачка не имеет: плечо P относительно K1 равно нулю.
Проекции сил на оси. Угол между вертикалью и нормалью n равен φ (рис. 6), поэтому: VA даёт на n +VA·cos φ, на m +VA·sin φ; H (вправо) — на n −H·sin φ, на m +H·cos φ; P (вниз) — на n −P·cos φ, на m −P·sin φ. Положительная Q1 направлена против оси n, поэтому входит в Σn со знаком «−».

4.1. Изгибающий момент M1

ΣMK1 = −M1 + VA·l/4 − H·yK1 = 0
M1 показан против часовой («−»); VA вращает часть вокруг K1 по часовой («+»); H приложен ниже K1 на yK1, направлен вправо — против часовой («−»). Сила P проходит через K1.
M1 = VA·l/4 − H·yK1 = 72,5·11 − 1441/14·$Y = 797,5 − $Hy = $M1_3 кН·м

M1 < 0: момент направлен противоположно показанному, в сечении K1 растянуты верхние (наружные) волокна арки.

Шаг 5. Сечение K2 — рассматриваем правую часть K2B

Пояснение. Для сечения в правой полуарке рассматриваем правую часть K2B: на ней меньше сил, чем на левой. Усилия на левом торце правой части в положительном направлении: N2 — от сечения вверх-влево по касательной; Q2 — по нормали вверх-вправо (вращает часть по часовой стрелке); M2 — по часовой стрелке. Ось m направлена вдоль N2, ось n — вдоль Q2.
Нагрузки на правой части: q на длине l/4 (равнодействующая Rq = q·l/4 = 10·11 = 110 кН, плечо относительно K2 — l/8 = 5,5 м) и сила 2P в самом сечении K2. Как и в K1: для сечения слева от 2P сила входит в правую часть (индекс «л»), для сечения справа — не входит (индекс «п»).
