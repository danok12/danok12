# Дроби и степени — задачи для ученика

54 задач. Задачи со ★ — по желанию. Теория и разборы — в PDF и на странице занятия.
Дробь в строчку: `(x + 1)/(x − 2)` — это дробь с числителем x + 1 и знаменателем x − 2.

## Блок 0. Разминка: обычные дроби

Вычислите. Правила те же, что и с буквами, только проще. Ответ — несократимая дробь.

```
 1.  5/6 − 3/8
 2.  7/12 + 5/18
 3.  3/4 · 8/15
 4.  9/14 : 15/28
 5.  (1/4 + 1/6) · 12/5
 6.  (5/6 − 1/4) : 7/8
 7.  (−2/3)³
```

## Найди ошибку

В каждом решении есть ошибка. Найдите неверный переход, объясните и решите правильно.

1. `a³ · (a²)⁴ : a⁵ = a³ · a⁶ : a⁵ = a⁹ : a⁵ = a⁴`  
2. `(−2x³y)⁴ = −2x¹²y⁴`  
3. `4a/b² : 2a²/b = b²/(4a) · 2a²/b = 2a²b²/(4ab) = ab/2`  
4. `(x² − 4)/(x² − 2x) = (−4)/(−2x) = 2/x`  
5. `1/(x − 2) − (x + 1)/(x² − 4) = (x + 2 − x + 1)/(x² − 4) = 3/(x² − 4)`
