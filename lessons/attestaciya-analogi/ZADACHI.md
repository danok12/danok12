## 1. Угол между функциями в C[0;1]

*Как решать.* (f,g) = ∫₀¹ f(x)·g(x)dx,   ‖f‖ = √((f,f)),   cosφ = (f,g)/(‖f‖·‖g‖).

**1А.** Найдите косинус угла между функциями f, g ∈ C[0;1]:   f(x) = 2x + 1 и g(x) = x − 1 в евклидовом пространстве со скалярным произведением (f,g) = ∫₀¹ f(x)·g(x)dx.

**1Б.** Найдите косинус угла и сам угол между функциями f(x) = x и g(x) = 3x − 2 в C[0;1] с тем же скалярным произведением. Что можно сказать об этих функциях?

## 3. Ранг квадратичной формы

*Как решать.* Ранг формы = ранг её симметричной матрицы. На диагонали — коэффициенты при xᵢ², вне диагонали — **половина** коэффициента при xᵢxⱼ. Ранг — элементарными преобразованиями строк.

**3А.** Найдите ранг квадратичной формы f(x₁, x₂, x₃) = x₁² + 4x₂² + 16x₃² + 6x₁x₂ + 12x₁x₃ + 16x₂x₃.

**3Б.** То же для f = x₁² + 5x₂² + 2x₃² − 4x₁x₂ − 2x₁x₃ + 6x₂x₃.

**3В.** То же для f = x₁² + 4x₂² + 9x₃² + 4x₁x₂ − 6x₁x₃ − 12x₂x₃.

## 4. Базис и размерность пространства решений однородной системы

*Как решать.* Привести к ступенчатому виду, найти ранг r. Тогда dimL = n − r (n — число неизвестных). Свободным неизвестным по очереди даём значения (1, 0, 0), (0, 1, 0), (0, 0, 1) — получаем фундаментальную систему решений.

**4А.** Найдите какой-нибудь базис и установите размерность пространства решений однородной системы { x₁ − x₂ + 2x₃ + x₄ − x₅ = 0;;  x₂ + x₃ − 2x₄ + 3x₅ = 0. }

**4Б.** То же для системы { x₁ + 2x₂ − x₃ + x₄ + 3x₅ = 0;;  2x₁ + 5x₂ − x₃ + 4x₄ + 4x₅ = 0;;  x₁ + 3x₂ + 3x₄ + x₅ = 0. }

*Как решать.* Строка № i матрицы A — коэффициенты при x₁, x₂, x₃ в i-й координате образа (если переменной нет — пишем 0). Образ: f(x̄) = A·X.

## 9. К какому собственному значению относится вектор

*Как решать.* Умножить A на столбец координат вектора. Если AX = λX — вектор собственный, а λ — искомое значение. Если результат не пропорционален X — вектор не собственный.

**9А.** Линейный оператор f в базисе ē1, ē2, ē3 задан матрицей A = (2 4 1; 3 1 −1; 1 3 1). Вектор x̄ = −ē1 + ē2 − ē3 является собственным вектором оператора f. Найдите, к какому собственному значению он относится.

**9Б.** Оператор задан матрицей A = (4 −1 1; 2 1 3; −2 1 2). Какой из векторов x̄ = ē1 + 2ē2 и ȳ = ē1 + ē2 + ē3 является собственным? К какому собственному значению он относится?

## 11. Канонический вид квадратичной формы ортогональным преобразованием

*Как решать.* 1) Матрица формы (вне диагонали — половина коэффициента при x₁x₂). 2) Корни |A − λE| = 0 — это коэффициенты канонического вида. 3) Для каждого λ — собственный вектор, нормировать. 4) Из нормированных векторов-столбцов составить матрицу перехода: X = P·Y.

**11А.** Приведите квадратичную форму Φ(x₁, x₂) = x₁² + 5x₂² + 4√3x₁x₂ к каноническому виду и укажите соответствующее ортогональное преобразование координат.

**11Б.** То же для Φ(x₁, x₂) = −x₁² + 4x₂² + 12x₁x₂.
