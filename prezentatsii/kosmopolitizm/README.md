# Космополитизм — презентация на ~10 минут

| Файл | Что это |
|---|---|
| `kosmopolitizm.pptx` | презентация, 15 слайдов; текст выступления — в заметках докладчика |
| `kosmopolitizm.pdf` | те же слайды в PDF (если показывать не из PowerPoint) |
| `TEKST.md`, `kosmopolitizm-tekst.pdf` | текст выступления по слайдам с хронометражем |
| `src/` | исходники: `build.js` (вёрстка), `tekst.js` (текст к слайдам), `img/` |

Стиль по референсу: светлый тёплый фон, акцент — синий `#2B4C8C`, основной текст — тёмно-коричневый `#3B2A20`,
ступенчатые полосы и метки `//01` из образца, картинки в тёплом монохроме.
Шрифты — те, что есть в Office: Arial Narrow (заголовки), Calibri (текст), Georgia (цитаты).

Картинки: статуя вырезана из присланного референса, «Афинская школа» (Рафаэль) и «Смерть Сократа» (Давид)
увеличены и переведены в монохром. Земля на слайде 11 собрана из снимков NASA Blue Marble (`src/zemlya.py`), глобус на титуле, круги Иерокла и солнце — фигуры PowerPoint.

## Пересборка

```bash
cd src && npm install && node build.js     # → ../kosmopolitizm.pptx, ../TEKST.md, tekst-print.html
```

Текст выступления правится в `src/tekst.js` — из него же берутся заметки в .pptx.
PDF слайдов — конвертацией .pptx через LibreOffice, PDF текста — из `src/tekst-print.html` через Chromium (см. `CLAUDE.md`).
