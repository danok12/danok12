Первые параметры

Восемь задач от самой простой до лёгкой экзаменационной. Каждая решена по шагам. Решения закрыты: сначала попробуй сама.

00Как думать о параметре

Параметр a — это число, которое уже выбрали, но не назвали. Пока решаешь, a ведёт себя как обычное число: его можно подставлять, складывать, им можно делить, если оно не ноль.

Ответ в задаче с параметром — все значения a, при которых выполнено условие. Записывают его как множество: a ∈ [1; 5), a ∈ {1; 5}, a = 2.

План, который работает почти всегда

  1. Ограничения. ОДЗ: корень, логарифм, знаменатель.
  2. Особые значения a. Коэффициент при старшей степени равен нулю; кандидаты в корни совпадают; кандидат попадает в выколотую точку или на границу ОДЗ.
  3. Общий случай. Все остальные a.
  4. Сбор ответа. Отдельно проверить каждое граничное a: входит оно или нет.

Словарь условия

«ровно один корень» — один, не больше и не меньше.

«хотя бы один» — один или больше.

«не имеет корней» — ни одного, включая случай, когда уравнение теряет смысл.

«различных корней» — совпавшие считаются один раз.

01Линейное уравнение

Уравнение kx = b: если k ≠ 0 — один корень x = b/k; если k = 0, b ≠ 0 — корней нет; если k = 0, b = 0 — подходит любое x.

Пример 1три случая

Найдите все значения a, при которых уравнение (a² − 4)x = a² + a − 2 а) не имеет корней; б) имеет бесконечно много корней; в) имеет ровно один корень.

Подробное решение

Разложим на множители коэффициент и правую часть: (a − 2)(a + 2)·x = (a + 2)(a − 1).

Коэффициент при x равен нулю при a = 2 и a = −2. Эти значения разбираем отдельно.

a = 2: 0·x = 4 — корней нет.

a = −2: 0·x = 0 — верно при любом x, корней бесконечно много.

a ≠ ±2: делим на коэффициент, x = (a − 1)/(a − 2) — ровно один корень.

Ловушка. Если сразу сократить обе части на (a + 2), случай a = −2 исчезнет. Сокращать на выражение с параметром нельзя, пока не проверено, что оно не ноль.

Ответ: а) a = 2; б) a = −2; в) a ≠ ±2

02Квадратное уравнение

При A ≠ 0 уравнение Ax² + Bx + C = 0 имеет два корня при D > 0, один при D = 0, ни одного при D < 0. Но если a стоит перед x², сначала разбираем A = 0.

Пример 2параметр при x²

Найдите все значения a, при каждом из которых уравнение (a − 1)x² − 2(a + 1)x + a + 4 = 0 имеет ровно один корень.

Подробное решение

Шаг 1. Старший коэффициент равен нулю: a = 1. Уравнение становится линейным: −4x + 5 = 0, x = 5/4. Корень ровно один — a = 1 подходит.

Шаг 2. a ≠ 1, уравнение квадратное. Один корень ⇔ D = 0.

D/4 = (a + 1)² − (a − 1)(a + 4) = a² + 2a + 1 − a² − 3a + 4 = 5 − a.

D = 0 при a = 5. Проверка: 4x² − 12x + 9 = 0, (2x − 3)² = 0, x = 1,5.

Ловушка. Самая частая потеря баллов — ответ «a = 5» без a = 1.

Ответ: a ∈ {1; 5}

03Произведение и дробь

Произведение равно нулю, когда один из множителей равен нулю, а остальные при этом имеют смысл. Дробь равна нулю, когда числитель равен нулю, а знаменатель — нет. В этих задачах ответ решают совпадения кандидатов и ОДЗ.

Пример 3произведение с корнем

Найдите все значения a, при каждом из которых уравнение (x² − 6x + 5)·√x − a = 0 имеет ровно два различных корня.

Подробное решение

ОДЗ: x ≥ a.

Кандидаты. Из корня: x = a — в ОДЗ при любом a, значит, это корень всегда. Из скобки: x = 1 и x = 5 — это корни, только если 1 ≥ a и 5 ≥ a.

Перебираем положение a относительно 1 и 5:

a < 1: корни a, 1, 5 — три.
a = 1: корень x = a совпал с 1, корни 1 и 5 — два.
1 < a < 5: 1 вне ОДЗ, корни a и 5 — два.
a = 5: корень 5 — один.
a > 5: корень a — один.

На картинке по горизонтали — a, по вертикали — x. Корни при данном a — это точки вертикальной прямой на линиях x = a, x = 1, x = 5, лежащие не ниже диагонали x = a. При a = 3 таких точек две.

Ответ: a ∈ [1; 5)

Пример 4дробь и выколотая точка

Найдите все значения a, при каждом из которых уравнение (x − a)(x − 3)x − 2 = 0 имеет ровно один корень.

Подробное решение

Дробь равна нулю ⇔ числитель равен нулю и x ≠ 2.

Кандидаты: x = 3 (годится всегда, 3 ≠ 2) и x = a.

Корней два, если x = a — новый и допустимый корень. Чтобы остался один, кандидат x = a должен «пропасть»:

— совпасть с 3: a = 3;
— попасть в выколотую точку: a = 2.

Ответ: a ∈ {2; 3}

04Графический метод: прямая y = a

Если параметр удалось оставить одного в одной части — f(x) = a, — число корней равно числу точек пересечения графика y = f(x) с горизонтальной прямой y = a. Строим график один раз и двигаем прямую снизу вверх.

Пример 5горизонтальная прямая

При каких a уравнение |x² − 4x + 3| = a имеет ровно три корня? Ровно четыре?

Подробное решение

График. Парабола y = x² − 4x + 3: нули 1 и 3, вершина (2; −1). Модуль отражает часть под осью вверх — получается «горб» с вершиной (2; 1).

Двигаем прямую y = a снизу вверх:

a < 0 — 0 точек; a = 0 — 2 (x = 1, x = 3);
0 < a < 1 — 4;
a = 1 — 3 (прямая касается горба в x = 2);
a > 1 — 2.

Ответ: три корня при a = 1; четыре при a ∈ (0; 1)

05Прямая, которая вращается

Если в уравнении есть ax + b с фиксированным b, это прямая через точку (0; b) с угловым коэффициентом a. Меняя a, мы вращаем прямую вокруг этой точки. Ищем «особые» положения: через угол графика и параллельно его частям.

Пример 6пучок прямых

Найдите все значения a, при каждом из которых уравнение |x − 2| = ax + 1 имеет ровно два корня.

Подробное решение

Слева — «галочка» с вершиной (2; 0), ветви с наклонами −1 и 1. Справа — прямая через точку (0; 1).

Особые положения. Через вершину (2; 0): 0 = 2a + 1, a = −1/2 — одна общая точка. Параллельно правой ветви: a = 1 — пересекает только левую ветвь.

Между ними, при −1/2 < a < 1, прямая режет обе ветви — два корня. При a ≥ 1 — одна точка, при −1 ≤ a < −1/2 — ни одной, при a < −1 — одна.

Проверка алгеброй. При x ≥ 2: x − 2 = ax + 1, x = 3/(1 − a); условие x ≥ 2 даёт −1/2 ≤ a < 1. При x < 2: 2 − x = ax + 1, x = 1/(a + 1); условие x < 2 даёт a > −1/2 или a < −1. Два корня — когда работают обе ветви.

Ответ: a ∈ (−1/2; 1)

06Окружность и прямая

Уравнение (x − x₀)² + (y − y₀)² = R² — окружность. Прямая и окружность имеют 2 общие точки, если расстояние от центра до прямой меньше R, одну — если равно, ни одной — если больше.

Пример 7система

Найдите все значения a, при каждом из которых система x² + y² = 8,y = x + a имеет ровно одно решение; ровно два решения.

Подробное решение

Геометрия. Окружность: центр (0; 0), R = √8 = 2√2. Прямые y = x + a параллельны друг другу, a сдвигает прямую вверх-вниз.

Расстояние от (0; 0) до прямой x − y + a = 0: |a|/√2. Касание: |a|/√2 = 2√2, |a| = 4.

Алгебра (то же самое). Подставим y: 2x² + 2ax + a² − 8 = 0, D/4 = a² − 2(a² − 8) = 16 − a². Одно решение при D = 0, два при D > 0.

Ответ: одно решение при a = ±4; два при a ∈ (−4; 4)

07Задача уровня ЕГЭ

Экзаменационные задачи собраны из тех же кирпичиков: ОДЗ, кандидаты, совпадения, график.

Пример 8всё вместе

Найдите все значения a, при каждом из которых уравнение (x² − 2x − a)·√x + 1 = 0 имеет ровно два различных корня.

Подробное решение

ОДЗ: x ≥ −1. Корень x = −1 (из второго множителя) есть при любом a.

Остальные корни: x² − 2x = a при x ≥ −1. Это пересечения куска параболы y = x² − 2x (x ≥ −1) с прямой y = a. Вершина (1; −1), на левом конце y(−1) = 3, точка (−1; 3) входит.

Точки пересечения: a < −1 — 0; a = −1 — 1; −1 < a ≤ 3 — 2; a > 3 — 1.

Совпадение. При a = 3 одна из точек — x = −1, а он уже посчитан. Различных корней:

a < −1: 1; a = −1: 2; −1 < a < 3: 3; a = 3: 2 (−1 и 3); a > 3: 2.

Ответ: a ∈ {−1} ∪ [3; +∞)
