`python make_dxf.py && python proverka.py && python vypusk_acad.py` (книга Excel — `python make_xlsx.py` и пересчёт формул в LibreOffice перед `proverka.py`).

### Оформление (одно на все листы курсовой)

Все листы собираются из общих элементов `make_dxf.py`: константы в начале файла, слои `LAYERS`, один размерный стиль, рамка со штампом, `image_title`, `volume_table`, `level`, `axis_bubble`. Новый чертёж делать только через них.
- Шрифт — «GOST type B» АСКОН (ГОСТ 2.304-81 тип Б, как в КОМПАС-3D; пропорции проверены: прописные 6/10 h, строчные 7/10 h, интервал 2/10 h). В стиле — файл `GOST_B.TTF` и семейство «GOST type B»; AutoCAD находит шрифт по семейству.
  Шрифт должен быть установлен **для всех пользователей** (`C:\Windows\Fonts`): установленный только для пользователя AutoCAD не видит и печатает Arial. На этом компьютере установлен 06.10.2026.
- Высоты шрифта только из ряда ГОСТ 2.304: 2,5 мм — текст, размеры, отметки, штамп; 3,5 — заголовки таблиц, шифр, цифры листа; 5 — наименования изображений, марки осей, ПВ/ПН.
- Линии по ГОСТ 2.303: основная s = 0,5 мм, тонкие 0,18–0,25 (штриховка не тоньше s/3); оси — штрихпунктир 20/1,5/1/1,5 мм, невидимое и проектные поверхности — штрихи 6/1,5 мм; длины в мм листа (PSLTSCALE = 1), поэтому одинаковы на листах 1:2000, 1:500 и 1:50.
- Цвета слоёв одни на всех листах: размеры зелёные, отметки (рабочие и уровней) синие, ЛНР красная, штриховки серые.
- Компоновка: наименование изображения у верхней рамки (y = 283 мм), таблица объёмов в нижней полосе слева от штампа на одном месте (x = 128 мм, ширина 96 мм), примечания — над штампом (ГОСТ 2.316).

### Принятые данные и допущения

- Отметки h1…h24 — приложение 1, столбец 2. Вершины нумеруются построчно слева направо, сверху вниз (проверено на примере из методички: лист Иминовой = вариант 12).
- h = Hкр − Hчёрн: «−» — выемка (ПВ), «+» — насыпь (ПН), как на примерах кафедры.
- Нумерация фигур: целый квадрат — «n»; разделённый ЛНР — выемка «n», насыпь «n′» (как 3′ на доске).
- hср фигуры = среднее |h| по её вершинам, точки нуля входят нулями (как hср3 = (0,47+0,64+0,45+0+0)/5 на доске).
- Kор = 1,04: супесь, остаточное разрыхление 3–5 % (табл. П2.1). Меняется в ячейке `Исходные данные!B4`.
- Шрифт чертежа и книги Excel — один: «GOST type B» (см. «Оформление»).

### Совместимость с nanoCAD

Лист проверен по скриншоту из nanoCAD x64 25 (учебная версия) и исправлен:
- в пространстве листа сохранён главный видовой экран (id 1): без него план внутри рамки не показывается;
- все надписи - MTEXT: однострочный TEXT с центровкой nanoCAD сдвигает вправо;
- в тексте только кириллица, латиница, цифры и «№»: в GOST_B.TTF нет длинного тире и знака минус (были квадратики), поэтому минус - дефис (так и оставлено — чертёж должен открываться и там, где стоит GOST_B);
- м² и м³ - уменьшенная цифра вверху строки средствами MTEXT;
- кодовая страница файла ANSI_1251.

`proverka.py` проверяет всё это, поэтому эти ошибки не вернутся.

### Проверка в AutoCAD 2026

Найдено при печати из AutoCAD и исправлено в `make_dxf.py`:
- формат бумаги был `ezdxf_(420x297)` — AutoCAD такого не знает; теперь `ISO full bleed A3` на `DWG To PDF.pc3`, acad.ctb;
- оси и линия планировки печатались почти сплошными (штрих 0,5 мм): масштаб типов линий задавался в метрах модели, а AutoCAD масштабирует их по листу; теперь типы линий ГОСТ 2.303 в мм листа;
- главный видовой экран листа лежал на слое `VIEWPORTS` — AUDIT AutoCAD считал это ошибкой; теперь слой 0, AUDIT — 0 ошибок;
- рабочие отметки на листе 1 наезжали на засечки размеров у вершин — сдвинуты на 1,8 мм и рисуются поверх размеров;
- в разрезе числа «200» и на плане «3000» не помещались между выносными — вынесены на полку и на продолжение размерной линии (ГОСТ 2.307);
- высоты шрифта 2,0 и 3,0 мм (не из ряда ГОСТ 2.304) заменены на 2,5 и 3,5;
- на откосах пандуса добавлены бергштрихи; разрез назван «Разрез 1-1» (как в штампе); лишнее примечание «Грунт - супесь» (есть в штампе) убрано.

`proverka.py` проверяет шрифт, формат печати, типы линий и слой главного экрана.

## Котлован (Задание 4, вариант 2)

Расчёт выполняет `kotlovan.py`. В Excel ему соответствуют листы «Котлован» и «Сводный баланс». На чертеже котлован нанесён на «Лист 1» (план площадки), а «Лист 2» — план котлована М 1:500 и разрез 1-1 М 1:50, оформленные по СПДС. Размеры на нём в мм, отметки в м (знак ▽, 0,000 — проектная отметка планировки). Грунт заштрихован по ГОСТ 2.306, слои подписаны многослойной выноской. Из задания взяты только габариты; грунт — супесь.

- **Здание.** По осям Г-образное: 60 × 30 м с вырезом 42 × 12 м. Вариант размещения 8: центр здания совпадает с центром квадрата 8.
- **Привязки по схеме фундамента.** Стена 400 мм стоит по оси, поэтому до наружной грани 0,2 м. Дальше 0,5 м — вылет плиты, 0,2 м — выход подготовки, 0,5 м — рабочая зона. Итого низ котлована отстоит от осей на 1,4 м.
- **Положение относительно ЛНР.** ЛНР срезает угол котлована. Среднее рабочих отметок по углам равно +0,144 (билинейно по квадрату 8), значит котлован в зоне насыпи и разрабатывается от естественной поверхности. Фактическая глубина hк = Нк − hр = 2,4 − 0,165 = 2,235 м.
- **Откос.** Супесь при глубине до 3 м — 1:0,67, заложение l = 1,497 м.
- **Габариты.** По низу 62,8 × 32,8 м, Fк.н = 1555,84 м². По верху 65,79 × 35,79 м, Fк.в = 1851,12 м².
- **Пандус** (принято: b = 3 м, i = 0,1): длина 22,35 м, Vпан = 99,86 м³.
- **Объёмы.**
  - Котлован: Vк = 3902,37 м³.
  - Подсыпка: Vподс = 155,58 м³.
  - Бетонная подготовка: Vб.п = 219,19 м³.
  - Подземная часть: Vп.ч = 2681,06 м³.
  - Обратная засыпка: Vо.з = 846,54 м³.
- **Сводный баланс до корректировки:** Vв = 24 094,45 м³, Vн / Kор = 33 046,69 м³, баланс −8952,24 м³ (27,1 % при допуске 5 %). Нужна поправка Δh = −0,0604 м и перерасчёт — это следующий этап.

`proverka.py` сверяет величины котлована в Excel с `kotlovan.py`, а контуры котлована в DXF — с расчётом.
