# Курсовой проект: внутренний водопровод и канализация жилого здания

Курсовой по дисциплине «Водоснабжение и водоотведение» (НИУ МГСУ). Графическая часть выполняется в Revit 2025, к ней прилагается пояснительная записка.
Эта папка — передача дел между сессиями Claude: облачная сессия разобрала материалы, а модель строит локальная сессия на компьютере с Revit.

## Что входит в проект (по методичке)

**Графическая часть:**
- генплан М 1:500 с сетями В1 и К1;
- план типового этажа и план подвала М 1:100 (стояки нумеруются по часовой стрелке);
- аксонометрия В1 М 1:100 или 1:200, фронтальная изометрия с левой системой осей, Y под 45°; диктующий стояк вычерчивается полностью;
- аксонометрия К1;
- продольный профиль дворовой канализации, вычерчивается слева направо по ходу воды;
- спецификации над штампом, позиции нумеруются снизу вверх.

Рамка листа: слева 20 мм, с остальных сторон по 5 мм.

**Пояснительная записка:**
1. Расходы: суточные (1.3), среднечасовые (1.4), секундные P и q = 5αq₀ (1.5–1.6), часовые Phr и q_hr = 0,005αq₀,hr (1.7–1.8).
2. Гидравлический расчёт В1 по диктующему направлению: таблица из 14 столбцов, V = 0,3–1,5 м/с, h = iL(1 + Kм.с), Kм.с = 0,3.
3. Ввод и водосчётчик: подбор по среднечасовому расходу, проверка h = S·q² (не больше 5 м для крыльчатого, 2,5 м для турбинного).
4. Требуемый напор Hтр = Hgeom + ΣHl + Hпр + ΣHвод + Hввод. Если Hтр больше Hгар, подбирается насос на напор Hр.
5. К1: стояки q_s = q_tot + q₀s по табл. К; горизонтальные участки q = q_hr/3,6 + Ks·q₀s (Ks по табл. 5.1); подбор по Лукиным, условие V·√(h/d) ≥ K (K = 0,5 для пластика, 0,6 для остальных), V ≥ 0,7 м/с, h/d ≥ 0,3; иначе уклон не меньше 1/d.
6. Отметки лотков и глубина колодцев дворовой сети: колодцы не реже чем через 35 м при d = 150; контрольный колодец в 1,0–1,5 м от красной линии; трубы разных диаметров соединяются «шелыга в шелыгу».

**Оформление записки** (СК о ПВД):
- Times New Roman 14 пт, интервал 1,5, поля 25/10/20/20 мм, абзац 12,5 мм, номер страницы сверху по центру;
- формулы нумеруются в пределах раздела, «(1.2)»;
- подписи: «Рисунок 2.3 – …» под рисунком, «Таблица 1.1 – …» над таблицей;
- в списке литературы не меньше 10 источников по ГОСТ Р 7.1, из них не меньше 20 % нормативных.

## Найденные нюансы

- **Свободный напор у верхнего прибора — не меньше 20 м** (п. 8.21, изм. 3). Почти наверняка понадобится повысительная насосная установка.
- **Ошибка в методичке, алгоритм К1, шаг 5**: написано «часовая вероятность для холодной воды», а по обозначению и формуле нужна общая (Phr^tot, q₀,hr^tot). Считаем по общей.
- **α в примерах методички** берётся по ближайшему *меньшему* табличному NP, без интерполяции: например, для NP = 0,5628 взято 0,717. В `normy.alpha_b2` есть оба режима, `floor` и `interp`. Какой принимать, уточнить у преподавателя; по умолчанию как в методичке.
- **В методичке «ванны от 1500 мм»**: q_u^tot = 180 л/сут, q_hr^tot = 11,6 л/ч, горячей 6,5 л/ч, q₀ = 0,3 (общая) и 0,2 (холодная) л/с, q₀,hr = 300 и 200 л/ч. Это совпадает с действующей табл. А.2.

## План работы (выбран вариант «скрипты Revit API + computer use»)

1. Локальная сессия Claude Desktop на ПК с Revit 2025 (вкладка Code, рабочая папка курсового), Computer use включён.
2. Установить pyRevit (актуальный релиз с GitHub pyrevitlabs, с поддержкой Revit 2025). Запасной вариант — Dynamo с узлом Python Script.
3. Диагностический скрипт выгружает в файл семейства, типы труб и систем, уровни и шаблоны видов. Без него названия семейств будут неверными.
4. Расчёты по заданию → файл данных (участки, диаметры, уклоны, отметки).
5. Построение по этапам, после каждого проверка скриншотом:
   1. уровни, оси, стены, перекрытия;
   2. приборы;
   3. В1;
   4. К1 с уклонами;
   5. виды и аксонометрия;
   6. листы, штамп, спецификации.
6. Пояснительная записка .docx, таблицы берутся из того же файла данных.
7. Разбор для защиты: что и почему так посчитано, типовые вопросы.
