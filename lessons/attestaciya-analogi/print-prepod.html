Аттестация: аналоги задач 1–11 — ответы и решения

Линейная алгебра · по образцу «Примерных задач на экзамен», задачи 1–11

Все ответы пересчитаны программой (build.py, точная арифметика sympy). Под каждым вариантом — ключевые промежуточные числа, по которым удобно найти, где ученик сбился. Оранжевым — типичная ошибка в этом типе задач.

1Угол между функциями в C[0;1]

А
Найдите косинус угла между функциями f, g ∈ C[0;1]:   f(x) = 2x + 1 и g(x) = x − 1 в евклидовом пространстве со скалярным произведением (f,g) = ∫10f(x)·g(x)dx.
Ответ: cosφ = −52√13 = −5√1326
(f,g) = ∫10(2x² − x − 1)dx = 23 − 12 − 1 = −56;   ‖f‖² = ∫10(4x² + 4x + 1)dx = 133;   ‖g‖² = ∫10(x − 1)²dx = 13;   ‖f‖·‖g‖ = √133.
Б
Найдите косинус угла и сам угол между функциями f(x) = x и g(x) = 3x − 2 в C[0;1] с тем же скалярным произведением. Что можно сказать об этих функциях?
Ответ: cosφ = 0,  φ = 90°: функции ортогональны
(f,g) = ∫10(3x² − 2x)dx = 1 − 1 = 0; нормы считать уже не нужно (‖f‖ = 1√3, ‖g‖ = 1).
Типичная ошибка. Забывают брать корень: в знаменатель ставят ‖f‖²·‖g‖² вместо ‖f‖·‖g‖. Второе — ошибки при раскрытии (x − 1)²: пишут x² − 1. Ловить проверкой |cosφ| ≤ 1.

2Дополнение до ортонормированного базиса в R³

А
В пространстве L = R³ в стандартном базисе i, j, k заданы два вектора a = (2, 1, −2) и b = (1, 2, 2). Убедитесь, что они ортогональны, и дополните их третьим вектором до ортонормированного базиса. В ответе укажите все три вектора.
Ответ: e1 = 13(2, 1, −2);   e2 = 13(1, 2, 2);   e3 = 13(2, −2, 1)
(a,b) = 2 + 2 − 4 = 0.   a × b = (6, −6, 3) ∥ (2, −2, 1). Все три длины равны 3. Годится и e3 = 13(−2, 2, −1).
Б
То же для a = (1, 1, 1) и b = (1, −2, 1).
Ответ: e1 = 1√3(1, 1, 1);   e2 = 1√6(1, −2, 1);   e3 = 1√2(1, 0, −1)
(a,b) = 1 − 2 + 1 = 0.   a × b = (3, 0, −3) ∥ (1, 0, −1). Длины: √3, √6, √2. Знак у e3 любой.
Типичная ошибка. Нормируют только третий вектор, а a и b оставляют как есть — базис ортогональный, но не ортонормированный. Или делят на сумму координат вместо длины.

3Ранг квадратичной формы

А
Найдите ранг квадратичной формы f(x1, x2, x3) = x1² + 4x2² + 16x3² + 6x1x2 + 12x1x3 + 16x2x3.
Ответ: r = 2
Матрица 1363486816: третья строка = 2 · вторая, а минор 1334 = −5 ≠ 0.
Б
То же для f = x1² + 5x2² + 2x3² − 4x1x2 − 2x1x3 + 6x2x3.
Ответ: r = 2
Матрица 1−2−1−253−132: третья строка = первая + вторая, минор 1−2−25 = 1 ≠ 0.
В
То же для f = x1² + 4x2² + 9x3² + 4x1x2 − 6x1x3 − 12x2x3.
Ответ: r = 1
Матрица 12−324−6−3−69: все строки пропорциональны первой. Действительно, f = (x1 + 2x2 − 3x3)².
Типичная ошибка. Главная ошибка — ставить в матрицу полный коэффициент при xᵢxⱼ (6, 12, 16), а не половину (3, 6, 8). Ранг при этом может получиться 3. Ловить: матрица обязана быть симметричной, а xᵀAx должен вернуть исходную форму.

4Базис и размерность пространства решений однородной системы

А
Найдите какой-нибудь базис и установите размерность пространства решений однородной системы x1 − x2 + 2x3 + x4 − x5 = 0;x2 + x3 − 2x4 + 3x5 = 0.
Ответ: dimL = 3;   e1 = (−3; −1; 1; 0; 0),  e2 = (1; 2; 0; 1; 0),  e3 = (−2; −3; 0; 0; 1)
Свободные x3, x4, x5.  x2 = −x3 + 2x4 − 3x5;  x1 = x2 − 2x3 − x4 + x5 = −3x3 + x4 − 2x5.
Б
То же для системы x1 + 2x2 − x3 + x4 + 3x5 = 0;2x1 + 5x2 − x3 + 4x4 + 4x5 = 0;x1 + 3x2 + 3x4 + x5 = 0.
Ответ: dimL = 3;   e1 = (3; −1; 1; 0; 0),  e2 = (3; −2; 0; 1; 0),  e3 = (−7; 2; 0; 0; 1)
Третье уравнение = второе − первое, поэтому r = 2, а не 3. После вычитания: x2 = −x3 − 2x4 + 2x5;  x1 = 3x3 + 3x4 − 7x5.
Типичная ошибка. В варианте Б считают уравнения, а не ранг: «три уравнения — значит dim = 5 − 3 = 2». Каждый найденный вектор подставить в исходную систему — это 30 секунд и ловит почти всё.

5Матрица линейного оператора в пространстве матриц 2×2

А
Пусть L = M2×2. Найдите матрицу A линейного оператора f(M) = 2−113T·M в стандартном базисе пространства L.
Ответ: A = 20100201−10300−103
Сначала транспонировать: 2−113T = 21−13. f(E1) = 20−10 → столбец (2; 0; −1; 0), и т.д.
Б
То же для оператора f(M) = M·120−1 (умножение справа).
Ответ: A = 10002−1000010002−1
f(E1) = 1200 → (1; 2; 0; 0);   f(E2) = 0−100 → (0; −1; 0; 0); E3, E4 — то же во второй строке.
Типичная ошибка. Записывают образы базисных матриц в строки, а не в столбцы — получается Aᵀ. Второе — в варианте А забывают транспонировать матрицу из условия. Проверка: A·(координаты M) должно дать координаты f(M) для любой M, например M = (1 1; 1 1).

6Длины и угол по матрице Грама

А
В базисе {e1, e2} дана матрица Грама скалярного произведения G = 3−1−12 и векторы x = 21, y = −13. Найдите длины векторов x и y, а также угол между ними.
Ответ: ‖x‖ = √10,  ‖y‖ = √27 = 3√3,  cosφ = −5√10·√27 = −53√30
GY = (−6; 7), (x,y) = 2·(−6) + 1·7 = −5.   GX = (5; 0), (x,x) = 10.   GY·Y = 6 + 21 = 27.
Б
То же для G = 4223, x = 5−6, y = 11. Отдельно ответьте: ортогональны ли x и y в этом скалярном произведении? А если бы скалярное произведение было обычным?
Ответ: ‖x‖ = √88 = 2√22,  ‖y‖ = √11,  cosφ = 0 — ортогональны; в обычном скалярном произведении 5 − 6 = −1 ≠ 0, не ортогональны
GY = (6; 5), (x,y) = 30 − 30 = 0.   GX = (8; −8), (x,x) = 40 + 48 = 88.
Типичная ошибка. Считают обычное скалярное произведение 2·(−1) + 1·3, забывая про G. Или берут только диагональ G. Ловить: (x,x) по матрице Грама обязано быть > 0.

7Координаты многочлена в новом базисе

А
В линейном пространстве P1 многочленов степени не выше 1 в стандартном базисе (x; 1) заданы три многочлена: p(x) = 2x + 1;  f1(x) = x + 3;  f2(x) = 2x + 5. Найдите координаты многочлена p(x) в новом базисе f1; f2.
Ответ: p(x) = −8f1 + 5f2 = (−8; 5)
x:  c1 + 2c2 = 21:  3c1 + 5c2 = 1   Проверка: −8(x + 3) + 5(2x + 5) = 2x + 1 ✓
Б
В пространстве P2 многочленов степени не выше 2 в стандартном базисе (x²; x; 1) даны p(x) = 2x² − x + 5 и f1 = x² + 1, f2 = x² + x, f3 = x + 1. Найдите координаты p(x) в базисе f1; f2; f3.
Ответ: p(x) = 4f1 − 2f2 + f3 = (4; −2; 1)
x²:  c1 + c2 = 2x:  c2 + c3 = −11:  c1 + c3 = 5   Проверка: 4x² + 4 − 2x² − 2x + x + 1 = 2x² − x + 5 ✓
Типичная ошибка. В ответ пишут коэффициенты самого p (2; 1) — это координаты в старом базисе. Проверка подстановкой c₁f₁ + c₂f₂ обязательна.

8Матрица оператора в R³ и образ вектора

А
Найдите матрицу A линейного оператора f((x1, x2, x3)) = (2x1 − x2 + 4x3;  x1 + 3x3;  −x1 + 5x2 − 2x3) в стандартном базисе пространства L = R³ и образ вектора x = (2; −1; 3).
Ответ: A = 2−14103−15−2;   f(x) = (17; 11; −13)
Во второй координате нет x2 — в матрице 0.   4 + 1 + 12 = 17;  2 + 0 + 9 = 11;  −2 − 5 − 6 = −13.
Б
То же для f((x1, x2, x3)) = (x2 − x3;  3x1 + x2;  x1 − 2x2 + 4x3) и x = (1; −2; 3).
Ответ: A = 01−13101−24;   f(x) = (−5; 1; 17)
−2 − 3 = −5;  3 − 2 = 1;  1 + 4 + 12 = 17.
Типичная ошибка. Пропущенная переменная: в строку (x₁ + 3x₃) пишут (1, 3) и сдвигают столбцы. Всегда три числа в строке.

9К какому собственному значению относится вектор

А
Линейный оператор f в базисе e1, e2, e3 задан матрицей A = 24131−1131. Вектор x = −e1 + e2 − e3 является собственным вектором оператора f. Найдите, к какому собственному значению он относится.
Ответ: λ = −1
X = (−1; 1; −1),  AX = (1; −1; 1) = −1·X.
Б
Оператор задан матрицей A = 4−11213−212. Какой из векторов x = e1 + 2e2 и y = e1 + e2 + e3 является собственным? К какому собственному значению он относится?
Ответ: x — собственный, λ = 2;  y — не собственный
AX = (2; 4; 0) = 2·(1; 2; 0).   AY = (4; 6; 1) — не пропорционален (1; 1; 1).
Типичная ошибка. Координаты вектора −e₁ + e₂ − e₃ пишут без знаков или пропускают нулевую координату (в оригинале −2e₁ + 2e₃ → (−2; 0; 2)). Ищут λ через характеристический многочлен — долго и не нужно.

10Собственный вектор для данного собственного значения

А
Для линейного оператора, заданного матрицей A = 30−12103−11, найдите какой-нибудь собственный вектор, соответствующий собственному числу λ = 2.
Ответ: r = (1; 2; 1)  (или любой ненулевой кратный)
A − 2E = 10−12−103−1−1, ранг 2 (третья строка = первая + вторая): x3 = x1, x2 = 2x1.   A·(1; 2; 1) = (2; 4; 2) ✓
Б
Для матрицы A = 0−122−34−11−3 найдите какой-нибудь собственный вектор, соответствующий λ = −1. Сколько линейно независимых собственных векторов отвечает этому значению?
Ответ: например, (1; 1; 0) или (−2; 0; 1);  таких независимых векторов два
A + E = 1−122−24−11−2 — все строки пропорциональны, ранг 1, остаётся одно уравнение x1 − x2 + 2x3 = 0: две свободные переменные.
Типичная ошибка. Вычитают λ из всех элементов, а не только из диагонали. Или для λ = −1 вычитают −1 «в ту же сторону» и получают A − E. Нулевой вектор в ответ — не собственный вектор.

11Канонический вид квадратичной формы ортогональным преобразованием

А
Приведите квадратичную форму Φ(x1, x2) = x1² + 5x2² + 4√3x1x2 к каноническому виду и укажите соответствующее ортогональное преобразование координат.
Ответ: Φ(y1, y2) = −y1² + 7y2²,  x1x2 = √3212−12√32y1y2
A = 1['2', <__main__.Sq object at 0x7f9c61a8b070>]['2', <__main__.Sq object at 0x7f9c61a8b0e0>]5,  λ² − 6λ − 7 = 0, λ = −1; 7. Для −1: x1 = −√3x2 → (√3; −1)/2; для 7: x2 = √3x1 → (1; √3)/2. Это поворот на −30°.
Б
То же для Φ(x1, x2) = −x1² + 4x2² + 12x1x2.
Ответ: Φ(y1, y2) = −5y1² + 8y2²,  x1x2 = 3√132√13−2√133√13y1y2

Типичная ошибка. Снова «половина коэффициента»: для 12x₁x₂ в матрицу идёт 6, а не 12 (и 2√3, а не 4√3). Собственные векторы забывают нормировать или ставят их в строки матрицы P. Проверка: сумма коэффициентов канонического вида = следу матрицы (−1 + 7 = 1 + 5), произведение = её определителю.
