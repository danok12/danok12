# Презентации по китайской философии

Стиль — новый китайский минимализм: рисовая бумага, тушь, выдержанная
палитра. Шрифт — **Arial**. На слайде только опора для взгляда, весь текст
выступления — в заметках докладчика и в отдельном файле с речью.

## Результат

### Конфуцианство — основная версия

| Файл | Что это |
|---|---|
| `out/konfucianstvo.pptx` | презентация, 14 слайдов, редактируемая |
| `out/konfucianstvo.pdf` | то же для показа с телефона |
| `out/rech-konfucianstvo.docx` | текст выступления, ~9 минут |
| `out/rech-konfucianstvo.pdf` | речь для чтения с телефона или печати |
| `out/konfucianstvo-sovmestimyy.pptx` | перепакованная копия — если основная где-то не открывается |

### Китайская философия целиком (даосизм + конфуцианство)

Первая, более длинная версия на 21 слайд: `out/kitajskaya-filosofiya.*`

## Структура основной версии

1. Титул · 2. Содержание · 3. Кун Цю, Учитель · 4. Автобиография в шесть строк
5. **Учение** (раздел) · 6. Человек, а не вселенная · 7. Градация знаний
8. Цитата о трёх путях · 9. Благородный муж · 10. Мораль как политика
11. Цитата о ветре и траве · 12. Советы Конфуция · 13. Какой итог?
14. Спасибо за внимание

## Как пересобрать

```bash
pip install python-pptx pillow python-docx

python3 tools/make_assets.py                                      # фоны и иллюстрации
python3 build.py --content content_confucius --out konfucianstvo  # презентация
python3 tools/make_speech.py --content content_confucius --out rech-konfucianstvo
```

Длинную версию собирает `python3 build.py` без аргументов.

## Файлы

- `content_confucius.py` — тексты слайдов и речь для версии о конфуцианстве.
  **Правки текста — только здесь**: отсюда берутся и слайды, и заметки
  докладчика, и файл с речью, поэтому они не расходятся.
- `content.py` — то же для длинной версии.
- `build.py` — вёрстка: палитра, типографика с расчётом высоты строк
  по метрикам шрифта, 15 типов макетов.
- `tools/make_assets.py` — процедурные фоны (бумага, гряды гор тушью, ветка
  сосны) и приведение иллюстраций к единому тушевому дуотону.
- `tools/make_speech.py` — файл с речью: для каждого слайда заголовок,
  строка «На экране» и текст рассказа.
- `assets/raw/` — исходные изображения, `assets/bg/` и `assets/img/` — готовые.

## Дизайн-система

- Палитра: бумага `#EDE9E1`, тушь `#2A2A24`, тёмно-зелёный `#2C382F`,
  бронза `#8C7B5F`, серый `#8A8578`.
- Заголовок слайда — Arial Bold 30 pt, тезис — 15–17 pt, читается с последнего ряда.
- Рубрика и подписи — разрядка 2–3 pt, приглушённый цвет.
- Иллюстрации приведены к общему тушевому дуотону, поэтому фотографии
  и старинная живопись не спорят друг с другом.

## Показ на телефоне

Мобильные просмотрщики часто не тянут полноэкранные фоны и показывают белый
экран. С телефона надёжнее открывать **PDF**; PPTX рассчитан на PowerPoint
на компьютере.
