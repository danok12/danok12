# Чтобы все диалоги открывались с любого устройства

## В чём была проблема

Сессии Claude Code бывают двух видов:

| | Где выполняется | Доступ с телефона |
|---|---|---|
| **Remote Control** (`/remote-control`) | на вашем ноутбуке | только пока ноутбук включён и терминал открыт |
| **Облачная** (`claude --cloud`) | на сервере Anthropic | всегда, ноутбук можно выключить |

Десять старых сессий (РЕПЕТИТОРСТВО, СИРИУС, СОПРОМАТ, МАТЕМАТИКА ВИДЕО и другие) — Remote Control. Поэтому они и недоступны: у всех в статусе `computer_unreachable`. **Переделать их в облачные нельзя** — они физически привязаны к ноутбуку. Настройка ниже касается всех новых.

## Настройка ноутбука — один раз

Открыть терминал и выполнить:

```bash
# 1. клон репозитория, если его ещё нет
git clone https://github.com/danok12/danok12
cd danok12

# 2. вход в аккаунт claude.ai (не по API-ключу)
claude
```

Дальше внутри Claude Code, по одной команде:

```
/login          вход в аккаунт claude.ai, если ещё не выполнен
/status         в строке Login method должен быть аккаунт claude.ai
/web-setup      передаёт токен gh, чтобы облачные сессии видели репозитории
/mobile         QR-код для установки приложения на телефон
```

Если `/web-setup` не находится — значит вход по API-ключу; сделать `/login` и повторить.

## Как запускать сессии дальше

```bash
claude --cloud "собери занятие по теме X"
```

Сессия создаётся в облаке, привязана к репозиторию, видна с телефона и из браузера. Ноутбук можно закрыть.

Чтобы не набирать `--cloud` каждый раз, добавить в `~/.zshrc` (macOS) или `~/.bashrc` (Linux/WSL):

```bash
alias cc='claude --cloud'
```

После этого достаточно `cc "задача"`. Перечитать настройки: `source ~/.zshrc`.

**Важно:** `--remote-control` для таких задач не использовать — именно он создаёт сессии, привязанные к ноутбуку.

## С других устройств

- **Браузер:** закладка `https://claude.ai/code?repositories=danok12/danok12` — репозиторий уже выбран.
- **Телефон:** приложение Claude, вкладка Code.
- **Вернуть облачную сессию в терминал ноутбука:** `claude --teleport` (выбор из списка) или `claude --teleport <id>`.
- **Дописать в запущенную сессию с любой машины:** `claude -p "текст" --cloud <id-сессии>`.

## Проверка, что всё получилось

Запустить `claude --cloud "проверка"` на ноутбуке и открыть claude.ai/code с телефона — сессия должна быть в списке. Затем закрыть ноутбук: сессия остаётся доступной.
