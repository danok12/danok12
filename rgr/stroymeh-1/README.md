# Строительная механика. Задание 1, вариант 2

Источник: МГСУ, кафедра строительной механики. «Расчёт статически определимых
стержневых систем». Задания для студентов бакалавриата. — М., 2015.
Схемы варианта 2 — с. 6, числовые данные — таблица 1, с. 4.

На этом этапе решение **не выполнялось**: выписаны исходные данные и заново
перечерчены пять расчётных схем варианта.

## Исходные данные (таблица 1, строка 2)

| l, м | h, м | q, кН/м | F, кН | m, кН·м |
|---|---|---|---|---|
| 6 | 4 | 1 | 20 | 10 |

Номер строки таблицы преподаватель задаёт отдельно от номера варианта; здесь
принята строка 2 по номеру варианта — это нужно подтвердить.

## Файлы

| файл | что это |
|---|---|
| `shablon.html` | шаблон страницы с местами под стили (`__CSS__`) и схемы (`__FIG_n__`) |
| `index.html` | собранная страница (публикуется как Artifact) |
| `shemy.py` | библиотека черчения расчётных схем и сами пять схем |
| `_css.html` | стили страницы и схем |
| `sborka-pdf.py` | сборка страницы, печатной версии и PDF |
| `shema-*.svg` | перечерченные схемы |
| `*.pdf` | собранная печатная версия |

## Как перечерчивались схемы

Методичка отсканирована в двухцветном режиме (JBIG2), тонкие линии местами
потеряны. Страница варианта рендерилась в PNG через PyMuPDF с увеличением,
положения узлов, шарниров, опор и нагрузок снимались с растра попиксельно
(анализ тёмных пикселей по строкам и столбцам), после чего соотношения участков
сверялись с размерными засечками. Например, для схемы 5 засечки дали цепочку
l, l, l/2, l/2, l/2, l/2, l/2 — то есть полная длина 4,5·l.

Три места скан не разрешает, они перечислены в разделе «Что в скане не читается»
самого документа: горизонтальные размеры схемы 2, точное положение момента m
на схеме 2 и положение точки K на схеме 4.

## Пересборка

```bash
python3 shemy.py        # перечертить схемы
python3 sborka-pdf.py   # index.html + print.html + PDF
```
