## Блок F. Найди ошибку — разборы

**Н1.** Потеряно второе условие: дробь `1/(x − 3)` требует `x ≠ 3`. Верно: `x ≥ −2, x ≠ 3`.

**Н2.** `x = 3` обнуляет знаменатель и в область определения не входит. Верно: один нуль `x = −3`.

**Н3.** Найдена область определения, а спрашивали множество значений. Квадратный корень принимает все неотрицательные значения: `y ≥ 0`.

**Н4.** Равенство для одной пары чисел чётность не доказывает. `f(2) = 10`, `f(−2) = −2` — ни равны, ни противоположны. `f(−x) = −x³ + x² + x` не совпадает ни с `f(x)`, ни с `−f(x)`. Ответ: ни та ни другая.

**Н5.** Пропущен шаг 1: область `−2 ≤ x ≤ 3` несимметрична — `f(3) = 9` есть, `f(−3)` нет. Ответ: ни та ни другая.

**Н6.** Промежутки склеены. `−1 < 1`, но `f(−1) = −4 < 4 = f(1)` — определение убывания нарушено. Верно: убывает при `x < 0` и при `x > 0`, каждый промежуток отдельно.

**Н7.** `x + 3` — сдвиг **влево**. Вершина `(−3; −2)`, наименьшее значение `−2` при `x = −3`. Проверка: `f(3) = 36 − 2 = 34`, а не −2.

**Н8.** Убывающая функция меняет знак неравенства: из `−5 < −4` следует `(−5)⁻³ > (−4)⁻³`. Проверка: `−1/125 = −0,008`, `−1/64 = −0,015625`, и `−0,008 > −0,015625`.
