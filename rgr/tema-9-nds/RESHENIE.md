## 2. Главные напряжения

На главной площадке касательных напряжений нет (σ ≠ 0, τ = 0). Условия для

```

τzx·l + τzy·m + (σz − σ)·n = 0
```

Ненулевое решение существует только при равенстве нулю определителя, что даёт
кубическое уравнение

σ³ − I₁н·σ² + I₂н·σ − I₃н = 0   (1)

### Инварианты

* I₁н = σx + σy + σz = −80 + 60 + (−60) = **−80 МПа**
* I₂н = σxσy + σyσz + σzσx − τxy² − τyz² − τzx² = −4800 − 3600 + 4800 − 8100 − 2500 − 4225 = **−18425 МПа²**
* I₃н = σxσyσz + 2τxyτyzτzx − σxτyz² − σyτzx² − σzτxy² = 288000 − 585000 + 200000 − 253500 + 486000 = **135500 МПа³**

Подставляя в (1): σ³ + 80σ² − 18425σ − 135500 = 0.

### Решение по теореме Виета

Приведённое кубическое σ³ + bσ² + cσ + d = 0, где b = −I₁н = 80, c = I₂н = −18425,
d = −I₃н = −135500. Соотношения Виета — это и есть инварианты:

```
σ₁ + σ₂ + σ₃ = −b = I₁н
σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = c = I₂н        (3)
σ₁·σ₂·σ₃ = −d = I₃н
```

Если известен хотя бы один корень, два других находятся из квадратного уравнения.

## 7. Полная удельная потенциальная энергия упругой деформации

Размерность удельной энергии совпадает с размерностью напряжения:
Дж/м³ = Н·м/м³ = Н/м² = Па, поэтому результат записывается в МПа.

**U₀ = U₀^об + U₀^ф**

### Полная энергия

U₀ = 1/(2E)·[σ₁² + σ₂² + σ₃² − 2ν·(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Суммы в скобках — инварианты, поэтому беру их точно:

* σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = 6400 + 36850 = **43250 МПа²**
* σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = **−18425 МПа²**

U₀ = (43250 + 11055)/(4,2·10⁵) = 54305/(4,2·10⁵) = **0,1293 МПа**

### Энергия изменения формы

U₀^ф = (1 + ν)/(6E)·[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²]

σ₁ − σ₂ = 113,1101; σ₂ − σ₃ = 171,6544; σ₃ − σ₁ = −284,7646 МПа.

Сумма квадратов разностей = 2·(I₁н² − 3·I₂н) = 2·61675 = **123350 МПа²**
(контроль по корням: 113,1101² + 171,6544² + 284,7646² = 123350,0).

U₀^ф = 1,3·123350/(1,26·10⁶) = **0,12727 МПа**

### Энергия изменения объёма

U₀^об = U₀ − U₀^ф = 0,12930 − 0,12727 = **0,00203 МПа**

Проверка по независимой формуле: U₀^об = (1 − 2ν)/(6E)·I₁н² = 0,4·6400/(1,26·10⁶) =
0,00203 МПа — совпало точно.

**Вывод:** U₀ = 0,1293 > U₀^ф = 0,12727 МПа. На формоизменение уходит 98,4 %
всей энергии, на изменение объёма — 1,6 %.

> **Почему не 0,13018.** Ту же энергию можно записать через компоненты:
> U₀ = 1/(2E)·[σx²+σy²+σz² − 2ν(σxσy+σyσz+σzσx)] + 1/(2G)·(τxy²+τyz²+τzx²).
> При G = 0,8·10⁵ из задания выйдет 0,03752 + 0,09266 = 0,13018 МПа. Разница в том,
> что G в задании округлён: согласованное с E и ν значение G = E/[2(1+ν)] = 0,80769·10⁵
> даёт 0,03752 + 0,09177 = 0,1293 МПа — ровно то же, что и по главным напряжениям.
> Формула по главным напряжениям от G не зависит, поэтому в отчёт идёт 0,1293 МПа,
> а 0,13018 — та же величина с округлённым G (расхождение 0,68 %).

## 8. Проверка прочности по IV (энергетической) теории

**Формулировка.** Опасное состояние наступает тогда, когда удельная энергия
формоизменения достигает того же значения, что и в момент наступления опасного
состояния при простом одноосном напряжённом состоянии. Модель Фёппля — Мизеса.

σ_экв^IV = (1/√2)·√[(σ₁ − σ₂)² + (σ₂ − σ₃)² + (σ₃ − σ₁)²] ≤ R·γc

σ_экв^IV = (1/√2)·√123350 = √61675 = **248,34 МПа**

R·γc = 210·0,9 = **189,0 МПа**

σ_экв^IV = 248,34 МПа **> R·γc = 189,0 МПа** — **условие прочности не выполняется**,
превышение **31,4 %**. Прочность в окрестности точки не обеспечена: требуется снизить
уровень напряжений либо применить сталь с более высоким R.

Связь пунктов 7 и 8: U₀^ф = σ_экв²/(6G) = 248,3445²/(6·0,80769·10⁵) = 0,12727 МПа —
то же число, что в п. 7.

**σ₃ = 0; σ₁ = −16,80 МПа; σ₂ = −98,20 МПа**

## 4. Экстремальные касательные напряжения

**Зачем этот пункт.** По главным площадкам касательных напряжений нет вовсе —
в этом их определение. Но рядом есть площадки, где касательное напряжение
наибольшее: по ним материал начинает течь. Такая площадка делит пополам прямой
угол между двумя главными направлениями, то есть наклонена к ним под ±45°.
Пар главных напряжений три — значит, и семейств площадок три.

```
τij = ±(σi − σj)/2,   σ' = (σi + σj)/2          (6)
```

Подставляем σ₁ = −16,8029; σ₂ = −98,1971; σ₃ = 0 МПа:

```
пара σ₁, σ₂ — площадки в плоскости пластины:
  τ₁₂ = ±(−16,8029 + 98,1971)/2 = ±81,3942/2 = ±40,70 МПа
  σ'  =  (−16,8029 − 98,1971)/2 = −115,0000/2 = −57,50 МПа

пара σ₂, σ₃ — площадки наклонены к плоскости пластины:
  τ₂₃ = ±(−98,1971 − 0)/2 = ±98,1971/2 = ±49,10 МПа
  σ'  =  (−98,1971 + 0)/2 = −49,10 МПа

пара σ₃, σ₁ — площадки наклонены к плоскости пластины:
  τ₃₁ = ±(0 + 16,8029)/2 = ±16,8029/2 = ±8,40 МПа
  σ'  =  (0 − 16,8029)/2 = −8,40 МПа
```

Наибольшее из трёх — вторая пара: **τmax = τ₂₃ = 49,10 МПа.**

> Первая строка, 40,70 МПа, — это радиус круга Мора по σx, σy, τxy: её и дала бы
> формула «в плоскости», если ограничиться одним кругом. Но наибольшее касательное
> в точке другое, 49,10 МПа: σ₃ = 0 больше обоих напряжений в плоскости, а они оба
> сжимающие, поэтому самая широкая пара — σ₂ и σ₃. Эта площадка наклонена
> к плоскости пластины, на плоском чертеже её не видно — только на круге Мора
> (рис. 2.6). В примере с занятия такого не возникает: там σ₁ = 100 МПа
> растягивающее, и наибольшей оказывается как раз пара в плоскости.

Элемент на площадках τ₁₂ повёрнут на α = 66,26° − 45° = 21,26° — рис. 2.4.

## 5. Напряжения на площадках под углом α = 15° к осям Ox и Oy

```
σν  = σx·cos²α + σy·sin²α − τxy·sin 2α          (7)
τtν = (σx − σy)/2·sin 2α + τxy·cos 2α           (8)
σt  = σx + σy − σν                              (9)
```

При α = 15°: cos²α = 0,93301; sin²α = 0,06699; sin 2α = 0,5; cos 2α = 0,86603.

```
σν  = −85·0,93301 − 30·0,06699 + 30·0,5 = −79,31 − 2,01 + 15,00 = −66,32 МПа
τtν = (−55/2)·0,5 − 30·0,86603 = −13,75 − 25,98 = −39,73 МПа
σt  = −115 + 66,32 = −48,68 МПа
```

**Проверка по инвариантам** (поворот площадок их не меняет):

```
σν + σt      = −115,000000 МПа  = I₁н   ✓
σν·σt − τtν² =  1650,000000 МПа² = I₂н   ✓
```

Рис. 2.5. Угол 15° взят по разбору на занятии; при другом угле меняются только
четыре тригонометрические величины.

## 6. Относительные линейные и угловые деформации

E = 2,1·10⁵ МПа, ν = 0,3, G = 0,8·10⁵ МПа, σz = 0.

```
εx = (1/E)[σx − ν·σy] = (−85 + 9,0)/2,1·10⁵  = −36,19·10⁻⁵   укорочение dx
εy = (1/E)[σy − ν·σx] = (−30 + 25,5)/2,1·10⁵ =  −2,14·10⁻⁵   укорочение dy
εz = −(ν/E)(σx + σy)  = +34,5/2,1·10⁵        = +16,43·10⁻⁵   удлинение dz
θ  = εx + εy + εz = −21,90·10⁻⁵
контроль: θ = (1−2ν)/E·I₁н = (0,4/2,1·10⁵)·(−115) = −21,90·10⁻⁵   ✓
γxy = τxy/G = −30/0,8·10⁵ = −37,50·10⁻⁵;  γyz = γzx = 0
```

Материал выдавливается вдоль свободной оси z; объём уменьшился — как и должно
быть при двухосном сжатии. При согласованном G = E/[2(1+ν)] = 0,8077·10⁵ МПа
вышло бы γxy = −37,14·10⁻⁵ — расхождение 1 %, на выводы не влияет.

## 7. Удельная потенциальная энергия упругой деформации

Суммы берутся через инварианты, без округления корней:
σ₁² + σ₂² + σ₃² = I₁н² − 2I₂н = 9925 МПа²; σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = 1650 МПа².

```
U₀   = (1/2E)[9925 − 0,6·1650] = 8935/4,2·10⁵  = 0,021274 МПа
U₀ф  = ((1+ν)/6E)·2(I₁н² − 3I₂н) = 16550·1,3/1,26·10⁶ = 0,017075 МПа  (80,3 %)
U₀об = ((1−2ν)/6E)·I₁н² = 13225·0,4/1,26·10⁶          = 0,004198 МПа  (19,7 %)
контроль: U₀ф + U₀об = 0,021274 МПа = U₀   ✓
```

В задаче 1 на формоизменение уходило 98,4 %, здесь 80,3 %: оба главных
напряжения одного знака, поэтому объёмная часть весомее.

## 8. Проверка прочности по энергетической (IV) теории

```
σэкв^IV = (1/√2)·√[(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)²] = √(I₁н² − 3I₂н) = √8275 = 90,97 МПа
90,97 МПа ≤ R·γc = 210·0,9 = 189,0 МПа   ✓
```

**Условие прочности выполняется.** Использовано 48,1 % несущей способности,
запас 2,08. Связь с энергией: U₀ф = ((1+ν)/3E)·(σэкв)² = 0,017075 МПа — то же
число, что в п. 7.

В задаче 1 было 248,34 > 189,0 (превышение 31,4 %). Здесь легче вдвое, хотя
наибольшее по модулю напряжение −98,20 МПа немалое: в энергетический критерий
входят разности σi − σj, а они при двухосном сжатии малы.

## 9. Круг напряжений (круг Мора)

Масштаб 1 см = 10 МПа.

```
OD = σx = −85 МПа;   OB = σy = −30 МПа
OC = (σx + σy)/2 = −57,5 МПа                       — центр
BK = τxy = −30 МПа                                 — вниз, знак минус
R  = CK = √[((σy − σx)/2)² + τxy²] = √(27,5² + 30²) = √1656,25 = 40,70 МПа
OC + R = −16,80 МПа = σ₁;   OC − R = −98,20 МПа = σ₂   — совпало с п. 2  ✓
```

Кругов три: основной по σx, σy, τxy и два вспомогательных через σ₃ = 0.
Радиус наибольшего равен τmax = 49,10 МПа из п. 4 — на одном круге это не видно,
поэтому на рис. 2.6 показаны все три.
