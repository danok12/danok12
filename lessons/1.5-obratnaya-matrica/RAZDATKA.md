# Обратная матрица (§1.5) — раздаточный лист ученика

*(конспект + задачи, без ответов)*

## Обозначения учебника

`|A|` — определитель · `A'` — транспонированная · `Ã` — присоединённая · `Aᵢⱼ` — алгебраическое дополнение

---

## 1. Определение (1.13)

Матрица `A⁻¹` называется **обратной** по отношению к квадратной матрице `A`, если при умножении на `A` как справа, так и слева получается единичная матрица:

```
A⁻¹·A = A·A⁻¹ = E                                    (1.13)
```

Из определения следует:
- обратную имеет **только квадратная** матрица;
- `A⁻¹` — тоже квадратная **того же порядка**;
- `A⁻¹` — обозначение целиком, элементы `A⁻¹` — это **не** `1/aᵢⱼ`.

## 2. Теорема существования

> Обратная матрица `A⁻¹` существует **и единственна** тогда и только тогда, когда исходная матрица **невырожденная**, то есть `|A| ≠ 0`.

`|A| ≠ 0` — невырожденная (неособенная) · `|A| = 0` — вырожденная (особенная)

Из `|A|·|A⁻¹| = |E| = 1` попутно следует: `|A⁻¹| = 1/|A|`.

> **Шаг 0 любой задачи: посчитать `|A|`.** Если ноль — ответ «обратной не существует».

## 3. Присоединённая матрица и формула (1.14)

`Ã` — матрица из алгебраических дополнений элементов **транспонированной** матрицы `A'`:

```
ãᵢⱼ = A'ᵢⱼ = Aⱼᵢ
```

```
             1
A⁻¹  =  ───────  ·  Ã ,        |A| ≠ 0                    (1.14)
           |A|
```

Знаки алгебраических дополнений:
```
| +  -  + |
| -  +  - |
| +  -  + |
```

## 4. Алгоритм — пять шагов

```
1°. Находим |A|.
    |A| = 0  → вырожденная, обратной нет, стоп.
    |A| ≠ 0  → невырожденная, обратная существует.
2°. Находим A' — транспонированную к A.
3°. Находим алгебраические дополнения элементов A'
    и составляем из них присоединённую матрицу Ã.
4°. Вычисляем A⁻¹ по формуле (1.14): делим Ã на |A|.
5°. Проверяем: A⁻¹·A = A·A⁻¹ = E.
```

> **Транспонирование — ровно один раз.** В учебнике оно на шаге 2°, до вычисления дополнений. В других источниках часто наоборот: сначала дополнения элементов `A`, потом транспонирование получившейся матрицы. **Результат тот же** (это и записано равенством `ãᵢⱼ = A'ᵢⱼ = Aⱼᵢ`), но смешивать маршруты нельзя: транспонировать дважды или ни разу — самая частая ошибка в теме.

Учебник помечает шаг 5° как необязательный. На наших занятиях он обязателен: это единственная тема курса, где можно самому на 100% проверить свой ответ.

## 5. Случай 2×2 — знать наизусть

```
A = | a  b |        A⁻¹ = ───1───  ·  |  d  -b |
    | c  d |              ad - bc     | -c   a |
```

Главную диагональ — поменять местами. Побочную — сменить знаки. Поделить на определитель.

## 6. Свойства невырожденных матриц

```
1)  |A⁻¹| = 1 / |A|
2)  (A⁻¹)⁻¹ = A
3)  (Aᵐ)⁻¹ = (A⁻¹)ᵐ
4)  (A·B)⁻¹ = B⁻¹·A⁻¹     ← порядок меняется!
5)  (A⁻¹)' = (A')⁻¹

(A + B)⁻¹ ≠ A⁻¹ + B⁻¹     ← такой формулы НЕ существует
```

## 7. Матричные уравнения

```
A·X = B   ⟹   X = A⁻¹·B      (умножаем СЛЕВА)
X·A = B   ⟹   X = B·A⁻¹      (умножаем СПРАВА)
A·X·C = B ⟹   X = A⁻¹·B·C⁻¹
```

Система `n` уравнений с `n` неизвестными и `|A| ≠ 0` решается так же: `X = A⁻¹·B`. Это **матричный метод**.
