# Дизайн мини-приложения

Два направления оформления мини-приложения «Профиль 10», по два экрана в каждом:
выбор направлений и сравнение профилей.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Вариант A · выбор направлений |
| `ResultA.dc.html` | Вариант A · сравнение профилей |
| `PickB.dc.html` | Вариант B · выбор направлений |
| `ResultB.dc.html` | Вариант B · сравнение профилей |
| `canvas.json` | Раскладка холста и пояснения к вариантам |

**Вариант A — «Спокойный список».** Токены реализованного мини-приложения:
холодный нейтральный фон, индиго `#4d5ae5`, скругление 14 px, системная
типографика. Плотно, читаемо, разбор по каждому направлению словами, хорошо
печатается для родителя. Цена: сравнение профилей приходится листать.

**Вариант B — «Матрица решений».** Тёплая бумага, петролевый `#2e7d6b` и
охра `#b5792e`, прямые углы, Golos Text. Ответ виден сразу цифрой, матрица
«направление × профиль» показывает всю картину на одном экране. Цена: пять
колонок — потолок по ширине телефона, длинные названия сокращаются.

Цифры и формулировки на макетах — реальная выдача расчётного ядра для класса
9А Лицея № 114 по направлениям 09.00.00, 38.00.00, 40.00.00, 31.00.00,
45.00.00. Артборд `ResultB.dc.html` собирается скриптом `build_resultb.py`
прямо из ответа `POST /api/match`, чтобы макет не разошёлся с расчётом.

Вариант A показан в состоянии «обществознание добрано элективом» (3 из 5) —
это демонстрация пересчёта по чипам; вариант B показывает исходный расчёт
(2 из 5).

`profil-10-mini-app.html` — собранный холст (открывается в браузере).
