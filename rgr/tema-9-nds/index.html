ЗАДАЧА 2. Двухосное напряжённое состояние

Дано

1. Тензор напряжений и напряжения на гранях элемента

По закону парности τxy = τyx = −30 МПа. Для двухосного состояния тензор вырождается в матрицу 2×2:

Tн = σxτxyτyxσy = −85−30−30−30 [МПа]

Плоское напряжённое состояние возникает в тонкой пластине, размеры которой в плане много больше толщины (h ≪ a, b), нагруженной силами, лежащими в её плоскости. На площадках с нормалью z, то есть на лицевых поверхностях пластины, нагрузки нет, поэтому σz = 0 и τzx = τzy = 0; из-за малой толщины это справедливо и внутри пластины.

Оба нормальных напряжения отрицательны, поэтому стрелки направлены к граням (сжатие); касательные напряжения тоже отрицательны и потому направлены противоположно положительному направлению осей. Так как из шести компонент отличны от нуля только три, элемент достаточно изобразить плоским — проекцией на плоскость xOy.

2. Главные напряжения

Главные напряжения — корни характеристического уравнения тензора напряжений:

σ³ − I₁н·σ² + I₂н·σ − I₃н = 0(1)

Для плоского состояния (σz = τyz = τzx = 0) инварианты сворачиваются к двум:

I₁н = σx + σy = −85 + (−30) = −115 МПа I₂н = σx·σy − τxy² = (−85)·(−30) − (−30)² = 2550 − 900 = 1650 МПа² I₃н = 0 — при двухосном состоянии третьего инварианта нет

Уравнение распадается:

σ·(σ² − I₁н·σ + I₂н) = 0 → σ = 0 или σ² + 115σ + 1650 = 0

Корень σ = 0 отвечает площадке с нормалью z: по условию на ней нет ни нормальных, ни касательных напряжений, значит ось z — главная. Квадратное уравнение даёт два оставшихся корня:

σ1,2 = I₁н/2 ± √[(I₁н/2)² − I₂н] = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²]
(σx + σy)/2 = (−85 − 30)/2 = −57,5 МПа (σx − σy)/2 = (−85 + 30)/2 = −27,5 МПа √[(−27,5)² + (−30)²] = √(756,25 + 900) = √1656,25 = 40,6971 МПа σ′ = −57,5 + 40,70 = −16,80 МПа σ″ = −57,5 − 40,70 = −98,20 МПа

Нумеруем так же, как на занятии: σ₁ и σ₂ — оба корня, лежащие в плоскости пластины (σ₁ — больший из них), а третье главное напряжение равно нулю и действует по площадке, совпадающей с плоскостью пластины:

Главные напряжения

σ₁ = −16,80 МПа;   σ₂ = −98,20 МПа;   σ₃ = 0

О нумерации. Это не порядок по убыванию: здесь σ₃ = 0 больше обоих остальных. Обычно главные напряжения нумеруют по убыванию, σ₁ ≥ σ₂ ≥ σ₃. Здесь состояние плоское, и по разбору с занятия первые два номера закреплены за напряжениями в плоскости пластины, а нулевое получает третий номер. На результат это не влияет — формулы пп. 7 и 8 симметричны относительно σ₁, σ₂, σ₃, — но в п. 4 от нумерации зависит, какая пара даёт наибольшее касательное напряжение, поэтому она выписана явно.

3. Углы наклона главных площадок к оси x

На главной площадке касательных напряжений нет, поэтому для двухосного состояния условия на нормали дают систему:

(σx − σi)·li + τxy·mi = 0(a) τyx·li + (σy − σi)·mi = 0(b)

где li = cos(σi^x), mi = cos(σi^y). Ось y направлена вниз, поэтому

li = cos αi; mi = cos(αi + 90°) = −sin αi

Подставляем в (b) и делим на cos αi:

τyx·cos αi − (σy − σi)·sin αi = 0 → tg αi = τyx / (σy − σi)(2)
при i = 1 (σ₁ = −16,80 МПа): tg α₁ = −30 / (−30 + 16,8029) = −30 / (−13,1971) = 2,2732 → α₁ = +66,26° при i = 2 (σ₂ = −98,20 МПа): tg α₂ = −30 / (−30 + 98,1971) = −30 / 68,1971 = −0,4399 → α₂ = −23,74°

Проверка. Главные площадки взаимно перпендикулярны, поэтому

|α₁| + |α₂| = 66,26° + 23,74° = 90,00° ✓

Дополнительная проверка — подстановкой найденных косинусов обратно в систему:

Сверка с формулой tg 2α₀. Тот же результат даёт tg 2α₀ = 2τxy/(σx − σy) = −60/−55 = 1,0909 → 2α₀ = 47,49°, α₀ = 23,74°. Эта формула записана для системы с осью y вверх и углом против часовой стрелки: там σ₂ = −98,20 МПа лежит под +23,74°, а σ₁ = −16,80 МПа — под 113,74°. Формула (2) использует ось y вниз, поэтому углы получаются зеркальными: −23,74° и +66,26°. Взаимное расположение площадок и величины напряжений одинаковы, различается только знак отсчёта угла.

4. Экстремальные касательные напряжения

Зачем этот пункт. По главным площадкам касательных напряжений нет вовсе — в этом и состоит их определение. Но рядом с ними есть площадки, где касательное напряжение наибольшее: именно по ним материал начинает течь, и именно эта величина нужна в третьей теории прочности. Такая площадка делит пополам прямой угол между двумя главными направлениями, то есть наклонена к ним под ±45°. Пар главных напряжений три, значит и семейств таких площадок три.

τij = ±(σi − σj)/2, σ′ = (σi + σj)/2 (3)

где σ′ — нормальное напряжение на той же площадке; на всех четырёх её гранях оно одинаково. Подставляем σ₁ = −16,8029; σ₂ = −98,1971; σ₃ = 0 МПа:

пара σ₁, σ₂ — площадки лежат в плоскости пластины: τ₁₂ = ±(−16,8029 − (−98,1971))/2 = ±81,3942/2 = ±40,70 МПа σ′ = (−16,8029 + (−98,1971))/2 = −115,0000/2 = −57,50 МПа пара σ₂, σ₃ — площадки наклонены к плоскости пластины: τ₂₃ = ±(−98,1971 − 0)/2 = ±98,1971/2 = ±49,10 МПа σ′ = (−98,1971 + 0)/2 = −49,10 МПа пара σ₃, σ₁ — площадки наклонены к плоскости пластины: τ₃₁ = ±(0 − (−16,8029))/2 = ±16,8029/2 = ±8,40 МПа σ′ = (0 + (−16,8029))/2 = −8,40 МПа

Наибольшее из трёх — вторая пара:

τmax = τ₂₃ = 49,10 МПа

На что обратить внимание. Первая строка, 40,70 МПа, — это радиус круга Мора, построенного по σx, σy, τxy, и именно её дала бы формула «в плоскости», если ограничиться одним кругом. Но наибольшее касательное напряжение в точке другое, 49,10 МПа: σ₃ = 0 больше обоих напряжений в плоскости, а они оба сжимающие, поэтому самая «широкая» пара — σ₂ и σ₃. Наглядно это на рис. 5: кругов Мора в точке всегда три — по одному на каждую пару главных напряжений, — и наибольшее касательное равно радиусу наибольшего из них. Основной круг, построенный по σx, σy, τxy (п. 9), — это круг пары σ₁, σ₂; он здесь не самый большой. Площадка с τmax наклонена к плоскости пластины, на плоском чертеже её не видно. В примере с занятия такого не возникает: там σ₁ = 100 МПа растягивающее, и наибольшей оказывается как раз пара в плоскости.

5. Напряжения на площадках под углом α = 15° к осям Ox и Oy

Площадка с нормалью ν повёрнута на α от оси x, перпендикулярная ей площадка с нормалью t — на α от оси y. Состояние двухосное (n = cos 90° = 0), поэтому общие формулы сворачиваются к двум слагаемым и одному с τxy:

σν = σx·cos²α + σy·sin²α − τxy·sin 2α (4) τtν = (σx − σy)/2·sin 2α + τxy·cos 2α (5) σt = σx + σy − σν (6)

При α = 15°: cos²α = 0,93301, sin²α = 0,06699, sin 2α = 0,50000, cos 2α = 0,86603.

σν = −85·0,93301 + (−30)·0,06699 − (−30)·0,50000 = −79,31 − 2,01 + 15,00 = −66,32 МПа τtν = (−85 + 30)/2·0,50000 + (−30)·0,86603 = −13,75 − 25,98 = −39,73 МПа σt = −115 − (−66,32) = −48,68 МПа

Проверка по инвариантам. Поворот площадок не меняет инвариантов тензора, поэтому

σν + σt = −66,3157 − 48,6843 = −115,000000 МПа = I₁н ✓ σν·σt − τtν² = 3228,53 − 1578,53 = 1650,000000 МПа² = I₂н ✓

Об угле. Значение α = 15° взято по разбору на занятии. Если в задании указан другой угол, меняются только четыре тригонометрические величины в формулах (4)–(6) — ход решения тот же.

6. Относительные линейные и угловые деформации

Обобщённый закон Гука при σz = 0; E = 2,1·10⁵ МПа, ν = 0,3, G = 0,8·10⁵ МПа.

εx = (1/E)[σx − ν·σy] = (1/2,1·10⁵)·(−85 + 9,0) = −36,19·10⁻⁵ εy = (1/E)[σy − ν·σx] = (1/2,1·10⁵)·(−30 + 25,5) = −2,14·10⁻⁵ εz = −(ν/E)(σx + σy) = (1/2,1·10⁵)·(+34,5) = +16,43·10⁻⁵

Рёбра dx и dy укоротились, ребро dz удлинилось — материал выдавливается в направлении свободной от нагрузки оси z. Объёмная деформация

θ = εx + εy + εz = −21,90·10⁻⁵ контроль: θ = (1 − 2ν)/E · I₁н = (0,4/2,1·10⁵)·(−115) = −21,90·10⁻⁵ ✓

Объём элемента уменьшился — так и должно быть при двухосном сжатии. Угловые деформации:

γxy = τxy/G = −30 / 0,8·10⁵ = −37,50·10⁻⁵ γyz = γzx = 0, так как τyz = τzx = 0

О модуле сдвига. Взято G = 0,8·10⁵ МПа — как в задании. Согласованное с E и ν значение G = E/[2(1 + ν)] = 0,8077·10⁵ МПа даёт γxy = −37,14·10⁻⁵; расхождение 1 %, на выводы не влияет.

7. Полная удельная потенциальная энергия упругой деформации

U₀ = (1/2E)[σ₁² + σ₂² + σ₃² − 2ν(σ₁σ₂ + σ₂σ₃ + σ₃σ₁)]

Суммы удобно взять через инварианты, без округления корней: σ₁² + σ₂² + σ₃² = I₁н² − 2·I₂н = 13225 − 3300 = 9925 МПа²; σ₁σ₂ + σ₂σ₃ + σ₃σ₁ = I₂н = 1650 МПа².

U₀ = (1/(2·2,1·10⁵))·[9925 − 0,6·1650] = 8935 / 4,2·10⁵ = 0,021274 МПа U₀ф = ((1+ν)/6E)·2(I₁н² − 3I₂н) = (1,3/1,26·10⁶)·16550 = 0,017075 МПа (80,3 %) U₀об = ((1−2ν)/6E)·I₁н² = (0,4/1,26·10⁶)·13225 = 0,004198 МПа (19,7 %) контроль: U₀ф + U₀об = 0,021274 МПа = U₀ ✓

На формоизменение приходится 80,3 % всей энергии, на изменение объёма — 19,7 %. Доля объёмной части здесь заметная именно потому, что оба главных напряжения в плоскости одного знака: при разноимённых напряжениях разности σi − σj были бы больше, и на формоизменение уходило бы почти всё.

8. Проверка прочности по энергетической (IV) теории

σэквIV = (1/√2)·√[(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)²] = √(I₁н² − 3I₂н) = √8275 = 90,97 МПа

Расчётное сопротивление R = 210 МПа, коэффициент условий работы γc = 0,9:

σэквIV = 90,97 МПа ≤ R·γc = 210·0,9 = 189,0 МПа ✓

Условие прочности выполняется.

Использовано 48,1 % несущей способности, запас 2,08. Связь с энергией: U₀ф = ((1+ν)/3E)·(σэквIV)² = 0,017075 МПа — то же значение, что в п. 7.

Запас двукратный — и это при том, что наибольшее по модулю напряжение (−98,20 МПа) само по себе немалое. Причина та же, что и в п. 7: в энергетический критерий входят разности σi − σj, а при двухосном сжатии, когда оба напряжения в плоскости одного знака, эти разности малы.

9. Круг напряжений (круг Мора)

Что нужно получить. Круг Мора — не отдельная задача, а геометрическая интерпретация того же расчёта: с одного чертежа должны читаться все результаты пунктов 2–5. Если хоть одна точка не легла на окружность — где-то ошибка в аналитике. Ради этого пункт и делается.

Почему получается именно окружность. Формулы поворота площадок (4) и (5) можно переписать так:

σν − (σx + σy)/2 = (σx − σy)/2·cos 2α − τxy·sin 2α τtν = (σx − σy)/2·sin 2α + τxy·cos 2α

Возведём обе строки в квадрат и сложим — слагаемые с sin 2α·cos 2α взаимно уничтожаются, остаётся

[σν − (σx + σy)/2]² + τtν² = [(σx − σy)/2]² + τxy² (7)

Это уравнение окружности в осях (σ; τ) с центром на оси σ в точке (σx + σy)/2 и радиусом √[((σx − σy)/2)² + τxy²]. Угол α входит в неё только как параметр 2α — поэтому повороту площадки на угол α отвечает поворот точки по кругу на 2α. Отсюда и весь порядок построения: центр — посередине между σx и σy, радиус — гипотенуза прямоугольного треугольника с катетами (σy − σx)/2 и τxy.

Построение (масштаб 1 см = 10 МПа):

1. OD = σx = −85 МПа, OB = σy = −30 МПа — две точки на оси σ 2. DC = CB = (σy − σx)/2 = (−30 + 85)/2 = 27,5 МПа OC = σx + DC = −85 + 27,5 = −57,50 МПа — центр круга 3. BK = τxy = −30 МПа, откладываем от B вниз (знак минус) → точка K 4. R = CK = √(CB² + BK²) = √(27,5² + 30²) = √1656,25 = 40,70 МПа 5. проводим окружность радиуса R из центра C

Что снимается с готового круга. Каждая точка окружности — это одна площадка: её абсцисса даёт нормальное напряжение, ордината — касательное.
