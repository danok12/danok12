# Обратная матрица — раздаточный лист ученика

*(конспект + задачи, без ответов)*

---

## 1. Главное определение

Матрица `A⁻¹` называется **обратной** к квадратной матрице `A`, если

```
A·A⁻¹ = A⁻¹·A = E ,       E = | 1 0 0 |
                              | 0 1 0 |
                              | 0 0 1 |
```

Обратная матрица, если она существует, **единственна**.
Обратная бывает **только у квадратных** матриц.
`A⁻¹` — это обозначение целиком; элементы `A⁻¹` — это **не** `1/aᵢⱼ`.

## 2. Критерий существования

```
A⁻¹ существует  ⟺  det A ≠ 0   (матрица невырожденная)
```

Попутно: `det A⁻¹ = 1 / det A`.

> **Шаг 0 любой задачи: посчитать det A.** Если `det A = 0` — ответ «обратной не существует».

## 3. Формула для 2×2 (знать наизусть)

```
A = | a  b |        A⁻¹ = ───1───  ·  |  d  -b |
    | c  d |              ad - bc     | -c   a |
```

Главную диагональ — поменять местами. Побочную — сменить знаки. Поделить на определитель.

## 4. Метод алгебраических дополнений (любой порядок)

`Mᵢⱼ` — **минор**: определитель, оставшийся после вычёркивания `i`-й строки и `j`-го столбца.
`Aᵢⱼ = (-1)^(i+j)·Mᵢⱼ` — **алгебраическое дополнение**.

Знаки:
```
| +  -  + |
| -  +  - |
| +  -  + |
```

```
            1
A⁻¹ = ───────── · Ã ,     Ã = (Aᵢⱼ)ᵗ  — присоединённая матрица
         det A
```

**Алгоритм:**
```
1) det A ;  если 0 — стоп, обратной нет
2) посчитать все Aᵢⱼ
3) записать их в матрицу на места (i, j)
4) ТРАНСПОНИРОВАТЬ  ← забывают чаще всего
5) поделить на det A
6) проверить: A·A⁻¹ = E
```

## 5. Метод Гаусса–Жордана

```
( A | E )  →  элементарные преобразования СТРОК  →  ( E | A⁻¹ )
```

Разрешено: умножить строку на число ≠ 0; прибавить к строке другую, умноженную на число; поменять строки местами.
Сначала обнуляем всё **под** диагональю, потом **над**.
Если появилась нулевая строка — `det A = 0`, обратной нет.

## 6. Свойства

```
(A⁻¹)⁻¹ = A            (A·B)⁻¹ = B⁻¹·A⁻¹   ← порядок меняется!
(Aᵗ)⁻¹ = (A⁻¹)ᵗ        (λA)⁻¹ = (1/λ)·A⁻¹
det A⁻¹ = 1/det A      E⁻¹ = E

(A + B)⁻¹ ≠ A⁻¹ + B⁻¹  — такой формулы НЕ существует
```

## 7. Матричные уравнения

```
A·X = B   ⟹   X = A⁻¹·B      (умножаем СЛЕВА)
X·A = B   ⟹   X = B·A⁻¹      (умножаем СПРАВА)
A·X·C = B ⟹   X = A⁻¹·B·C⁻¹
```

Система `n` уравнений с `n` неизвестными и `det A ≠ 0` решается так же: `X = A⁻¹·B`.
