# Определённый интеграл — ответы и решения

Все значения получены программой `raschet.py`: каждый интеграл взят
символьно (точно, без float) и независимо проверен численной квадратурой
с 30 знаками. Расхождений нет ни в одной из 44 задач.

---

## Диагностика

1. `x⁵/5` 2. `ln|x|` 3. `e³ˣ/3` 4. `(sin 2x)/2` 5. `2√x` 6. `arctg x`

Все — с точностью до `+C`. Если ученик пишет `ln x` вместо `ln|x|` — сразу
пометь, это отдельная ошибка, она всплывёт в F3.

**B1.** Подынтегральная функция нечётна, отрезок симметричен → ноль.
Считать первообразную не нужно. Если ученик всё же посчитал — хорошо,
пусть сверит, но покажи, что это была лишняя работа.

**B2.** Функция чётна: `∫(−1..1) = 2·∫(0..1) (x⁴ + x) dx = 2·(1/5 + 1/2) = 7/5`.
На `[0; 1]` модуль снимается как `|x| = x`.

**B3.** Раскрываем модуль по точке `x = 2`:
`∫(0..2)(2 − x) dx + ∫(2..3)(x − 2) dx = 2 + 1/2 = 5/2`.
Геометрически — два треугольника, можно проверить без интегрирования.

**B4.** Корни `x² − x − 2` это `−1` и `2`, на `[0; 2]` функция отрицательна,
на `[2; 3]` положительна:
`∫(0..2)` даёт `−10/3` → модуль `10/3`; `∫(2..3)` даёт `11/6`.
Сумма `10/3 + 11/6 = 31/6`.

**B5.** `∫(4..9) = ∫(1..9) − ∫(1..4) = 2 − 7 = −5`; перестановка пределов
меняет знак: `∫(9..4) = 5`.

**B6.** `∫(0..1) 3x² dx + ∫(1..2)(4 − x) dx = 1 + (6 − 3,5) = 7/2`.

**B7.** На `(0; 1)` выполняется `x³ < x²`, значит `∫(0..1) x² dx > ∫(0..1) x³ dx`
по свойству монотонности. Проверка: `1/3 > 1/4`.

**B8.** `1/(x + 2)` убывает на `[1; 4]`, поэтому `m = 1/6`, `M = 1/3`,
и `m·(4−1) ≤ I ≤ M·(4−1)`, то есть `1/2 ≤ I ≤ 1`.
Точно `I = ln 6 − ln 3 = ln 2 ≈ 0,693` — в вилку попало.

**Выбор u.** За `u` берут то, что при дифференцировании упрощается:
многочлен (`D1`, `D2`, `D4`, `D7`), логарифм (`D3`, `D4`, `D8`),
арктангенс (`D5`). Остальное уходит в `dv`.

**D1.** `u = x`, `dv = e²ˣdx` → `xe²ˣ/2 |(0..1) − ½∫(0..1) e²ˣ dx
= e²/2 − (e² − 1)/4 = (e² + 1)/4`.

**D3.** `u = ln x`, `dv = dx` → `x ln x − x |(1..e) = 0 − (−1) = 1`.
Классика: `dv = dx` — законный ход, о нём ученики часто не догадываются.

**D5.** `u = arctg x`, `dv = dx` → `x·arctg x |(0..1) − ∫(0..1) x/(1+x²) dx
= π/4 − ½·ln 2`.

**D6.** По частям дважды, после чего исходный интеграл возвращается:
`I = [eˣ(sin x − cos x)/2](0..π) = (e^π + 1)/2`.
Приём «перенести I в левую часть» — главное, что здесь надо запомнить.

**D7.** Дважды по частям: `(x² − 2x + 2)eˣ |(0..2) = 2e² − 2`.

**D8.** `u = ln²x`, `dv = dx`, потом ещё раз по частям:
`x(ln²x − 2ln x + 2) |(1..e) = e − 2`.

| № | ответ | ≈ |

**E1.** Сначала замена `t = x²`, потом по частям:
`½∫(0..1) t·eᵗ dt = ½·[(t − 1)eᵗ](0..1) = ½·(0 + 1) = 1/2`.
Порядок важен: по частям сразу не берётся.

**E2.** Понижение степени: `cos²x = (1 + cos 2x)/2` →
`½·(π/2) + ¼·sin 2x |(0..π/2) = π/4`.

**E3.** Разбиваем на два. `x³cos x` нечётна, отрезок симметричен → 0.
`sin²x` чётна → `2∫(0..π/2) sin²x dx = π/2`. Итого `π/2`.
Смысл задачи: увидеть, что половина работы не нужна.

**E4.** По частям, `u = ln x`, `dv = √x dx`:
`(2/3)x^{3/2}·ln x |(1..4) − (2/3)∫(1..4) √x dx = (32/3)ln 2 − 28/9`.
Здесь `ln 4 = 2 ln 2` — иначе ответ выглядит иначе, хотя и верен.

**E5.** Замена `x = a − t` даёт `dx = −dt` и переворот пределов, минус
съедается: `∫(0..a) f(x) dx = ∫(0..a) f(a − x) dx`.
Применяем к `I = ∫(0..π/2) sin x/(sin x + cos x) dx` с `a = π/2`:
`sin(π/2 − x) = cos x`, поэтому
`I = ∫(0..π/2) cos x/(cos x + sin x) dx`.
Складываем оба выражения: `2I = ∫(0..π/2) 1 dx = π/2`, значит `I = π/4`.
Первообразная при этом не нужна вообще.

**E6.** `t = √(eˣ − 1)`, тогда `eˣ = t² + 1`, `dx = 2t dt/(t² + 1)`,
пределы `0..1`:
`2∫(0..1) t²/(t² + 1) dt = 2∫(0..1) (1 − 1/(1 + t²)) dt = 2(1 − π/4) = 2 − π/2`.
Ключевой ход — выделить целую часть у `t²/(t² + 1)`.

**E7.** `u = arctg x`, `dv = x dx`:
`(x²/2)arctg x |(0..1) − ½∫(0..1) x²/(1 + x²) dx = π/8 − ½(1 − π/4) = π/4 − 1/2`.

## Блок F. Найди ошибку

**F1. Пределы не пересчитаны при замене.**
Сделав `t = x² + 1`, надо пересчитать и пределы: `x = 0 → t = 1`, `x = 2 → t = 5`.
Верно: `½∫(1..5) t³ dt = (625 − 1)/8 = 78`. В «решении» получилось 2.
*Как поймать:* после замены в записи не должно остаться ни одного `x`.
Если пределы остались старыми, а переменная новая — это и есть ошибка.

**F2. Формула Ньютона—Лейбница применена к разрывной функции.**
`1/x²` не определена в `x = 0`, а ноль лежит внутри `[−1; 1]`.
Условие «`f` непрерывна на `[a; b]`» нарушено, формулой пользоваться нельзя;
интеграл несобственный и расходится.
*Как поймать без теории:* подынтегральная функция положительна всюду,
значит интеграл не может быть отрицательным. Ответ `−2` невозможен
физически — это сигнал искать разрыв.

**F3. Потерян модуль в первообразной.**
`∫ dx/x = ln|x| + C`, а не `ln x`. На отрезке `[−2; −1]` аргумент
отрицателен, и без модуля выражение не существует.
Верно: `ln|x| |(−2..−1) = ln 1 − ln 2 = −ln 2 ≈ −0,693`.
Знак минус правдоподобен: на этом отрезке `1/x < 0`.

**F4. Нечётность применена на несимметричном отрезке.**
`sin x` действительно нечётна, но свойство `∫(−a..a) = 0` требует
симметричного отрезка. `[0; π]` симметричным не является.
Верно: `−cos x |(0..π) = 1 + 1 = 2`.
*Как поймать:* на `[0; π]` синус неотрицателен, площадь под ним не ноль.

**F5. Потеряно слагаемое `uv`.**
Формула `∫ u dv = uv|(a..b) − ∫ v du`, а в «решении» осталась только вторая
часть. Пропущено `−x·cos x |(0..π) = π − 0 = π`.
Верно: `π + ∫(0..π) cos x dx = π + 0 = π`. В «решении» вышел 0.
*Как поймать:* подынтегральная функция `x·sin x` на `[0; π]` неотрицательна
и не равна тождественно нулю, значит и интеграл строго положителен.
