# Функции и их свойства — конспект и задачи

По учебнику Алимова: глава II, §6 «Степенная функция, её свойства и график».
Промежутки записываем, как в учебнике, неравенствами: «x ≥ 0», а не «[0; +∞)».

---

## Конспект

### 1. Что такое функция

**Функция** — правило, которое каждому допустимому значению `x` ставит в соответствие **ровно одно** значение `y`. Пишут `y = f(x)`; `x` — аргумент, `y` — значение функции.

Задать функцию можно формулой, графиком, таблицей или словами.

**Проверка по графику:** любая вертикальная прямая пересекает график функции не больше чем в одной точке.

### 2. Схема описания функции

```
1. Область определения — при каких x формула имеет смысл
2. Множество значений — какие y функция принимает
3. Чётность или нечётность
4. Нули — при каких x значение равно 0
5. Промежутки знакопостоянства — где y > 0, где y < 0
6. Промежутки возрастания и убывания
7. Наибольшее и наименьшее значения; ограниченность
```

По графику: область определения — проекция графика на ось `Ox`, множество значений — на ось `Oy`.

### 3. Область определения

```
дробь                              знаменатель ≠ 0
√ (и корень любой чётной степени)  подкоренное выражение ≥ 0
√ в знаменателе                    подкоренное выражение > 0
x⁻ⁿ = 1/xⁿ                         x ≠ 0
xᵖ, p > 0 нецелое                  x ≥ 0
xᵖ, p < 0 нецелое                  x > 0
∛ и корни нечётной степени         ограничений нет
```

Если условий несколько, должны выполняться **все**.

**Внимание:** в учебнике степень с нецелым показателем определена только при неотрицательном основании. Поэтому `y = ∛x` определена при всех `x`, а `y = x^(1/3)` — только при `x ≥ 0`.

### 4. Нули, знаки, множество значений

- **Нули:** решить `f(x) = 0` и **проверить, что корни входят в область определения**.
- **Знаки:** метод интервалов — нули и точки разрыва делят прямую на промежутки, в каждом знак постоянен.
- **Множество значений:**
  - `x² ≥ 0`, `√x ≥ 0`, `|x| ≥ 0`;
  - у параболы вершина `x₀ = −b/(2a)`, `y₀ = f(x₀)`: ветви вверх — `y ≥ y₀`, ветви вниз — `y ≤ y₀`;
  - `k/x` никогда не равно нулю, поэтому `y = k/x + b` не принимает значение `b`.

### 5. Чётность и нечётность

```
чётная:    f(−x) = f(x)    для всех x из области определения
нечётная:  f(−x) = −f(x)   для всех x из области определения
```

График чётной функции симметричен относительно оси `Oy`, нечётной — относительно начала координат.

**Алгоритм:**
1. Симметрична ли область определения (вместе с каждым `x` в неё входит `−x`)? Если **нет** — функция ни чётная, ни нечётная, дальше проверять не нужно.
2. Найти `f(−x)`, упростить, сравнить с `f(x)` и с `−f(x)`.

Проверка на числах может только **опровергнуть** чётность: одной пары `f(1) = f(−1)` для доказательства мало.

### 6. Возрастание и убывание

```
возрастает на промежутке:  x₂ > x₁  ⇒  f(x₂) > f(x₁)
убывает на промежутке:     x₂ > x₁  ⇒  f(x₂) < f(x₁)
```

- `y = kx + b`: при `k > 0` возрастает на R, при `k < 0` убывает на R.
- Парабола меняет характер монотонности в вершине.
- `y = k/x` при `k > 0` убывает при `x < 0` и убывает при `x > 0`, но **не на всей области определения**: `−1 < 1`, а `4/(−1) < 4/1`. Промежутки монотонности нельзя склеивать знаком `∪`.

**Ограниченность:** функция ограничена снизу, если есть число `m`, что `f(x) ≥ m` при всех `x`; сверху — если есть `M`, что `f(x) ≤ M`.

### 7. Степенная функция `y = xᵖ`

| Показатель `p` | Область определения | Множество значений | Чётность | Монотонность | Пример |
|---|---|---|---|---|---|
| чётное натуральное | R | y ≥ 0 | чётная | убывает при x ≤ 0, возрастает при x ≥ 0 | `x⁴` |
| нечётное натуральное | R | R | нечётная | возрастает на R | `x³` |
| отрицательное чётное | x ≠ 0 | y > 0 | чётная | возрастает при x < 0, убывает при x > 0 | `x⁻²` |
| отрицательное нечётное | x ≠ 0 | y ≠ 0 | нечётная | убывает при x < 0 и при x > 0 | `x⁻¹` |
| положительное нецелое | x ≥ 0 | y ≥ 0 | ни та ни другая | возрастает при x ≥ 0 | `x^(1/2)` |
| отрицательное нецелое | x > 0 | y > 0 | ни та ни другая | убывает при x > 0 | `x^(−1/2)` |

Все эти графики проходят через точку `(1; 1)`.

### 8. Сравнение чисел через монотонность

Возрастающая функция **сохраняет** знак неравенства, убывающая — **меняет**.

```
0,7⁻³ и 0,8⁻³:  y = x⁻³ убывает при x > 0;  0,7 < 0,8  ⇒  0,7⁻³ > 0,8⁻³
```

### 9. Сдвиги графиков

```
y = f(x − a)   сдвиг графика y = f(x) на a вправо     (x − 2 → вправо на 2)
y = f(x + a)   сдвиг на a влево                       (x + 3 → влево на 3)
y = f(x) + b   сдвиг на b вверх, при b < 0 — вниз
```

## Блок F. Найди ошибку

Не решайте заново — найдите, на каком шаге решение сломалось, и объясните почему.

**Н1.** Найти область определения `y = √(x + 2) + 1/(x − 3)`.
*Решение:* `x + 2 ≥ 0`, значит `x ≥ −2`. *Ответ:* `x ≥ −2`.

**Н2.** Найти нули функции `y = (x² − 9)/(x − 3)`.
*Решение:* `x² − 9 = 0`, `x = ±3`. *Ответ:* `−3; 3`.

**Н3.** Найти множество значений функции `y = √(x − 5)`.
*Решение:* подкоренное выражение неотрицательно: `x − 5 ≥ 0`, `x ≥ 5`. *Ответ:* `x ≥ 5`.

**Н4.** Выяснить, чётна ли функция `f(x) = x³ + x² − x`.
*Решение:* `f(1) = 1 + 1 − 1 = 1`, `f(−1) = −1 + 1 + 1 = 1`. Так как `f(−1) = f(1)`, функция чётная.

**Н5.** Выяснить, чётна ли функция `y = x²`, `−2 ≤ x ≤ 3`.
*Решение:* `(−x)² = x²`, значит `f(−x) = f(x)`, функция чётная.

**Н6.** Найти промежутки монотонности функции `y = 4/x`.
*Решение:* это гипербола в первой и третьей четвертях, она убывает. *Ответ:* убывает на всей области определения, то есть при `x ≠ 0`.

**Н7.** Описать функцию `y = (x + 3)² − 2`.
*Решение:* график получается из параболы `y = x²` сдвигом на 3 вправо и на 2 вниз. Вершина `(3; −2)`. Наименьшее значение `−2` при `x = 3`.

**Н8.** Сравнить `(−5)⁻³` и `(−4)⁻³`.
*Решение:* функция `y = x⁻³` убывает при `x < 0`. Так как `−5 < −4`, то `(−5)⁻³ < (−4)⁻³`.
