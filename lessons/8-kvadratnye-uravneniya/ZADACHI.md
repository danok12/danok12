# Квадратные уравнения — домашнее задание

## 1. Раскройте скобки и приведите подобные

1. `(x + 4)(x − 3)`
2. `(2x − 5)²`
3. `(x − 2)² − (x + 1)(x − 4)`
4. `(x + 1/2)²`

## 2. Решите неполные квадратные уравнения

1. `x² − 16 = 0`
2. `3x² − 27 = 0`
3. `x² + 9 = 0`
4. `2x² + 7x = 0`
5. `x² = 3x`
6. `4x² − 1 = 0`

## 3. Решите уравнения через дискриминант

1. `x² − 5x + 6 = 0`
2. `x² + 2x − 15 = 0`
3. `2x² − 3x − 2 = 0`
4. `x² − 6x + 9 = 0`
5. `x² + x + 5 = 0`
6. `3x² + 5x − 2 = 0`
7. `−x² + 4x + 5 = 0`
8. `x² − 4x + 1 = 0`

## 4. Раскройте скобки и решите уравнения

1. `(x − 3)(x + 2) = 14`
2. `(x + 4)² = 3x + 22`
3. `(2x − 1)² = (x + 1)²`
4. `(2x + 3)(x − 1) = (x + 1)² + 2`
5. `(x − 2)² + (x + 3)² = 25`

## 5. Решите уравнения с дробными коэффициентами

1. `x²/2 − x − 4 = 0`
2. `x²/6 − x/3 = 1/2`
3. `(x² − 1)/4 = (x + 1)/2`
4. `0,5x² − 1,5x + 1 = 0`
5. `(2x² − 3)/5 − x/2 = 2`

## 6. Решите задачи с помощью уравнения

1. Одно натуральное число на 5 больше другого, а их произведение равно 84. Найдите эти числа.
2. Длина прямоугольника на 3 см больше ширины, площадь равна 54 см². Найдите стороны прямоугольника.
3. Произведение двух последовательных натуральных чисел равно 156. Найдите эти числа.
4. Сторону квадрата увеличили на 3 см, и его площадь стала 64 см². Какой была сторона квадрата?
5. Мяч подбросили вверх. Его высота над землёй через t секунд равна h = 20t − 5t² метров. Через сколько секунд мяч будет на высоте 15 м?

## 7. Найдите ошибку в решении и решите правильно

1. Решите уравнение `x² = 6x`. Решение: «делим обе части на x: x = 6»
2. Решите уравнение `2x² − 5x − 3 = 0`. Решение: «D = 25 − 24 = 1, x = (5 ± 1) : 4, x = 1,5 или x = 1»
3. Решите уравнение `(x − 2)² = 3x − 2`. Решение: «x² − 4 = 3x − 2, x² − 3x − 2 = 0, D = 17»
