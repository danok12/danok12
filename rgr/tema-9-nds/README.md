# Тема № 9. Исследование НДС в окрестности точки тела (РГР)

Вариант: задача 1 — строка 14 (σx, σy, τxy) и строка 11 (σz, τyz, τzx);
задача 2 — σx по строке 29, σy по строке 8, τxy по строке 25.

Документ собран целиком: **задача 1 — пункты 1–8**, **задача 2 — пункты 1–3**,
выводы. Порядок решения и обозначения повторяют разбор на практическом занятии:
U₀ = U₀^об + U₀^ф через главные напряжения, σ_экв^IV по модели Фёппля — Мизеса,
главные напряжения задачи 2 — из кубического уравнения с I₃н = 0, углы — по формуле
tg αi = τyx/(σy − σi) при оси y, направленной вниз.

## Схемы

| рисунок | что показывает |
|---|---|
| 1.1 | напряжения на гранях элементарного параллелепипеда (аксонометрия) |
| 1.2 | главный элемент, построенный по найденным направляющим косинусам |
| 1.3 | диагональная площадка с наибольшим касательным τ31 |
| 1.4 | линейные деформации: контур до и после |
| 1.5 | **угловые деформации сразу на трёх координатных плоскостях, пространственно** |
| 2.1 | напряжения на гранях элемента при плоском состоянии |
| 2.2 | главный элемент задачи 2, углы α₂ и α₃ от оси x |

Аксонометрия: z вверх, x вправо, y на зрителя — как на схеме элемента в тетради.
В рис. 1.5 деформированный элемент строится тензором сдвига (недиагональные члены
γij/2) с увеличением углов примерно в 200 раз; знаки проверяются скриптом —
при γ > 0 угол на рисунке действительно уменьшается, при γ < 0 увеличивается.
