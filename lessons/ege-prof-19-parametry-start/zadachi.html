ННайди ошибку

Каждое решение неверное. Найди место, где ошибка, и запиши правильный ответ.

  1. Н.1

    Найдите все значения a, при которых уравнение (a − 1)x² + 2x + 1 = 0 имеет ровно один корень.

    Решение ученика

    «D/4 = 1 − (a − 1) = 2 − a. Один корень при D = 0, то есть a = 2. Ответ: a = 2».

    Где ошибка? Верный ответ: ______________________

  2. Н.2

    Найдите все значения a, при которых уравнение (x² − 4)·√x − a = 0 имеет ровно два различных корня.

    Решение ученика

    «Корни: x = 2, x = −2, x = a. Чтобы корней было два, x = a должен совпасть с одним из них: a = ±2. Ответ: a = ±2».

    Где ошибка? Верный ответ: ______________________

  3. Н.3

    Найдите все значения a, при которых система x² + y² = 4,y = x + a имеет ровно два решения.

    Решение ученика

    «Расстояние от центра до прямой равно |a|, оно должно быть меньше радиуса 2. Ответ: −2 < a < 2».

    Где ошибка? Верный ответ: ______________________
